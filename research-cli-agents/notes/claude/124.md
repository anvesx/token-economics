# 124 — The Hidden Cost Driver in Agentic Coding: Not the Per-Token Price
- **Source**: https://vantage.sh/blog/agentic-coding-costs (Vantage, date not stated; references Opus 4.6, GPT-5.4, Composer 2)
- **Claim**: In agentic coding, cost is driven by accumulated re-sent input context (about 25:1 input to output), so session length, retries, compaction and model choice matter more than per-token sticker price.
- **Mechanism**: Each turn is a separate API call that re-sends system prompt, files read, edits, errors and full history. Input grows across the session while output stays flat; retries at turn 40 are billed at the inflated context size; compaction that drops needed content causes re-reads (paying twice). Cursor max mode routes to premium models pay-per-token outside the included allowance and can spike cost unseen. Recommended tracking: model distribution by usage type, per-user patterns, Fast vs Standard variant, max-mode usage.
- **Numbers**: Illustrative 50-turn session: turns 1-10 ~5,000 in / ~600 out per turn; 11-30 ~20,000 / ~1,000; 31-50 ~35,000 / ~800; total roughly 1M input and 40K output tokens. Session cost: Claude Opus 4.6 $6.00 (input $5.00 + output $1.00); GPT-5.4 $3.10; Composer 2 Fast $1.80; Composer 2 Standard $0.60. 25-person team, ~1,000 sessions/month: Opus 4.6 ~$6,000/mo (~$72,000/yr); GPT-5.4 ~$3,100; Composer 2 Fast ~$1,800; Composer 2 Standard ~$600 (~$7,200/yr). Prices cited: Opus 4.6 output $25/M; Composer 2 Standard $0.50/$2.50 per M, Fast $1.50/$7.50 per M; Cursor Teams $40/user/month. Non-agentic usage ~10,000 interactions a month maybe ~$30/month on Opus, so agentic is about 200x more costly. Claims: a session with 2x the turns may cost 3-4x; same-team engineers can differ 10x; Standard variant could cut background-task cost by two-thirds; input ~85% of session total.
- **Token-cost implication**: Start a fresh session when a task ends, keep sessions short, cap retry loops, use cheaper models (or Standard variants) for long background work, and track spend by model, user and max-mode flag rather than total tokens.
- **Caveats**: Vendor blog from a cost-tracking product; figures are explicitly illustrative/approximate, not measured; ignores prompt-cache discounts, which would lower the input cost materially (the phase table sums to about 1.15M, rounded to 1M in the text).
