# 071 — Amp and your Claude subscription: What Is Free and What Still Costs Money?
- **Source**: https://kingy.ai/blog/amp-claude-subscription-costs-limits (Kingy AI, 2026-11; article dated Oct 10, 2026)
- **Claim**: Amp's new Claude Code mode lets a Claude Pro/Max subscription pay for Claude usage on the user's own runner, but hosted orbs, Painter image generation and Amp's own modes are metered separately. The article is documentation-based and proposes, but does not run, a comparison protocol.
- **Mechanism**: Mode > Claude Code in Amp uses Anthropic's Agent SDK; subscription linked under Settings > Model Routing. Billing map: own runner = Claude plan usage, runner free; hosted orb = Claude plan plus orb usage (allowances or credits); Painter = Amp credits; Amp's own modes/raw models = not covered by Claude plan. Orbs bill by the minute, auto-pause 5 minutes after agent work ends or 20 minutes after last interaction, whichever is later; opening an unarchived thread or portal can wake compute. Claude and Claude Code share the same five-hour and weekly limits; Agent SDK / claude -p with subscription auth still draws on plan limits.
- **Numbers**: Orb rates $0.08/hr (a1.tiny), $0.17/hr (a1.small), $0.33/hr (a1.medium), up to $2.13/hr (a1.3xlarge). Hypothetical 30 min: small orb 0.5 x $0.17 = $0.085; medium $0.165 (excludes tax, credits, allowances; not observed invoices).
- **Token-cost implication**: Run on a local runner to avoid orb charges, forbid the Painter tool in project instructions for coding-only work, and log Claude usage, orb minutes and any paid continuation as separate columns when comparing tools.
- **Caveats**: No matched run or settled charges verified; reader limit reports are unverified; enterprise pricing differs; tool exclusions untested; subscription limits still apply.
