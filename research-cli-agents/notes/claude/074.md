# 074 — Hooks reference (Claude Code Docs)
- **Source**: https://code.claude.com/docs/en/hooks (Anthropic official documentation, undated)
- **Claim**: Hooks are shell commands, HTTP endpoints, MCP tool calls, LLM prompts or subagents that run at lifecycle events. Several events and fields let you control what enters the context window and observe session cost.
- **Mechanism**: Context injection: stdout from UserPromptSubmit, UserPromptExpansion, SessionStart and PostModelSwitch hooks, and the additionalContext field, is added to Claude's context as a system reminder. PreCompact stdout becomes instructions for the compaction summary, and PreCompact can block compaction (exit 2). Other events send stdout to the debug log only. PostToolUse updatedToolOutput replaces a tool's result before the model sees it; PreToolUse updatedInput rewrites tool arguments. PostToolBatch fires after parallel tool calls and before the next model call. PreModelSwitch and PostModelSwitch hooks receive from_model and to_model and can block a switch. StopFailure matches error types such as rate_limit, overloaded, billing_error, max_output_tokens. Hook input carries an effort level (low, medium, high, xhigh, max). Prompt hooks run a single-turn Claude call (default model is the one used for background functionality); agent hooks spawn a subagent; async and asyncRewake run in the background.
- **Numbers**: Hook output cap: additionalContext, systemMessage, initialUserMessage and plain stdout are each limited to 10,000 characters; over the cap the output is saved to a file and replaced by the path plus a preview of up to 2,000 characters (no setting raises it; PreCompact stdout is exempt). Default timeouts: 600 s for command, http and mcp_tool; 30 s for prompt; 60 s for agent. At most 12 prompt or agent hooks run concurrently per event. Skill sources can register at most 1,024 hooks and 16,384 matcher characters per source. SessionStart on resume or fork (v2.1.251 or later) receives seconds_since_last_response, context_tokens, prompt_cache_likely_expired and estimated_cache_write_usd; docs example: 182,340 context tokens, cache expired after 90 minutes, estimated cache write cost 1.1396 USD.
- **Token-cost implication**: A resume hook can warn before a stale session re-sends its whole context uncached, so you can choose /clear or compaction instead. PostToolUse updatedToolOutput can trim bulky tool results (for example test or build logs) before they reach the model. PreCompact instructions steer what the summary keeps. Every hook that injects text adds tokens on every firing and is replayed from the transcript on resume, so keep injected text short. Prompt and agent hooks cost model calls of their own.
- **Caveats**: Official docs describe behaviour, not measured savings. Many fields are version-gated (for example v2.1.251, v2.1.304, v2.1.314), and agent hooks are marked experimental. Cost fields are estimates (cache write only, response excluded). Injected context persists in the transcript and counts against the window. Reference page, so no benchmarks.
