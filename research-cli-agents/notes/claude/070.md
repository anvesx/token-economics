# 070 — Amp Code Free: What Happened & Alternatives (2026)
- **Source**: https://www.bitdoze.com/amp-code-free-ai-coding-agent (Bitdoze, 2026-02 per metadata; text refers to mid-2026 events)
- **Claim**: Amp's free tier went through three funding models in about eight months (ads plus training data, ads only, daily credit grant) and was paused in mid-2026 because frontier tokens got expensive faster than ad revenue. What remains is Amp Smart, usage-priced at model list prices with no subscription.
- **Mechanism**: Amp routes to models itself (no model picker, no BYOK, no local models). Smart mode: pay-as-you-go at list prices, no markup for individuals/teams; Enterprise adds markup, zero retention and pooled credits. Features: subagents (own context each), Oracle deep-reasoning tool, MCP tools, `amp -x` non-interactive runs (needs paid credits), AGENTS.md, /compact, one task per thread, thread File Changes revert. Cost-control habits: one task per thread, /compact, cap subagents (about three), use Oracle sparingly, check the usage page before unattended loops, scope CI review to PR diffs.
- **Numbers**: Amp Free launched Oct 2025; training clause dropped a week later; ads dropped Mar 2026; paused mid-2026. Small fix costs cents; multi-hour refactor with subagents and Oracle calls can run into dollars (no exact figures). No other pricing numbers.
- **Token-cost implication**: Do not build workflows on subsidised free tiers; keep a paid fallback. Subagents and Oracle multiply token burn, so limit them; context hygiene (/compact, fresh threads) is cheaper than retries.
- **Caveats**: Independent blogger, no measured costs; "answers feel dumber" attributed to rotating model routing is an assertion; much of the text is install and safety guidance rather than cost data; some details marked as needing verification against `amp --help`.
