# 080 — Best practices for Claude Code
- **Source**: https://code.claude.com/docs/en/best-practices (Anthropic, date not given)
- **Claim**: Defaults are good; setup pays off for knowledge Claude cannot see. The page also lists the levers that change cost: keep CLAUDE.md short, use skills and path-scoped rules, tune effort and model, know what subagents cost, clear and compact deliberately, and cap unattended runs.
- **Mechanism**: CLAUDE.md is loaded every session so every line costs attention; only write what cannot be found by reading the repo (/doctor and /doctor prompt-audit suggest cuts; memory guide recommends under 200 lines). Skills expose only name and description each session and read the full file on demand. .claude/rules/ with a paths: filter loads only when working in matching files. Connected MCP servers add tool names and instructions to context even when unused, so disable unneeded ones. Effort (/effort low|high|xhigh|max, ultrathink for one turn) is the main thinking control; max tends to overthink on ordinary tasks. Subagents spend their own requests against the same usage; model: haiku in a subagent definition, short summaries back, and tool-restricted agents reduce cost. /usage breaks usage down by skill, subagent, plugin and MCP server on Pro, Max, Ultra, Team and Enterprise and flags long context or frequent cache misses above 10% of usage. /clear between unrelated tasks; /compact with a focus; after two failed corrections, /clear and rewrite the prompt. Unattended runs: --max-turns, --max-budget-usd, --bare (skips hooks, skills, plugins, MCP, CLAUDE.md), --allowedTools, --permission-mode dontAsk. Deterministic controls (hooks, deny rules, Stop hook) replace emphasis in CLAUDE.md.
- **Numbers**: Defaults named: Opus 5.5, Sonnet 5.5 and Haiku 5.5 default to medium effort. Most current models have a 1M-token window. Prompt cache lasts about an hour on a subscription and five minutes on an API key, cloud provider or usage credits; subagents get five minutes unless changed. On the one-hour cache, a session past about 200K tokens that sits idle is compacted shortly before cache expiry. /usage flags patterns once they pass 10% of usage. Stop hook override after 8 consecutive blocks without a tool call. Auto mode pauses after 3 consecutive (or 20 total) blocks. /batch splits work into 5 to 30 units. No dollar prices.
- **Token-cost implication**: Every request resends the whole conversation (discounted while cache is warm, full price after expiry), so /clear between tasks and keep unrelated work out of one session. Run /compact with a focus and before the cache expires, since compaction itself is a big request. Keep CLAUDE.md minimal, move procedures to skills and scoped rules, drop unused MCP servers. Use low effort for fast iteration, high or xhigh only for edge-case-heavy work, max rarely. Route simple subagent jobs to Haiku and ask for short returns. Cap background loops, goals and unattended runs with turn and spend limits since they keep sending requests while idle.
- **Caveats**: Vendor guidance, no measured savings. Model names and defaults (Opus 5.5, Fable 5.1) reflect the doc as written. Not an independent benchmark.
