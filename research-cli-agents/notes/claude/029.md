# 029 — A Unified Approach to Routing and Cascading for LLMs
- **Source**: https://arxiv.org/abs/2410.10347 (Dekoninck, Baader, Vechev; ETH Zurich; arXiv 2024-10, v5)
- **Claim**: Routing (pick one model per query) and cascading (run models in sequence until one is good enough) can be unified as "cascade routing". The authors derive an optimal cascading strategy, prove an existing routing strategy optimal, and show cascade routing beats both. Quality estimator accuracy is the critical factor.
- **Mechanism**: Treat each set of models as a "supermodel" with expected quality E[max quality] and summed cost. At each step, pick the supermodel with the best cost-quality tradeoff (parameter lambda), run its cheapest unrun model, update quality and cost estimates from the output (for example low confidence or long output), and repeat or stop. Routing is the special case of one step with ex-ante estimates. Cascading is the case of a fixed order with post-hoc estimates. Pruning: if a model has negative marginal gain in a supermodel, all supermodels containing that set are dropped, which cuts the 2^k search. Prior threshold-based cascades are shown optimal only under strong assumptions.
- **Numbers**: RouterBench (7 benchmarks, 11 models; AUC % of quality-cost curve). 3 models low/med/high noise: linear interpolation 69.62/69.62/69.62; routing 79.73/74.97/71.81; baseline cascade 80.86/74.64/72.48; new cascade 81.09/76.16/72.67; cascade routing 82.36/76.55/73.22. 11 models, low noise: routing 83.25, baseline cascade 84.48, cascade routing 87.24. Gains over baselines 1% to 4% AUC (13% to 80% relative to linear interpolation); up to 8% over cascading and 12% over routing across noise grids; new cascade up to 2% over threshold cascade. Gap grows with more models and lower noise. SWE-Bench (post-hoc quality via tests, cost = latency in seconds, 10 models): up to 14% over baselines; cascade routing AUC 54.21; routing no better than trivial baseline; threshold cascade also poor because binary feedback makes the threshold admit all or only correct models. Qwen Math+Coder on Minerva Math plus LiveCodeBench (accurate ex-ante): cascade routing 51.20 and the new cascade clearly beats the baseline cascade. Classification and open-form (Llama, Gemma, Mistral, 3 models each, log-prob quality estimator): margins up to 1.2%, for example 58.20, 75.56, 64.89, 79.95. Ablation (11 models): variant without the pruning lemma is almost an order of magnitude slower at similar quality; greedy and no-expectation variants are faster but 0.5% to 1.3% worse at low and medium noise.
- **Token-cost implication**: Route on ex-ante signals only if they are accurate. In agent loops where cheap post-hoc checks exist (tests passing, linter, type check), cascade from a cheaper model and escalate on failure. With noisy estimators expect only about 1% gain, so the router is not free value. Selection overhead must stay negligible next to model compute.
- **Caveats**: RouterBench estimates are simulated with Gaussian noise on true quality, not real estimators. Real-benchmark gains are small (up to 1.2%) with log-prob estimators. SWE-Bench quality uses ground-truth tests as the post-hoc oracle, which a real agent lacks. Model sets are small (3 to 11) and static, and cost is generation cost or latency, not cache-aware billing. Self-reported on public benchmarks.
- **Topic**: routing
