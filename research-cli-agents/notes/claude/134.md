# 134 — The Best Programming Language for Tokenmaxxing (coding agent token cost by language)
- **Source**: https://arxiv.org/abs/2607.22807 (arXiv 2607.22807v2, Wu, Anderson, Guha; Northeastern/Wellesley, v2 21 Oct 2026)
- **Claim**: At comparable accuracy, the agent's output-token cost depends on the target programming language, and lower-resource languages (OCaml most, then Rust, Java) cost significantly more than Python, consistently across five models, after controlling for problem difficulty.
- **Mechanism**: mini-swe-agent on a 100-problem subset of LiveCodeBench (MiniLCB, language-agnostic stdin/stdout tasks, visible tests via ./test.sh) in Python, Java, Rust, OCaml; five models (Qwen 3.6-35B-A3B, Gemma-4-26B-A4B, GLM-5.2, GPT-5.5, Claude Sonnet 4.6), 2,000 trajectories, 40-turn and 600 s limits. Cost = total output tokens over all trajectories (failures included; "no refund"). Mixed-effects model: language fixed effect, problem random effect. Every intermediate solution is re-executed to classify transitions (breakthrough, stay, improved, regressed, churn, broke, stuck); spans between snapshots are labeled with a 12-category taxonomy by an LLM judge (GPT-5-Mini). Waste patterns: noncompiling code loops in unfamiliar languages, revising already-passing solutions, distrusting provided tests, planning in code comments, prototyping in Python first.
- **Numbers**: OCaml vs Python output-token ratio: Gemma 1.44x, Qwen 1.69x, GLM 1.54x, GPT-5.5 1.30x, Sonnet 1.28x (all p<0.001; OCaml range 1.28-1.69x). Java vs Python: Gemma 0.85x (n.s.), Qwen 1.21x, GLM 1.34x, GPT-5.5 1.30x, Sonnet 1.18x. Rust vs Python: Gemma 1.07x (n.s.), Qwen 1.20x, GLM 1.57x, GPT-5.5 1.36x, Sonnet 1.16x. ICC (share of variance from problem identity) 0.73-0.97. Gemma OCaml tokens per success 45,390 (1.4-1.9x other languages); Gemma OCaml has 1,196 stuck self-loops (revert 31%; 92% of failed snapshots are compile errors). Gemma Python 205 "stay" loops (rewriting passing solutions). Tokens after first correct solution (median, tokens/turns): Gemma Python 3,628 (3), Rust 7,312 (3); Qwen 294-405; GLM 98-122. Gemma/Qwen reasoning "wait/actually" 7.70 and 7.72 per turn. Qwen wrote a 35-line Java solution with 3,439 comment lines. Reproduction cost about $100 GPT-5.5, $150 Sonnet, $25 GLM (400 tasks per model at July 2026 rates). Accuracy barely varied by language except Gemma on OCaml. Cheating in 2 of all traces. Stack v2 corpus: about 200GB Java and Python, 12GB Rust, less OCaml.
- **Token-cost implication**: Budget by language, not code length: agent cost comes from reasoning and revision, mostly output tokens. Wasted spend comes from post-success polishing (stop at first all-pass), compile-error loops, and self-invented tests ignoring the provided ones; smaller models waste more. Failed runs are not refunded, so use tokens-per-success.
- **Caveats**: Competitive-programming problems with visible tests, a single scaffold (mini-swe-agent) with fixed prompt, 40 turns, 10 minutes; may not generalize to repo-scale work or other harnesses; counts output tokens only (not input/cache); four languages; effect may shrink as pretraining improves; for GPT-5.5 and Sonnet OCaml is not the most expensive per success. Title is satirical, authors discourage deliberately inflating spend.
