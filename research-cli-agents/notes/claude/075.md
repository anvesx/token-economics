# 075 — Extend Claude with skills
- **Source**: https://code.claude.com/docs/en/skills (Anthropic, date not given)
- **Claim**: Claude Code skills (SKILL.md files) load only a short description every turn and pull the full body into context when invoked, unlike CLAUDE.md which is always loaded. The page also documents controls (disable-model-invocation, skillOverrides, context: fork, paths) and /skill-doctor to cut skill context cost.
- **Mechanism**: In a regular session only skill descriptions are in context; the rendered SKILL.md enters as one message when invoked and stays across later turns (not re-read; an identical re-invoke adds a short "already loaded" note, a changed render appends full content again). The combined description + when_to_use text is truncated at 1,536 characters in the listing. disable-model-invocation: true removes the description from context entirely (user-only /name). skillOverrides settings set per-skill states: on, name-only, user-invocable-only, off. paths globs load a skill automatically only for matching files. context: fork runs the skill in a fresh subagent (own context, no conversation history; Explore/Plan agents skip CLAUDE.md and git status). model and effort frontmatter override the model/effort for the turn. Supporting files (reference.md, scripts) load only when needed; scripts are executed, not loaded. !`cmd` injects shell output before the content is sent. /skill-doctor reports each skill's context cost and usage and flags never-invoked skills. Auto-compaction re-attaches the most recent invocation of each skill.
- **Numbers**: Description + when_to_use truncated at 1,536 characters in the listing. Keep SKILL.md under 500 lines. After auto-compaction, first 5,000 tokens of each invoked skill are re-attached, within a combined 25,000-token budget, filled from the most recently invoked skill (older skills can be dropped). /skill-doctor requires v2.1.252 or later.
- **Token-cost implication**: Move task-specific instructions out of always-loaded CLAUDE.md into skills; keep bodies short because loaded content is a recurring per-turn cost; push reference material into separate files; set disable-model-invocation: true on rarely used skills so their descriptions cost nothing; prune never-used skills using /skill-doctor, highest context cost first; use context: fork (with a cheaper model/effort) for noisy tasks to keep their output out of the main context; budget for the 25,000-token post-compaction cap if many skills are invoked.
- **Caveats**: Vendor documentation, no measured token savings; per-skill listing cost in tokens is not stated. The doc date is not given. Behaviour is version-dependent (several features cite version minimums).
- **Topic**: context
