# 048 — Small Language Models for Efficient Agentic Tool Calling
- **Source**: https://arxiv.org/abs/2512.15943 (Amazon Web Services authors, arXiv, 2025-12; v2 dated 9 Mar 2026)
- **Claim**: AWS authors fine-tune facebook/opt-350m on ToolBench and report a 77.55% ToolEval pass rate, above ChatGPT-CoT, ToolLLaMA and Claude-CoT baselines. They argue targeted SLMs can replace LLMs for tool calling at far lower infrastructure cost.
- **Mechanism**: Supervised fine-tuning with Hugging Face TRL SFTTrainer on Amazon SageMaker (ml.g5.8xlarge). ToolBench (16,000+ RapidAPI APIs) was converted to concatenated system/user/assistant sequences in Thought-Action-Action Input format, giving 187,542 training examples. One epoch, learning rate 5e-5, 100 warmup steps, effective batch 32 (gradient accumulation 4), grad clip max norm 0.3, FP16, gradient checkpointing, AdamW weight decay 0.01, 5,860 steps. Evaluated with ToolEval (ChatGPT as judge, at least 4 assessments per query, majority vote) on 1,100 queries across six ToolBench categories; inference at temperature 0.1, max 8192 tokens, max 10 reasoning iterations.
- **Numbers**: Pass rate: Ours 350M 77.55%; ToolLLaMA-DFS 7B 30.18%; ChatGPT-CoT 175B 26.00%; ToolLLaMA-CoT 7B 16.27%; Claude-CoT 52B 2.73%. Per category (ours): G1 instr 78.5, G1 cat 74.0, G1 tool 79.0, G2 cat 80.5, G2 instr 74.5, G3 instr 80.0. Test set sizes: 200 each for five categories, 100 for G3-instruction. Paper states 20-500x fewer parameters. No dollar costs, latency or token counts are reported.
- **Token-cost implication**: For narrow, structured tool-calling steps, a small fine-tuned model is a candidate to route to instead of a frontier model. Treat the result as a hypothesis to test on your own tool set, not as proof.
- **Caveats**: Self-reported by AWS authors. Cost savings are asserted, not measured. Baselines are older (ChatGPT-CoT, Claude-CoT at 52B, ToolLLaMA), not current frontier models, and results are ToolBench-specific with tight train/eval coupling. The authors themselves list limits: generalization beyond ToolBench, complex tool ecosystems, retraining as APIs change. Claude-CoT at 2.73% suggests format or harness mismatch rather than capability. Abstract mentions summarization and QA tasks but evaluation covers tool calling only.
- **Topic**: routing
