# 039 — Aider Benchmark notes: edit formats and token efficiency
- **Source**: https://aider.chat/docs/leaderboards/notes.html (Aider, no date)
- **Claim**: Aider's leaderboard reports percent of tasks completed correctly and percent using the correct edit format. The "whole" edit format is easiest for LLMs but token-hungry; diff formats use far fewer tokens.
- **Mechanism**: Aider asks the LLM for code edits in a chosen edit format. "whole" returns entire files; diff-style formats return only changes. If the model breaks the format, aider feeds back the error and asks for a fixed edit. Aider picks the best format for popular OpenAI/Anthropic and recommended models, and defaults to "whole" for lesser-known models.
- **Numbers**: none. Pricing on the leaderboard is the cost to run the benchmark at the time it was run, best-effort, may be outdated.
- **Token-cost implication**: Prefer models and harnesses that support diff-style edit formats; "whole" file rewrites cost more tokens and limit editable file size. Unknown models silently default to the costly "whole" format.
- **Caveats**: Qualitative statement only, no quantified token savings. Pricing on the leaderboard may be stale or inaccurate. Self-reported by Aider.
