# 132 — Credit-Budgeted ICPC-Style Coding: When Agents Must Pay for Every Decision (USACOArena)
- **Source**: https://arxiv.org/abs/2604.10182 (Shanghai Jiao Tong Univ., ICLR 2026, 2026-04)
- **Claim**: Coding-agent evaluation ignores cost. USACOArena charges a unified credit budget for every token, local test, hint, wrong submission and wall-clock second. Frontier single agents and swarms fail to balance accuracy against that budget, and the blind parallel swarm loses to a cost-aware one.
- **Mechanism**: Credit = LLM inference cost (normalised by API price) + hint/test cost + alpha x wall-clock time + penalties. The agent stops when action + time cost exceeds the limit; total consumed credit (incl. penalties) breaks ties. Turn-based MCP loop shows credit, score and leaderboard each turn. Three Codex swarm profiles: Speedy Spendthrift (max parallel workers), Frugal Perfectionist (sequential), Cost-Aware Strategist (adapts to remaining budget). Parallel workers add a communication-overhead token category that drains the budget.
- **Numbers**: Default budget 20,000,000 credits per participant; hints 500 to 1,500; test 10 per request; each wrong/error submission 100; scoring weights 1/2/5/10 (Bronze to Platinum); 12 problems per match, 48 problems in the 2024-2025 season; temperature 0.7. Max contest score 54; top agents about 15. Gemini-2.5-pro 13.2 on Feb 2025 contest, 10M budget drops it to 8.3, 40M gives about 13.0 (no gain). GPT-5-Codex 12.0 at default, 4.3 at 10M. Gemini avg rank 1.3, GPT-5-Codex 1.7; max scores 19 vs 29. Aggressive prompt 13.2 to 14.7; few-shot prompts degraded performance by consuming token credits. Swarms: Speedy Spendthrift score 3, Cost-Aware Strategist 8, Frugal Perfectionist 8 but about 300 minutes. Prices (USD per 1M in/out): GPT-5 and GPT-5-Codex $1.25/$10.00, Gemini 2.5 Pro $1.25/$10.00, Claude Sonnet 4 $3.00/$15.00, DeepSeek V3/V3.1 $0.27/$1.10, Qwen3-235B $0.70/$2.80, Kimi-K2 $1.00/$2.75, GLM-4.5 $0.59/$2.19 (Artificial Analysis, Sept 2025).
- **Token-cost implication**: More parallel agents cut latency but inflate tokens through coordination chatter without raising accuracy; a budget-aware orchestrator that scales parallelism to remaining budget matched the sequential score in far less time. Extra budget does not help a capability-limited agent, so raising spend caps buys nothing past the reasoning wall. Verbose few-shot prompts cost credits without better decisions.
- **Caveats**: Competitive-programming (USACO) tasks, not repo-level engineering. Credits are normalised to API price, not billed dollars. Ablations averaged over 3 runs on one contest; main results 5 runs. Swarm experiment uses Codex only; scores are single configurations with no variance reported in the text I read. Claude-4-Sonnet scored 1.0 in the ablation main column.
