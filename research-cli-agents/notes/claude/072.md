# 072 — Create custom subagents
- **Source**: https://code.claude.com/docs/en/sub-agents (Anthropic, no date)
- **Claim**: Claude Code subagents run in their own context window with their own system prompt, tools and permissions, so verbose work stays out of the main conversation and cheaper models can be routed to side tasks. Each subagent still spends its own tokens and counts toward the same usage limits.
- **Mechanism**: Subagents are markdown files with frontmatter (model, tools, disallowedTools, effort, maxTurns, autoCompactWindow, omitClaudeMd, skills, memory, mcpServers, hooks, isolation: worktree, experimental.cacheTtl 5m or 1h). Model resolution order: per-invocation parameter, frontmatter, CLAUDE_CODE_SUBAGENT_MODEL, then the main model; CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 forces one model on all. Explore and Plan skip CLAUDE.md and the git status snapshot "to keep research fast and inexpensive"; Explore can be defined with model: haiku. A non-fork subagent starts with its system prompt, task message, CLAUDE.md files, git status, preloaded skills; a fork inherits the full conversation and shares the parent's prompt cache. MCP servers defined inline in a subagent keep their tool descriptions out of the main context. Subagents auto-compact at their own window; autoCompactWindow sets an earlier trigger. Subagent context window is sized by its own model.
- **Numbers**: Combined subagent descriptions over 15,000 tokens trigger a startup warning (all still load). autoCompactWindow range 100000-1000000 tokens (write 200000, not 200k). Default max 20 concurrent subagents (CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS). Default nesting depth three layers (CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH). Skills field preloads up to 32 distinct names. Memory injects first 200 lines or 25KB of MEMORY.md. Transcripts deleted after 30 days by default. Example compaction log shows preTokens 167189. No price figures.
- **Token-cost implication**: Delegate high-volume output (tests, logs, docs) to subagents and route them to cheaper models (Haiku). Use forks when a subagent would need heavy background, since they reuse the parent's cache. Keep descriptions short, limit tools, set omitClaudeMd or inline MCP servers to cut per-subagent startup context, and cap depth and concurrency. Many subagents returning detailed results can still consume main context.
- **Caveats**: Vendor documentation; no measured savings. Cost statements are qualitative. Features are version-gated (e.g. v2.1.296 for autoCompactWindow, v2.1.217 for the concurrency limit).
