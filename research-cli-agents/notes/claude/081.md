# 081 — Orchestrate teams of Claude Code sessions
- **Source**: https://code.claude.com/docs/en/agent-teams (Anthropic, Claude Code docs, date not given in file)
- **Claim**: Experimental, off-by-default Claude Code feature where a lead session coordinates multiple independent teammate sessions with a shared task list and direct messaging. The docs state teams use significantly more tokens than a single session and cost scales with active teammates.
- **Mechanism**: Enabled with CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 (settings.json env or shell); interactive sessions only (not -p or Agent SDK). Lead spawns teammates; each has its own context window, loads CLAUDE.md, MCP servers and skills, but not the lead's conversation history. Coordination via a mailbox (JSON files at ~/.claude/teams/{team-name}/inboxes/{agent}.json), a file-locked shared task list at ~/.claude/tasks/{team-name}/ (pending/in progress/completed, dependencies auto-unblock), and hooks TeammateIdle, TaskCreated, TaskCompleted (exit code 2 gives feedback). Teammate model precedence: spawn prompt, subagent definition, CLAUDE_CODE_SUBAGENT_MODEL (unless inherit), lead's model; CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 changes this (v2.1.257+). Display modes in-process or split panes (tmux/iTerm2). While enabled, a subagent Claude names launches as a teammate; set the env var to 0 to revert. Teammates start in the lead's permission mode; prompts surface in the lead.
- **Numbers**: In-process teammate prompt cache TTL is 5 minutes by default; subagentPromptCacheTtl=1h extends it, and 1-hour cache writes are billed at a higher rate. Guidance: start with 3-5 teammates; 5-6 tasks per teammate; 15 independent tasks suggests 3 teammates. Idle rows hide after 30 seconds; rows beyond 3 idle collapse. No dollar or percentage token figures given.
- **Token-cost implication**: Use teams only for parallel research, review, competing-hypothesis debugging or separate-module work; use a single session or subagents for sequential or same-file tasks. Keep teams small, set a cheaper teammate model via spawn prompt or CLAUDE_CODE_SUBAGENT_MODEL, and weigh the 5-minute vs 1-hour cache TTL. Disable the env var if unplanned teammate spawning inflates usage.
- **Caveats**: Vendor docs, no measured token multiples. Experimental with known limits: no resume of in-process teammates, task status can lag, one team per session, no nested teams, no per-teammate permission modes at spawn. Trailing part of the file is site navigation config, not content.
