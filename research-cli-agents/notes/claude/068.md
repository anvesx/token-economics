# 068 — Amp Docs: Pricing
- **Source**: https://ampcode.com/docs/pricing (Amp (Sourcegraph), date not stated)
- **Claim**: Amp sells monthly tiers (Hobby free, Individual $20/mo, Teams, Enterprise custom) that include agent and "orb" usage, and after included usage is used up, charges paid credits at provider API prices with no markup for individuals and non-enterprise workspaces.
- **Mechanism**: Credits are deducted for the actual model and tool usage in each thread (e.g. $2 Anthropic + $0.50 OpenAI = $2.50 deducted). Non-model tools such as web search also consume credits. Orbs (Amp-hosted sandboxes) use a separate allowance billed per minute; an orb pauses 5 minutes after the agent stops working or 20 minutes after last user interaction, whichever is later, and a paused orb costs nothing. Larger orb sizes burn the allowance faster. Users can bring their own keys or link ChatGPT/Claude subscriptions ("no Amp token fees or limits"). Per-thread cost is visible via the $ price in the thread sidebar or `amp usage`; Amp can also explain why a thread used more tokens.
- **Numbers**: Individual tier $20/mo with 45,000 minutes of orb time (Amp-hosted orbs); Hobby free; Purchased credits expire 12 months after purchase; included usage resets monthly and does not roll over; orb pause 5 min after agent idle / 20 min after user interaction. No markup on provider API prices for individuals and non-enterprise workspaces. Enterprise is custom pricing, pooled credits only.
- **Token-cost implication**: Treat Amp as pass-through API pricing plus a sandbox-minute meter; model cost is controlled by which models/keys you route, and orb cost by orb size and idle behavior. Use BYOK or linked subscriptions to avoid Amp token fees, and use per-thread cost views to find expensive threads.
- **Caveats**: Vendor's own pricing page; undated; no benchmark data. The "no markup" statement excludes enterprise. Orb-minute-to-dollar conversion is not given.
