# 046 — Coding Agents are Effective Long-Context Processors
- **Source**: https://arxiv.org/abs/2603.20432 (Duke University authors, arXiv preprint, 2026-03)
- **Claim**: Off-the-shelf coding agents (Codex with GPT-5, Claude Code with Sonnet 4.5) that treat text as files in a directory beat published SOTA by 17.3% on average across five long-context benchmarks, at costs comparable to other strong methods but above RAG.
- **Mechanism**: Corpora above 100M tokens are stored as one txt file per document in a folder; single long documents go in one txt file; NQ (3T tokens) is one JSONL file. The agent is given only the path and the query and uses its native tools (rg/grep, sed, nl, Python scripts, intermediate files). Observed behaviors: iterative query refinement for multi-hop retrieval, Python aggregation for counting tasks, hybrid search-then-read for reading comprehension. Folder structure beats single file: agents use `nl` plus `sed` to read line ranges (index and slice) instead of repeated corpus-wide scans. Adding BM25 or Gemini-embedding retrievers does not consistently help and reduces native grep use.
- **Numbers**: Table 1 (Codex no retriever / +Gemini Emb. / +BM25 / Claude Code+BM25): BrowseComp-Plus 88.50 / 84.00 / 78.50 / -; Oolong-Syn 71.75 / 68.03 / 71.07 / -; Oolong-Real 33.73 / 32.40 / 30.86 / 37.46; LongBench 61.50 / 61.50 / 60.80 / 62.50; NQ 56.00 / - / 53.00 / -. Baselines: GPT-5 full context 20.00, 59.22, 22.45, 61.00, 27.00; RAG 65.00, 45.53, 13.38, 50.50, 47.00; ReAct 72.50, 31.39, 19.06, 59.00, 49.00; RLM -, 64.38, 23.07, 54.00, 55.33. Ablation (BrowseComp-Plus, Codex GPT-5): folder 89.0/90.0/82.0 vs single file 83.0/86.0/82.0 (no retriever/Gemini/BM25). Command use, single file vs folder: rg 31.05 vs 18.46 (-40.5%), sed 0.61 vs 4.48 (+634%), nl 0.69 vs 1.22 (+76.8%). Native searches per query: no retriever 14.92, BM25 9.84, Gemini 8.33. Cost per query (Table 5), Codex no retriever: BrowseComp-Plus $0.703, Oolong-Syn $0.194, Oolong-Real $0.419, LongBench $0.128, NQ $0.111. GPT-5 full context: $0.275, $1.421, $0.770, $0.432, $0.129. RAG: $0.111, $0.045, $0.026, $0.024, $0.006. ReAct: $0.237, $0.092, $0.168, $0.056, $0.027. RLM: -, $0.920, $0.094, $0.360, $0.630. Claude Code + BM25: Oolong-Real $0.380, LongBench $0.319. 200 samples per benchmark; Codex v0.46.0.
- **Token-cost implication**: For large corpora, give the agent a navigable directory plus grep/sed rather than stuffing context or defaulting to RAG; line-range reads (nl + sed) keep tokens down. For very long single documents, full context can be several times costlier (e.g. Oolong-Syn $1.421 vs $0.194). RAG remains the cheapest option per query, so choose by accuracy needs.
- **Caveats**: Academic preprint, self-run; 200-example samples with baselines rerun on the same subset. Costs are per-query averages from the authors' setup, not billing plans. RLM excluded from BrowseComp-Plus; Claude Code tested on only two benchmarks for budget. GPT-5 full-context accuracy on large corpora likely reflects contamination. Starred best-published numbers come from full sets. Why retrievers hurt is left as an open question.
