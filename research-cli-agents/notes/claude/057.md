# 057 — Gemini CLI: Quotas and pricing
- **Source**: https://geminicli.com/docs/resources/quota-and-pricing (Gemini CLI, 2026-06)
- **Claim**: Gemini CLI quota depends on auth method: per-user daily request caps for Google-account and Workspace tiers, free-tier caps for API keys, and pay-per-token for API key or Vertex AI.
- **Mechanism**: Limits are counted as model requests per user per day (also limited per minute). Google-account and Workspace plans give fixed-price quotas across the Gemini model family; API key or Vertex AI is pay-as-you-go and uninterrupted. /stats model shows session token usage and quota; a usage summary shows on exit.
- **Numbers**: Max requests/user/day: Code Assist Individual 1,000; Google AI Pro 1,500; Google AI Ultra 2,000; API key free tier 250 (Flash only); Code Assist Standard 1,500; Code Assist Enterprise 2,000; Workspace AI Ultra 2,000. Vertex AI Express: 90 days before billing needed. Pay-as-you-go varies. Banner: Gemini CLI replaced by Antigravity CLI for unpaid and Google One users on June 18, 2026.
- **Token-cost implication**: Quota is per request, not per token, on subscriptions, so fewer, larger, precise prompts are cheaper on pay-as-you-go while many small calls are cheaper on request-quota plans; track with /stats model.
- **Caveats**: Official doc. No per-token prices are given. Page says pay-per-token can cost more for many small calls.
