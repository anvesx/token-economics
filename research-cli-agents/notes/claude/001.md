# 001 — Claude Code Token Usage: Monitor It with an AI Gateway
- **Source**: https://dev.to/kamya_shah_e69d5dd78f831c/claude-code-token-usage-monitor-it-with-an-ai-gateway-kih (dev.to, Kamya Shah, 2026-10)
- **Claim**: Claude Code's native tools (/usage, status line, OpenTelemetry, Console analytics) are per-machine or per-billing-surface and cannot enforce budgets; an AI gateway (Bifrost, by Maxim AI) on the request path gives per-developer attribution, multi-provider coverage and enforcement.
- **Mechanism**: Point `ANTHROPIC_BASE_URL` at Bifrost and set `ANTHROPIC_AUTH_TOKEN` to a per-developer virtual key (managed setting `allowedProviders: ["customEndpoint"]` forces gateway use). Bifrost resolves the key, checks provider/key/team/customer budgets and rate limits before the provider call (HTTP 402 when spent), then logs tokens and cost asynchronously. Outputs: request logs and dashboard, Prometheus metrics (bifrost_input_tokens_total, bifrost_output_tokens_total, bifrost_cost_total, labelled by virtual_key_name, team_name, customer_name, model, provider), OTel GenAI spans. Session affinity via the x-claude-code-session-id header keeps prompt-cache hits; x-bf-lh- headers become log metadata. Budgets reset 1d/1w/1M/1Q/1Y (calendar_aligned in UTC). Enterprise alerting by CEL rules (e.g. budget_usage_percent > 80, evaluated every 60 s). Native: `/usage` (aliases /cost, /stats) estimates cost locally at list price for one session; OTel needs CLAUDE_CODE_ENABLE_TELEMETRY=1 on each machine (claude_code.token.usage, claude_code.cost.usage).
- **Numbers**: Anthropic's Claude Code cost guide (as cited): about $13 per developer per active day, $150-$250 per developer per month, 90% of users below $30 per active day. Agent teams use approximately 7x more tokens than standard sessions when teammates run in plan mode. Example virtual key: $150/month budget, 2,000,000 tokens/hour, 300 requests/min. Bifrost overhead 11 microseconds per request at 5,000 RPS; logging plugin under 0.1 ms; pricing sheet synced every 24 h; 25+ providers, 10,000+ models.
- **Token-cost implication**: Meter and cap spend at a gateway with per-developer virtual keys and budgets sized from a measured pilot baseline; export per-key token and cost metrics to existing dashboards; keep session affinity so caching continues; remember Anthropic dashboards do not cover Bedrock/Vertex/Foundry-billed usage.
- **Caveats**: Vendor content marketing for Bifrost (author's own product, ends with a demo pitch); performance figures are self-reported benchmarks; dollar averages are attributed to Anthropic, not measured here; native cost figures are list-price estimates; the single visible comment is unverified.
