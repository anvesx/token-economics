# 122 — OpenHands Context Condensation for More Efficient AI Agents
- **Source**: https://openhands.dev/blog/openhands-context-condensensation-for-more-efficient-ai-agents (OpenHands, 2025-04-09)
- **Claim**: OpenHands' context condenser summarizes older conversation once context passes a threshold, cutting per-turn API cost up to 2x with equal or better SWE-bench Verified results.
- **Mechanism**: When context reaches a set size, older interactions are summarized (user goals, agent progress, remaining work, plus critical files and failing tests for coding) while recent exchanges are kept intact. Condensation triggers only at the threshold, so prompt-cache hits are preserved and rebuild cost is amortized across many turns. With similar-sized events, baseline cost scales quadratically over time; condensed scales linearly.
- **Numbers**: Up to 2x per-turn API cost reduction; per-turn cost settles at less than half of baseline once condensation kicks in. On a subset of SWE-bench Verified, condensation solves an average 54% of instances vs 53% for baseline. Uses fewer tokens, less money and less time; more turns (extra turns to condense).
- **Token-cost implication**: Bound agent context with threshold-triggered summarization rather than growing history or summarizing every turn; trigger infrequently to keep cache efficiency.
- **Caveats**: Self-reported by OpenHands, on a subset of SWE-bench Verified only; the actual threshold values and instance count are not stated in the text. The cost graphs are not reproduced in the text.
