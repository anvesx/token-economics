# 063 — A Survey of Small Language Models: Architectures, Capabilities, and Deployment Trade-offs
- **Source**: https://arxiv.org/abs/2510.03847 (arXiv, Sharma and Mehta, 2025-10; "Small Language Models for Agentic Systems")
- **Claim**: Small language models (about 1-12B, up to ~20B parameters) with guided decoding and validators can match or beat LLMs on agent workloads (function calling, structured output, RAG, tool use) at much lower token cost. Proposes SLM-default, LLM-fallback architecture with uncertainty-aware routing.
- **Mechanism**: Front-door router with capability registry picks the cheapest competent SLM; output forced through JSON-Schema/CFG constrained decoding (vLLM/Outlines/XGrammar, SGLang, TensorRT-LLM) at temperature 0; validators check schema and tool args; if valid and uncertainty below threshold, execute, else small verifier repair, else escalate to LLM. Telemetry feeds LoRA/QLoRA adapter refresh. Migration: log LLM usage, cluster tasks, fine-tune adapters, quantize (INT4/INT8, AWQ/GPTQ), add routing and validators. Metric: Cost per Successful task (CPS) = total cost / schema-valid, tool-valid completions.
- **Numbers**: Claims 10x-100x lower token cost on APIs (abstract); CPS typically 10-30x lower vs LLM-only; vLLM structured decoding up to ~5x TPOT speedup; FrugalGPT cascades ~98% lower cost near best-LLM accuracy; extraction with 3-9B SLM >99% validity; 10,000-50,000 traces for adapters; keep KV memory at 70-85% VRAM; rollback triggers: schema validity drop >2 pp, ExecRate drop >3 pp, p95 inflation >20%; SLA: interactive p95 <=1.5-2.0 s, batch p95 <=10-30 s. Table II ablation values are marked representative (placeholders).
- **Token-cost implication**: Route routine, structured, tool-calling steps to small models with constrained output and validators; escalate to frontier models only on low confidence; track cost per successful task, not per token.
- **Caveats**: Literature survey with qualitative synthesis, no new experiments; headline cost multiples are not backed by reproducible measurements in the text and the table values are "fill with your measurements"; self-published, not peer-reviewed; says frontier LLMs still win on long-range synthesis and complex repo-wide code repair.
- **Topic**: routing
