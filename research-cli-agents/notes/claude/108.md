# 108 — Diagnosing and Reducing Codex CLI Token Consumption (June 2026 quota)
- **Source**: https://codex.danielvaughan.com/2026/06/10/codex-cli-token-consumption-diagnosis-reduction-quota-drain-practitioner-toolkit (Daniel Vaughan, 2026-06)
- **Claim**: Rapid Codex CLI quota drain since May 2026 was partly a service-side metering anomaly and partly real hidden token costs (MCP schemas, verbose tool output, reasoning tokens, compaction); the post gives a diagnostic toolkit and seven reduction strategies for v0.139.
- **Mechanism**: Overheads: system prompt + AGENTS.md + skills + JSON schemas of every tool each turn; rolling context accumulating tool results; hidden reasoning tokens (medium can double a turn, high/xhigh triple it); auto-compaction at model_auto_compact_token_limit (default 80% of window) that itself costs tokens; per-MCP-server schemas. Diagnostics: TUI status line Context % (over 60% early signals tool/output volume), `/status`, `codex exec --json` token_count events (subtract consecutive for per-turn), ccusage (`npx ccusage@latest codex --period weekly`), tokscale, OpenTelemetry export. Strategies: allowlist tools with `enabled_tools`; fast/deep profiles with different `model_reasoning_effort`; manual `/compact` and lower compact threshold (value above 90% silently ignored); short single-task sessions (5-15 turns); prefer shell over MCP; filter verbose output (`| tail -20`, PostToolUse hooks); `disabled_tools` in code mode.
- **Numbers**: GitHub MCP with 93 tools ~55,000 tokens/turn; 4 MCP servers could add 100,000+ tokens/turn; scoping to 3 tools drops ~55,000 to ~3,000. Scalekit: $55.20/month MCP vs $3.20/month CLI at 10,000 operations (also "$55.20 to under $5" for scoped tools); shell command ~200 tokens/op, MCP 4-32x more. System prompt + AGENTS.md ~2,000-5,000 tokens. Lower reasoning effort medium to low saves 40-60% on routine tasks. Shell output of ls/docker ps/git status 60-90% irrelevant; cargo test 10,000+ tokens. Claimed before/after: median tokens/turn 45,000 to 12,000 (73%); compactions/session 3-5 to 0-1 (80%); routine reasoning tokens 8,000 to 2,500 (69%); monthly API cost (10K ops) $55 to $8 (85%). Quota drain began ~10 May 2026; OpenAI acknowledged 15 May and reset usage. ccusage 12,000+ GitHub stars.
- **Token-cost implication**: Treat agent config as a cost surface: allowlist only needed MCP tools, split fast/deep reasoning profiles, compact proactively, keep sessions short and trim shell output, and measure with ccusage before and after.
- **Caveats**: Single practitioner blog (also sells a book); the before/after table is stated as "based on Scalekit benchmarks and community reports", not a controlled test; the `model_auto_compact_token_limit = 60` example is inconsistent with the "80% of window" default as written; the metering anomaly attribution rests on OpenAI community posts.
