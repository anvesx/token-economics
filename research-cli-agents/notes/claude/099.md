# 099 — Custom instructions with AGENTS.md
- **Source**: https://learn.chatgpt.com/docs/agent-configuration/agents-md.md (OpenAI, no date)
- **Claim**: Codex reads AGENTS.md files before work, layering global and per-directory guidance into one instruction chain, capped by a byte limit.
- **Mechanism**: Built once per run/TUI session. Global: ~/.codex (or CODEX_HOME) AGENTS.override.md else AGENTS.md (first non-empty only). Project: from project root down to cwd, one file per directory (override, then AGENTS.md, then project_doc_fallback_filenames). Files concatenated root-first with blank lines, so closer files override. Empty files skipped; adding stops at project_doc_max_bytes.
- **Numbers**: project_doc_max_bytes default 32 KiB; example raised to 65536. No cost figures.
- **Token-cost implication**: Instruction files are injected into every run's prompt, so they cost tokens each session; keep them concise, put specialized rules in nested directories, and watch the 32 KiB cap, which truncates silently once reached.
- **Caveats**: Official doc, describes behavior only; says nothing about token cost or caching directly (the cost point is inference).
