# 016 — Cursor apologizes for unclear pricing changes that upset users
- **Source**: https://techcrunch.com/2025/07/07/cursor-apologizes-for-unclear-pricing-changes-that-upset-users (TechCrunch, 2025-07-07)
- **Claim**: Cursor's June 16 switch of the $20/month Pro plan from 500 fast requests to $20 of usage billed at API rates caused surprise overages; CEO apologized and promised refunds. The reason: newer models spend more tokens per request on long-horizon tasks.
- **Mechanism**: Old Pro: 500 fast responses on advanced models, then unlimited slower. New Pro: $20 of usage per month at API rates, then users must buy credits; only "auto mode" (routes to models based on capacity) is unlimited. Cursor had been absorbing higher token costs under the old plan and passed them to users.
- **Numbers**: Pro $20/month; old plan 500 fast responses; Ultra plan $200/month with very high rate limits; Claude Opus 4 $15 per 1M input tokens and $75 per 1M output tokens; Cursor over $500 million ARR; Claude Code reportedly lifted Anthropic ARR to $4 billion.
- **Token-cost implication**: Flat-rate seats mask per-token cost; agentic long-horizon tasks consume far more tokens per request, so budget by usage and set spend limits, and expect vendors to move to usage-based pricing.
- **Caveats**: News report; the company declined further comment; ARR and Claude Code figures are reported, not verified here. No per-task token measurement.
- **Topic**: pricing
