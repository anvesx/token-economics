# 090 — Claude Code Docs: Automate actions with hooks (guide)
- **Source**: https://code.claude.com/docs/en/hooks-guide (Anthropic docs; no date given)
- **Claim**: Hooks are deterministic user-defined handlers fired at lifecycle events; the guide's cost-relevant uses are re-injecting context after compaction, blocking unwanted tool calls, and model-based (prompt/agent) hooks that themselves consume model calls.
- **Mechanism**: Hook types: command (shell), http, mcp_tool, prompt (single-turn LLM evaluation, optional `model` field), agent (subagent with tool access, experimental). Events include SessionStart (matcher `compact` to re-inject context after compaction; stdout text is added to context), PreCompact/PostCompact, UserPromptSubmit (additionalContext injection), PreToolUse (exit 2 or `permissionDecision: deny` blocks and feeds the reason back to Claude; most restrictive result wins across parallel hooks: deny, defer, ask, allow), PostToolUse, PostToolBatch, Stop (a prompt hook returning ok:false makes Claude keep working), StopFailure (error types include rate_limit, billing_error, max_output_tokens), InstructionsLoaded, Notification (including quota_auto_resume_* matchers for claude.ai usage-limit pauses). Matching hooks run in parallel. For context on every session start the guide points to CLAUDE.md instead of a hook.
- **Numbers**: Default timeouts: command/http/mcp_tool 10 minutes (30 s for UserPromptSubmit, PreModelSwitch, PostModelSwitch; 10 s for MessageDisplay); prompt 30 s; agent 60 s with up to 50 tool-use turns; SessionEnd 1.5 s (up to 60 s if configured). Notification timings: permission_prompt after about six seconds; idle_prompt about 60 seconds. Version gates: quota_auto_resume matchers v2.1.234+, auth_storage_failure v2.1.288+. No dollar or token figures.
- **Token-cost implication**: Command hooks cost no model tokens, so enforce rules (formatting, protected paths, command blocking) with them instead of prompting. Prompt hooks add one extra model call per fire, and agent hooks up to 50 tool turns each, so a Stop-time agent hook that runs tests multiplies cost per turn. Post-compaction re-injection restores lost conventions without keeping them in every prompt, but injected text is context tokens on every compaction.
- **Caveats**: Mostly configuration how-to; no cost measurements, and the token-cost points are inferences. Agent hooks are explicitly experimental. Rest of the file is page-rendering config.
- **Topic**: context
