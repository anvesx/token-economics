# 037 — How I Cut Aider's Token Bill 80%: Prompt Caching, MCP Code Mode, and Tier Routing
- **Source**: https://dev.to/lynkr/run-aider-on-ollama-bedrock-or-any-llm-provider-one-gateway-every-model-3jm4 (dev.to, Harjot Rana / Lynkr, 2026-05)
- **Claim**: Running Aider through the author's self-hosted Lynkr gateway with auto-injected prompt-cache breakpoints, MCP "code mode" and complexity-based tier routing cut a typical session from about $8 to under $1.50.
- **Mechanism**: Lynkr is an OpenAI-compatible proxy (Aider points OPENAI_API_BASE at it). It injects `cache_control: ephemeral` breakpoints on repo-map/file blocks for upstreams that support caching; exposes MCP tools as a TypeScript API so the model writes one program (run in sandbox) instead of N tool-call round trips; scores prompt complexity (`--model lynkr-auto`) and routes to tiers: local Ollama qwen2.5-coder:7b for commit messages/repo-map summaries, Haiku 4.5 for small edits, Sonnet 4.5 default, Opus 4.5/GPT-5 for hardest work. Cache only hits when prefix is byte-identical.
- **Numbers**: Token share in an Aider session (author estimate): repo map ~50-60%, added files ~20-30%, new diff/instruction ~5-10%, commits/summaries ~5%. Cached input costs 10% of fresh on Anthropic, 25% on Bedrock, free for 5 minutes on Gemini. Caching alone about 70% input cut; tier routing another about 40%; code mode 5-15x on tool plumbing; session $8 to under $1.50 (200k-LOC monorepo, author's own workflow). Example tool-call mode: 18 round trips (5 search + 12 read + 1 grep). Aider polyglot (as quoted): Opus 4.5 89.4%, GPT-5 high 88.0%, Gemini 2.5 Pro 83.1%, Sonnet 4.5 82.4%, Haiku 4.5 73.5%, GPT-4o 72.9%, DeepSeek V3.2 Reasoner 74.2%; Copilot cost ratios Opus 4.5 3x, Sonnet 1x, Haiku 0.33x. Hit rate below 60% signals prefix busting.
- **Token-cost implication**: Most agent spend is the re-sent static prefix; cache it and keep it stable, route routine calls to cheap/local models, and batch tool calls into code execution.
- **Caveats**: Single author, builds the product being promoted (disclosed); self-reported on one workflow; headline 80% vs stated figures not reproduced; leaderboard figures quoted, not verified; the "~40%" and "5-15x" are unsupported estimates.
