# 129 — AI Agent Cost Per Task [2026]: Token Budgets and Break-Even Math
- **Source**: https://www.kunalganglani.com/blog/ai-agent-cost-per-task-2026 (Kunal Ganglani, published 2026-07-14, last reviewed 2026-10-31)
- **Claim**: Coding-agent cost per task ranges from $0.03 to $0.13 on benchmarks but $1.60-2.60 in real Claude Code usage because most spend is context overhead; the post gives per-task tables, team burn rates, a local-vs-API break-even, and budget guidance.
- **Mechanism**: Cost per task = input + output + overhead tokens; tokens are dominated by repo map (2,000-8,000 input tokens for 500-2,000 files), file loads (3,000-15,000), system prompt + CLAUDE.md (1,500-4,000 per turn), reasoning (2,000-10,000 output tokens on GPT-5 high), code generation (200-2,000, often only 5-15% of tokens), and retries that re-send full context (two retries can triple cost). Conversation history accumulates: a 10-turn session with 4,000-token prompt and 8,000 repo tokens sends 120,000+ input tokens on call 10. Mitigations: Anthropic cache_control (TTL 5 min standard, 1 hour extended; ~10% price on cached tokens), hybrid cheap planner + frontier executor, model tiering, token budgets. Local break-even: (amortized GPU + electricity) / tokens per month vs API price.
- **Numbers**: Aider polyglot (225 exercises): GPT-5 high $29.08, $0.129/task, 88% pass, $0.147 per solved; Claude Sonnet 5 ~$12-15 (~$0.053-0.067, 85-90% pass, estimated); Gemini 2.5 Pro $6.32, $0.028, 72%, $0.039; DeepSeek R1 + Sonnet $13.29, ~$0.059, 64%, ~$0.092 (Jan 2025, 14x cheaper than o1 alone). Claude Code enterprise ~$13/developer/active day, $150-250/month, 90% under $30/day; implies $1.60-2.60 per task at 5-8 tasks/day. 10 devs x 20 PRs x 4 tasks = 800 tasks/month: GPT-5 high $103/mo, Sonnet 5 API $48, Gemini 2.5 Pro $22, Claude Code subscription $1,500-2,500 ($18,000-30,000/yr); with a 3-5x realism multiplier, Gemini $66-110/mo, Sonnet $144-240, GPT-5 $310-515. Local LLM break-even ~5-10M tokens/month (RTX 4070 $550 over 36 months ~$15/mo + $8 electricity: $4.60-11.50 per M tokens; RTX 4090 $1,600 ~$44/mo + $15 at 20M tokens: ~$2.95/M). Caching: 10-turn session with 80% cacheable tokens costs roughly 30-40% of uncached; typical 50-70% total reduction, near 80% over 15+ turns (assertions). Claimed: planning tokens 5-20x cheaper and planning cuts execution retries 40-60%; per-token prices down 60-80% YoY; Claude Code vs OpenCode overhead gap 4.7x (separate post); untracked teams overspend 30-50%. Suggested daily budget: 2x expected average.
- **Token-cost implication**: Measure cost per solved task, not per call; enable prompt caching; keep repo maps and history small; use cheap models for planning/simple edits and frontier models for hard multi-file work; set per-developer daily limits (start from $30/day, tune after two weeks of data).
- **Caveats**: Single-author blog with consulting and tool plugs; mixes Aider benchmark data (clean prompts, some from Jan 2025) with Anthropic's averages and the author's own estimates; Sonnet 5 row is approximate; the Claude Code comparison versus API-direct ignores that subscription and API are different products; several predictions (subscriptions win for 5-20 devs) are opinion; the page contradicts itself in the summary ($0.03-$2.60 vs $0.03-$0.13).
