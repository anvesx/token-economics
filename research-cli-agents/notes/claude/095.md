# 095 — Choose a permission mode (Claude Code docs)
- **Source**: https://code.claude.com/docs/en/permission-modes (Anthropic docs, no date)
- **Claim**: Auto mode replaces human permission prompts with a separate classifier model. On API-billed accounts those classifier calls count toward token usage and add a round-trip before execution.
- **Mechanism**: Modes: default (Manual), acceptEdits, plan, auto, dontAsk, bypassPermissions. In auto mode, allow/ask/deny rules resolve first; read-only actions and working-directory edits are auto-approved without the classifier; everything else (mainly shell commands, network operations) goes to the classifier. Each check sends a portion of the transcript plus the pending action. Classifier sees user messages, non-read tool calls and CLAUDE.md, with tool results stripped. It also reviews subagent work at spawn, per action, and on completion, and reviews SendMessage between agents. Default classifier model is Claude Sonnet 5, overridable with CLAUDE_CODE_AUTO_MODE_MODEL (v2.1.302+), so it can run on a cheaper or different model than the session model. Where server-side review is enabled, verdicts come with the session's model requests and there are no separate classifier calls to count. Sandboxed network access adds no per-connection classifier calls (one review covers command and hosts). If the server does not review, Claude Code falls back to its own classifier requests and shows a notice about classifier request charges on billed accounts.
- **Numbers**: Auto pauses and resumes prompting after 3 blocks in a row or 20 total (not configurable). Auto is the built-in starting mode from Claude Code v2.1.283 on interactive terminal and VS Code. No dollar or token figures.
- **Token-cost implication**: Classifier calls count toward token usage on Enterprise, Claude API, Bedrock, Vertex-style and Foundry accounts, so a shell-command-heavy auto session pays extra tokens plus latency per command, while read/edit-heavy work pays almost none. Pointing the classifier at a cheaper model cuts that overhead. Plan mode lets Claude research without edits; cost effect is an inference. Subagent-heavy runs multiply classifier reviews.
- **Caveats**: Document gives no magnitude for classifier overhead. Subscription (Pro/Max/Team) billing treatment is not stated beyond the list of accounts where calls count. Most of the page is permission semantics, not cost.
- **Topic**: agent-cost
