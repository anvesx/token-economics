# 019 — How MCP Tool Definitions Inflate Your AI Agent Token Costs
- **Source**: https://docs.bswen.com/blog/2026-04-24-mcp-token-overhead (bswen, 2026-04-24)
- **Claim**: MCP servers inject all tool schemas into context every turn, consuming thousands to tens of thousands of tokens before any prompt; the author measures this and compares four mitigations.
- **Mechanism**: Every turn carries tool name, description, JSON-schema parameters and output specs for all connected tools. Mitigations: (1) Claude Code tool deferral/search, auto-on when schemas exceed a threshold (default 10% of context), loading tools on demand; (2) code-execution mode (Anthropic approach) where the agent writes code that discovers tools; (3) mcp2cli, where `--list` shows names (~16 tokens/tool) and `--help` fetches a schema (~120 tokens) only when needed; (4) a workflow layer (e.g. LangGraph) routing structured agent output to tools so the agent never sees them. Use `/context` to measure.
- **Numbers**: Four MCP servers = 7,000 tokens before first prompt; a colleague's heavy config = 66,000 tokens (nearly a third of a 200k window). Per server: Playwright 22 tools ~3,442; Gmail 7 tools ~2,640; Jira ~17,000; mcp-omnisearch 20 tools ~14,100; GitHub MCP ~8,000-12,000; Codex 2 tools 610; SQLite row reads "SQLite638564" in source (garbled; likely 6 tools, 385 tokens, 64 per tool). gmail_create_draft alone 820 tokens; Playwright screenshot 370 vs close browser 59. Cumulative: 30 tools x 15 turns 54,450; 80 x 20 193,240; 120 x 25 362,350; 200 endpoints x 25 358,425. At $3/MTok input (Sonnet 4.6): 100 tools x 20 turns x 1,000 daily conversations = 242M tokens/day, about $21,000/month. Deferral saved 13.2k tokens in a typical session. Anthropic code execution reported up to 98.7% context reduction. mcp2cli: 96% (30 tools/15 turns, 54,525 to 2,309), 98% (80/20, 193,240 to 3,871), 99% (120/25, 362,350 to 5,181).
- **Token-cost implication**: Disconnect unused MCP servers, audit complex nested schemas, measure with `/context`, and use deferral, code execution or CLI-style discovery once tools exceed about 20 and sessions run over about 10-15 turns. Native MCP is fine under 20 simple tools.
- **Caveats**: Single-author blog; measurements are the author's own and the mcp2cli savings are self-reported by a different tool's author as cited; the cost projection ignores prompt caching, which would cut repeated schema cost; the SQLite row is garbled in the source.
