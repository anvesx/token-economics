# 096 — Codex Pricing
- **Source**: https://developers.openai.com/codex/pricing (OpenAI, no date; mentions GPT-5.5 retiring Oct 14, 2026 and GPT-5.6 Sol promo through at least Nov 21, 2026)
- **Claim**: Codex and ChatGPT Work share plan usage, credits and limits; plans run Free to Enterprise, extra usage is bought as credits, and credit-per-million-token rates differ widely by model. API-key use is billed at API prices separately.
- **Mechanism**: Local messages per five-hour window are estimates (not fixed limits), plus weekly limits; Pro has no five-hour limit. After limits, Plus/Pro buy credits; Business/Enterprise with flexible pricing buy workspace credits; or run extra local chats on an API key. Credit billing has no cache-write charge. Fast and Ultrafast modes multiply usage. Voice in Desktop uses plan budget. Tips: trim prompts, narrow sources, nested/smaller AGENTS.md, fewer MCP servers, smaller model, check /status and the dashboard.
- **Numbers**: Plans: Free $0, Go $8/mo, Plus $20/mo, Pro from $100/mo ($100, $200, $500), Business $20/user/mo annual ($25 monthly, 2+ users), Enterprise/Edu custom. Local messages per 5 hours (Plus / Standard Business): GPT-6 Astra 5-45, GPT-6.1 Sol 15-160, GPT-6.1 Terra 35-285, GPT-6 Sol 15-150, GPT-6 Luna 350-3,000. Credits per 1M tokens (input / cached / output): GPT-6 Astra 250/25/1,250; GPT-6.1 Sol 50/2.5/250; GPT-6.1 Terra 25/1.25/125; GPT-6 Sol 50/5/250; GPT-6 Luna 2.5/0.25/12.5; GPT-5.6 Sol 100/10/500; GPT-5.6 Terra 50/5/300; GPT-5.6 Luna 5/0.5/30; Daybreak Red 312.5/31.25/1,875; GPT-Image-2 (image) 200/50/750. Speed multipliers (included usage / purchased credits): Fast 2.5x / 2x; Astra Ultrafast and Sol Ultrafast 8x / 6x. Voice $0.05/min (1.25 credits/min on credit plans). Image generation uses included limits 3-5x faster. Typical GPT-5.6 Sol task 2-15 credits. No long-context surcharge for GPT-6.1 Sol on subscription.
- **Token-cost implication**: Cached input is ~1/20 to 1/10 of input credit rates, so keep prefixes stable; pick Luna/Terra for routine work, avoid Fast/Ultrafast unless needed, and do not estimate subscription usage from API token prices.
- **Caveats**: Vendor pricing page; message counts are estimates with wide ranges; model names are as listed in the source and not verified; some features limited by region; enterprise legacy rate card differs.
