# 054 — The Coding Agent Economy
- **Source**: https://www.requesty.ai/coding-agent-economy (Requesty, Thibault Jaigu, 2026-04; abstract dated May 2026)
- **Claim**: Twelve months of Requesty gateway data (May 2025-April 2026, nine coding agents) show per-user cost up 3.8x while per-call cost stayed flat because prompt-cache hit rates rose from 52% to 86%; Claude models take 92% of spend.
- **Mechanism**: Observational analysis of anonymized monthly aggregates (averages, medians, percentiles, ratios) per API routing key. Cost growth is attributed to more calls per user and larger context, offset by caching. "Active user" = at least two distinct active days in a month. Cache hit = cached_tokens / input_tokens. Agents identified via request headers/origin metadata.
- **Numbers**: Avg cost per user $14 to $54/month (3.8x); active users $92/month; Claude Code active mean $108, median $23, P95 $291 (all-users mean $78). Other agents (all mean / active mean / median / P95): Roo Code $46/$79/$25/$333; Kilo Code $65/$107/$5/$268; Cline $25/$50/$17/$205; OpenCode $58/$104/$15/$473. Avg input tokens per call rose from ~50,000 to nearly 200,000 (4x) per the text; Claude Code 1,549 API calls/month; Cline 214. Cache hit (April 2026): Claude Code 92% (avg input 84K tokens/call, $0.050/call); OpenCode 89% ($0.061); Aider 84% ($0.009); Zed 80% ($0.083); Roo 74% ($0.105); Forge 64% ($0.107); Cline 61% ($0.121); Kilo 46% ($0.065). Platform cache hit 52% to 86%, input about 7x cheaper than list. Effective input rate at 92% hit about $0.30/M vs $3.00 list (Sonnet); at 46% about $1.62/M (5.4x gap). Claude share of spend 68% (May 2025), 95% (Dec 2025), 92% (Apr 2026); Gemini share fell from 34% to under 6%. Error rates: Aider 0.9%, Roo 2.5%, OpenCode 3.1%, Zed 3.7%, Cline 4.9%, Claude Code 7.0%, Kilo 10%, Forge 11%. Claude Code latency: Anthropic 4.6s median/98.5% success; Bedrock 4.9s/96.0%; Vertex 4.0s/92.8%. Tool-call finish share: Roo 91%, OpenCode 87%, Claude Code 73%, Cline 16%, Aider 12%.
- **Token-cost implication**: Cache hit rate is the dominant lever: keep a stable prompt prefix across sequential calls; budget per user around heavy-tail P95 rather than the mean; expect cost growth from call volume, not call price.
- **Caveats**: Vendor-run gateway data with selection bias (Cursor and Copilot largely bypass gateways); no absolute user counts or spend disclosed; Claude Code only present from Aug 2025; internal inconsistency on Claude Code input size (84K per call in chart vs "exceeds 200,000" in text); the Claude-dominance explanations are hypotheses; Anthropic reports zero reasoning tokens, so reasoning cost is not comparable.
