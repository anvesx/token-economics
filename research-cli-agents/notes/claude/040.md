# 040 — How to Manage the Aider Context Window and Token Budgets
- **Source**: https://about.fast.io/resources/aider-context-window (Fast.io, 2026-11)
- **Claim**: Aider has no internal token ceiling; its context is split into system prompt, repo map, chat history and added files, and disciplined use of /add, /drop, /clear and a capped repo map (plus offloading docs to an indexed MCP workspace) keeps token use and latency down.
- **Mechanism**: Four layers share one window: system/edit-format instructions (1,000 to 2,500 tokens per request), Tree-sitter repo map ranked by a PageRank-style graph over files/symbols (budget `--map-tokens`, default 1k, 0 disables; doubled via `--map-multiplier-no-files` when no files added; `--map-refresh auto|always|files|manual`), chat history (soft cap `--max-chat-history-tokens` triggers summarization), and full text of /add'ed files. /read costs the same tokens as /add (only editability differs). /drop returns a file to the map; /clear wipes history; /reset drops all; /tokens shows the breakdown. Diff edit format avoids output-limit truncation. Architect mode splits planner and editor models. Remote MCP retrieval (Fastio, promoted product) returns snippets instead of whole docs.
- **Numbers**: Context ceilings: claude-3-5-sonnet-20241022 200,000 (output 8,192); claude-3-7-sonnet-20250219 200,000 (output 64,000); gpt-4o 128,000 (output 4,096); deepseek-chat 64,000 (output 8,192); qwen2.5-coder:32b 32,768 to 128,000 (output 4,096). Recommended 2 to 4 editable files; `--max-chat-history-tokens 2048` example. Unrecognized model: Aider assumes unlimited context and zero cost. Fastio plans: $9.99/mo (100,000 AI credits), $49.99 (600,000), $199.99 (3,000,000). No measured savings percentages.
- **Token-cost implication**: In long Aider sessions, history and added files are re-sent every turn: drop finished files, clear transcripts at milestones, never /read large docs, and keep unknown-model cost tracking from silently reporting $0.
- **Caveats**: Vendor marketing blog (sells the workspace it recommends); model list is dated (claude 3.5/3.7, gpt-4o); no benchmarks or cost measurements; "context rot" claims are general, not measured here.
