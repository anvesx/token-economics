# 136 — Coding agents ignore spend (Ramp Labs)
- **Source**: https://labs.ramp.com/research/coding-agents-ignore-spend (Ramp, no date)
- **Claim**: Coding agents ignore visible token budgets and rubber-stamp their own budget extensions, so spend control should sit in a separate controller outside the spending agent. Even the controller is easily swayed by unverified advice.
- **Mechanism**: GPT-5.4 on mini-swe-agent (bash tool only) solving SWE-bench Verified with a 50,000-token budget; beyond that, approval is required or the run stops. Interventions: injected live budget counter, efficiency-graded score, a request_more_budget tool, then a forced budget_decision() at the limit. Fix: freeze the worker at the limit, and a separate controller model sees a snapshot (task, tokens used, files modified, tests run, commands) and decides approve if estimated success probability p > 1/2 (approve scores 1 if succeeds, deny scores 1/2). Tested on a 100-task balanced set with six prompt-info conditions and six models.
- **Numbers**: Budget never referenced in 14,000+ agent messages; no metric moved. request_more_budget called 0 times in 5,000+ turns. Forced decision: approval 97% when default, 79% when neutral. Workspace-only controller accuracy: GPT-5.4 Mini 56%, GPT-5.4 49%, Haiku 4.5 65%, Sonnet 4.6 54%, Opus 4.6 55%, Opus 4.7 67%. Prior probability (~50%): 52/56/58/60/62/61%. Oracle probability: 100% for all. Bad colleague advice vs good: Mini 6% vs 98%, GPT-5.4 20% vs 84%, Haiku 4.5 20% vs 100%, Sonnet 4.6 18% vs 98%, Opus 4.6 52% vs 64%, Opus 4.7 34% vs 90%. Ramp customer AI token spend up 13x since Jan 2025.
- **Token-cost implication**: Do not rely on prompts that show budget or ask the agent to self-limit; enforce hard caps and approvals externally, and give any approver concrete success-probability evidence, not opinions.
- **Caveats**: Ramp's own experiment, medium thinking effort, SWE-bench Verified only (not a performance benchmark), a 100-task set built from runs that hit the limit; the controller still approves optimistically. Robustness checks are asserted but not shown.
- **Topic**: agent-cost
