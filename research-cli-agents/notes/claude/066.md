# 066 — Memory & context management with Claude (cookbook)
- **Source**: https://platform.claude.com/cookbook/tool-use-memory-cookbook (Anthropic, Claude Cookbook; page dated 2025-06, content references 2026 models)
- **Claim**: Combining the client-side memory tool with server-side context editing lets long-running agents carry learned patterns across sessions while old tool results and thinking blocks are cleared to keep context small.
- **Mechanism**: Memory tool (memory_20250818) is client-side with commands view/create/str_replace/insert/delete/rename under /memories; Claude checks memory first, writes patterns after. Context editing (beta header context-management-2025-06-27) has two strategies: clear_tool_uses_20250919 (trigger on input_tokens, keep last N tool uses, clear_at_least) and clear_thinking_20251015 (keep last N thinking turns; requires thinking enabled, adaptive on current models; must be listed first; "keep: all" preserves thinking blocks for maximum cache hits). Memory files survive clearing.
- **Numbers**: Demo thresholds are low (trigger 5,000 input tokens, keep 2 tool uses, clear_at_least 2,000). Observed: input 6,611 -> 7,923 -> 9,052 tokens; clearing saved 166 and 265 thinking tokens. Production guidance: trigger at 30-40k tokens (example 35,000, keep 5), clear_at_least 3,000-5,000 for large tool results. Context window stated as 1M tokens on all current Claude models. Demo memory file was 318 bytes.
- **Token-cost implication**: Clear stale tool results and old thinking at a token trigger instead of resending them each turn; store distilled patterns in small memory files and read just in time. Clearing changes the prefix and can invalidate the prompt cache, hence the note to keep thinking for cache hits.
- **Caveats**: Beta feature; demo is a toy (three short code files) and savings shown are tiny; no dollar figures; claims attention cost "scales quadratically"; memory poisoning and path traversal are real risks (memory is read back into context); the "faster" Session 2 claim is not measured.
- **Topic**: context
