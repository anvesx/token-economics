# 119 — Cursor Models & Pricing
- **Source**: https://cursor.com/docs/models (Cursor docs, date not given; refers to GPT-5.6 / Claude 5.5-era models)
- **Claim**: Cursor now sells plans as part of "The X Subscription" with a weekly usage pool for Cursor models; third-party models (Claude, GPT, Gemini) are charged at API list price from prepaid credit; Teams/Enterprise add a per-token Cursor Token Rate.
- **Mechanism**: Paid plans include one weekly-refreshing pool shared across Agent, CLI, Cloud Agents, Grok Bot and Grok apps for Cursor models (Grok 4.7/4.6/4.5, Composer 2.5). Past the pool: wait, spend prepaid credit (top-ups/Auto Top-up, with monthly cap), or upgrade; no quality downgrade. Auto has Cost mode (draws from pool), plus Balance and Intelligence (Teams/Enterprise, via Cursor Router, billed at the routed model's list price). Cursor Token Rate applies to input, output and cached tokens of eligible third-party models, except models with cache-read price strictly below $0.10/1M across all tiers, Cursor models, and Cost mode. Legacy plans keep two monthly pools; Max Mode (legacy) = API rate +20%.
- **Numbers**: Plans: Free $0; Plus $8/mo (base); Premium $30 (4x Plus); Super $100 (15x); Ultra $200 (50x); Teams $30/$100/$200 per seat. Annual: $80/$300/$1,000/$2,000. Cursor Token Rate $0.25 per 1M tokens (Teams/Enterprise). Data residency +10%. Prices per 1M tokens (input/cache write/cache read/output): Claude Fable 5.1 $10/$12.5/$0.25/$50; Opus 5.5 $4/$5/$0.2/$20; Sonnet 5.5 $2/$2.5/$0.1/$10; Haiku 5.5 $0.1/$0.125/$0.01/$0.5; GPT-5.6 Sol $4/$5/$0.4/$20; Terra $2/$2.5/$0.2/$12; Luna $0.2/$0.25/$0.02/$1.2; Gemini 3.1 Pro $2/-/$0.2/$12; Gemini 3.8 Flash $0.75/-/$0.075/$3.75; Gemini 4 Argon $2/-/$0.1/$10; Muse Wonder $4/-/$0.2/$20; Grok 4.7 $2/-/$0.5/$6 (Fast $4/-/$1/$12); Composer 2.5 $0.5/-/$0.2/$2.5 (Fast $3/-/$0.5/$15).
- **Token-cost implication**: Cached reads are 1/10 to 1/20 of input price across models, so cache-friendly agent loops dominate cost; Cursor passes list prices through, so choosing Haiku 5.5/Luna-class vs Fable-class models changes cost by up to 100x on input. Teams pay an extra $0.25/M on top, which can matter for cheap models only if cache read >= $0.10.
- **Caveats**: Vendor docs; the weekly pool size is stated only as multiples of Plus, not tokens; table dashes mean no cache-write price listed.
