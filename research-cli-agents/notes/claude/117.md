# 117 — Understanding and managing requests in Copilot
- **Source**: https://docs.github.com/en/enterprise-cloud@latest/copilot/concepts/copilot-billing/understanding-and-managing-requests-in-copilot (GitHub, date not given)
- **Claim**: Legacy GitHub Copilot billing meters "premium requests" per user prompt, scaled by a per-model multiplier. The page applies only to Pro/Pro+ annual-plan subscribers who stayed on legacy request-based billing after June 1, 2026.
- **Mechanism**: One premium request per user prompt (chat ask/edit/agent/plan modes, Copilot CLI, Spaces) times the model's multiplier. For agentic features only prompts you send count; autonomous tool calls do not (e.g. /plan in Copilot CLI = 1, each follow-up = 1). Cloud agent counts one per session (plus one per real-time steering comment), times multiplier. Code review is a flat 13 premium requests per review from June 1, 2026. Counters reset 1st of month 00:00 UTC; unused requests do not carry over. After exhausting the allowance, included models continue (subject to rate limiting); extra requests are purchasable or capped by a budget.
- **Numbers**: Copilot Pro $10/month, 300 premium requests/month; Pro+ $39/month, 1500/month; extra requests $0.04 each; code review multiplier 13; billing for premium requests began 2025-06-18 (github.com) and 2025-08-01 (GHE.com); dedicated SKUs for Spark and cloud agent from 2025-11-01. The model-multiplier table itself is not in the text (page ends at "See Model multipliers").
- **Token-cost implication**: Under per-prompt billing, cost is decoupled from tokens consumed: long autonomous agent runs cost the same as one prompt, so batch work into fewer, larger prompts and steer less often; avoid heavy-multiplier models and code review for trivial changes (13x).
- **Caveats**: Vendor documentation; legacy plan only; text truncated before the multiplier table; says included-model fallback "is subject to change".
