# 031 — Response-Level Speculative Decoding for Cost-Efficient LLM API Serving (RLM-Cascade)
- **Source**: https://arxiv.org/abs/2606.22840 (arXiv, PayPal authors Wu, Manoharan, Tu, Zhao, Wan, 2026-06-22)
- **Claim**: A proxy that has a cheap draft model (DeepSeek-V4-Pro) answer simple turns itself and have Opus accept/enhance drafts on complex turns cut API cost 45.8% (all-time service bench, 125 requests) vs direct Opus on Claude Code traffic, while lowering p50 latency and matching quality on a 20-task benchmark.
- **Mechanism**: FastAPI proxy set via ANTHROPIC_BASE_URL (Anthropic wire format, no client change). Rule-based O(1) router: requests with non-empty `tools` go straight to Opus (draft models break tool-use JSON schema); simple prefixes ("what is", "summarize") are SKIPPED (DeepSeek only, ~2% of Opus cost); complex keywords (class, security, sql) or input over 1,500 chars go Draft+Verify: DeepSeek drafts, Opus sees the request plus draft and replies USE_DRAFT (ACCEPTED, ~20% of cost, ~5 output tokens) or ENHANCE with a rewrite (~115% of cost). Verify prompt defaults to approving unless a genuine error. Fallbacks: draft failure goes to Opus; verify failure returns the draft. Langfuse traces, Prometheus metrics, dashboard. 70-80% of Claude Code turns are tool-selection, so the pipeline reaches only the 20-30% text turns.
- **Numbers**: Prices per 1M tokens: DeepSeek-V4-Pro $1.74 in / $3.48 out; claude-opus-4-8 $5.50 in / $27.50 out. Draft-use rate 88.8% (112/125). Savings: current run (N=12) 32.0% ($0.047 vs $0.069); all-time 45.8% ($1.155 vs $2.130); architecture all-time 47.4% ($0.943 vs $1.791) (abstract/conclusion also cite 47.4%). Verdict mix SKIPPED 64-70%. Latency (20 tasks): avg 2,520 ms vs 4,159 ms; p50 2,026 vs 3,698 ms (1.83x); TTFT 2,520 vs 1,213 ms (2.1x slower). Quality 20 tasks: Speculate 100% (10 code, 5 math, 5 instruct) vs Native Opus 95% (instruct 80%); local 4-bit 7B 10%. Break-even SKIPPED rate 13.3%. Model predicted 67.2% savings vs 47.4% empirical. One cost inversion (mteb-retrieve: $0.01401 vs $0.00212). Claimed $2,000-$3,000/month at 100 requests/day (47% on ~30% of turns). 5 of 6 ENHANCED tasks had positive savings.
- **Token-cost implication**: Route by turn type: keep tool-call turns on the strong model, send trivially simple text turns to a cheap model, and use "approve or fix" verification so the expensive model emits few output tokens (output is 8x pricier on Opus). Router precision (not enhancement quality) drives savings.
- **Caveats**: Self-reported by the deploying company; small samples (125 production requests, 20-task benchmark, N=12 run); binary pass/fail quality; keyword router is crude; latency gain is an artifact of skipping Opus; TTFT worse; two-provider failure modes; "SKIPPED" turns are unverified so false negatives risk quality (bounded only by a 30% extended-suite ENHANCED rate). The 100% vs 95% claim rests on one task difference.
- **Topic**: routing
