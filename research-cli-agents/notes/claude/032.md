# 032 — Agentic Model Routing for Coding Tasks
- **Source**: https://arxiv.org/abs/2606.22902 (arXiv; NUS, Alibaba DAMO and others, 2026-06; "Agent-as-a-Router")
- **Claim**: No single LLM dominates all coding tasks, and routers are limited by missing information rather than reasoning. A router that accumulates execution-verified experience (ACRouter) beats static routers and costs less than always using Claude Opus 4.6.
- **Mechanism**: Routing is a Context-Action-Feedback loop (contextual-bandit style). ACRouter has an Orchestrator (LLM policy with memory-kNN ensemble), a Verifier, and a Memory that logs chosen model, performance, cost and verification result. Reward = e1*score + e2*cost (e1>0, e2<0; reported regret uses e1,e2 = 1,-0.1). Evaluated on CodeRouterBench (~10K tasks, 8 LLMs, execution-verified) via cumulative regret vs the per-task oracle. A fine-tuned Qwen3.5-0.8B is the cheap local router baseline.
- **Numbers**: Vanilla LLM router (Claude Sonnet 4.6, 2,919 tasks) 41.41 AvgPerf; +per-dimension perf stats 47.74 (+15.3% relative); best heuristic with same stats 47.50. ID test (n=2,919): ACRouter 49.98% AvgPerf, cumulative regret 205.5, beats DimensionBest by 2.48%; Perf/$ 3.79 vs Always-Opus 1.29. OOD agentic: ACRouter 62.50%, Always-Opus 57.14%, fine-tuned Qwen3.5-0.8B 55.36%, Random 31.25%; Perf/$ 1.18 vs Opus 0.64; lightweight static classifiers drop to 8.93-21.43% OOD; bandits LinUCB/LinTS 49.82%/46.43% OOD. Regret: static classifiers 284-317, bandits 297-307. Opus 4.6 about 12x total cost of Kimi-K2.5 over 7,080 probing tasks. Best-model examples: Opus 4.6 highest average 42.9%; GLM-5 47.2% vs 25.4% on algorithm design; Qwen3-Max 82.7% vs 39.2% on test generation. Pricing used, USD per 1M tokens input/output: Opus 4.6 5.00/25.00; Sonnet 4.6 3.00/15.00; GPT-5.4 2.50/15.00; Qwen3-Max 1.20/6.00; GLM-5 0.88/3.22; Kimi-K2.5 0.60/3.07; Qwen3.5-Plus 0.40/2.40; MiniMax-M2.7 0.30/1.20. Local router tokens priced at $0.054/M (H100 at $6.88/GPU-hour; 35,094 tokens/s measured).
- **Token-cost implication**: Route per task across tiers instead of one premium model, feed the router per-dimension performance stats, and keep learning from verified outcomes. Static classifiers look good in-distribution but fail on new agentic tasks, so do not rely on them alone.
- **Caveats**: Authors' own benchmark. Provider cache hit rates not observable, so dollar costs are secondary estimates from public prices and measured tokens. Agentic eval uses a 40-step limit instead of 250. ACRouter pays extra cost for Memory and Verifier. Small OOD set (percentages like 62.50, 57.14 suggest small n; n not stated here).
