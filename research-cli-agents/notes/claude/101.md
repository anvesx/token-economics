# 101 — ChatGPT Work: usage and cost
- **Source**: https://learn.chatgpt.com/docs/enterprise/chatgpt-work-usage-and-cost.md (OpenAI, no date)
- **Claim**: For credit-based Enterprise agreements, ChatGPT Work activity draws from a shared workspace credit pool; whether it creates new invoice charges depends on remaining credits, contracted rates and overage settings.
- **Mechanism**: Consumption varies by model, execution environment, reasoning/speed settings (Fast Mode can use more credits), task complexity, tools and frequency. If credits run out: overage permitted means usage continues up to the workspace overage limit at the contracted overage rate; not permitted means features pause. Controls: Work access, model/speed defaults, user usage limits (individual override beats group; highest group limit applies; unset group limit is not zero), workspace overage limit (zero blocks overage; "No limit" is not a zero-spend cap), alerts (notify only, do not stop spend), credit/usage reports. USD-billed workspaces use a separate rate card, not credits.
- **Numbers**: Marketing example, annualized from one week of first-time adopter usage: median ~$53, average ~$309, 90th percentile ~$1,154 per employee per year. 100 employees x $309 is ~$30,900/yr or $2,575/month as planning equivalent.
- **Token-cost implication**: Pilot with a limited group, set per-user limits and a workspace overage cap (alerts alone will not stop spend), compare combined Chat plus Work usage to baseline, and tie consumption to workflow outcomes.
- **Caveats**: Vendor doc; estimates are not prices or guaranteed invoices; the median/average gap shows heavy-tail users; one function (Marketing), one week annualized; model mix unspecified.
- **Topic**: limits-billing
