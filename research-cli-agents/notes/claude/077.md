# 077 — How Claude remembers your project
- **Source**: https://code.claude.com/docs/en/memory (Anthropic, no date)
- **Claim**: Claude Code starts each session with a fresh context window and carries knowledge via CLAUDE.md files (written by you) and auto memory (written by Claude). Both are loaded into context, so their size is a per-session token cost and the doc advises keeping them short.
- **Mechanism**: CLAUDE.md files from managed policy, user, project and local scopes are concatenated into context at launch (ancestor directories at launch, subdirectory files on demand when Claude reads a file there). They arrive as a user message after the system prompt, not enforced config. `@path` imports load alongside the importing file (max depth four hops) and do not reduce context cost. Block-level HTML comments are stripped before injection. `.claude/rules/*.md` with `paths:` frontmatter load only when matching files are touched; rules without paths load at launch. Auto memory stores MEMORY.md (index) plus topic files at ~/.claude/projects/<project>/memory/; only the first 200 lines or 25KB of MEMORY.md load at session start, topic files are read on demand. Auto memory is not loaded into subagents (forks excepted). After /compact, project-root CLAUDE.md is re-read from disk; nested files and path-scoped rules reload on demand. Hooks, not CLAUDE.md, enforce must-run behavior.
- **Numbers**: Target under 200 lines per CLAUDE.md; longer files consume more context and reduce adherence. MEMORY.md: first 200 lines or 25KB. CLAUDE.md files over 4 MiB are skipped entirely. On-demand file limits: 40,000 characters with a 200K context window; 200,000 characters on Opus 4.6 and Sonnet 4.6 with 1M context, 150,000 on later models. Path-rule brace expansion budget 1,000 patterns and 4 MiB. No prices.
- **Token-cost implication**: Keep CLAUDE.md lean (under 200 lines), move part-of-codebase guidance to path-scoped rules and multi-step procedures to skills, use HTML comments for maintainer notes, exclude irrelevant ancestor CLAUDE.md in monorepos with claudeMdExcludes, and keep MEMORY.md as a short index. Do not expect @imports to save tokens. Avoid duplicating AGENTS.md via hooks or imports.
- **Caveats**: Vendor documentation with no measured cost or adherence data; "longer files reduce adherence" is asserted, not quantified. Behavior is version-dependent (e.g. v2.1.277 for AGENTS.md reading, v2.1.309 for on-demand limits).
- **Topic**: context
