# 008 — The Hidden Cost of "Maximum Context" in AI Coding Agents
- **Source**: https://codechefvaibhavkashyap.medium.com/the-hidden-cost-of-maximum-context-in-ai-coding-agents-specs-memory-chunking-and-token-burn-d73e13e3d833 (Vaibhav Kashyap, Medium, 2026-04-28)
- **Claim**: Persistent memory, big specs and retrieval do not remove token cost; they move it into reading, summarizing, retrieval and memory-update loops. The goal is maximum relevant context, not maximum context.
- **Mechanism**: Every request rebuilds the context window from system/developer instructions, history, files, retrieved memory, tool results and specs. Costs compound per loop: reading, summarizing (reads 12,000 tokens, writes 1,500), retrieval (bad chunk size or top-K causes extra fetches), memory and graph updates (re-read old memory, diff, then write). Feedback cycle: mistake, add specs, bigger prompt, summarize into memory, memory grows, bootstrap cost grows. Mitigations: layered specs, tiny always-loaded AGENTS.md, decisions separated from session logs, retrieval before loading, per-category token budgets, hierarchical summaries, references instead of copies, memory pruning, structured over narrative memory, a "memory update instruction" section in each spec.
- **Numbers**: Illustrative, not measured. Pre-coding load of 59,000 input tokens x 5 planning iterations = 295,000. Session bootstrap example 35,000 tokens (rules 2,000, project memory 8,000, summaries 5,000, architecture 10,000, tools 4,000, retrieved 6,000). Full task example: 57,000 + 3,000 plan + 24,000 memory update + 13,000 graph update = 97,000 tokens before retries. Suggested budgets: always-loaded instructions 2,000; memory bootstrap 3,000; retrieved memory per task 5,000; spec 8,000; code 15,000; test/log 8,000. A 500-line memory file is fine, 5,000 lines is a burden.
- **Token-cost implication**: Keep always-loaded context under ~5,000 tokens, load the rest on demand, cap and prune memory, and account for memory maintenance (summaries, graph and vector updates, MCP tool definitions and calls) as real spend.
- **Caveats**: Opinion piece with hypothetical token figures and no measurements or pricing; no cache discussion (cached input would cut repeated-prefix cost); cites Anthropic memory tool, Milvus/Zilliz and LangChain docs second-hand; claims the problem is "not solvable" without evidence.
- **Topic**: context
