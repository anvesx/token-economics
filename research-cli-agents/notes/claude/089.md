# 089 — How Claude Code works
- **Source**: https://code.claude.com/docs/en/how-claude-code-works (Anthropic, no date)
- **Claim**: Claude Code is an agentic harness running a gather-context, act, verify loop where models reason and tools act. Everything it sees (history, file contents, command outputs, CLAUDE.md, memory, skills, system instructions) occupies the context window, so context management is the main lever on token use.
- **Mechanism**: The context window holds conversation history, file contents, command outputs, CLAUDE.md, auto memory, loaded skills and system instructions. Near the limit Claude Code auto-compacts the conversation into a summary (early detailed instructions may be lost; add a "Compact Instructions" section to CLAUDE.md or use /compact with a focus). If one file or tool output refills context right after each summary, auto-compaction stops after a few attempts with a thrashing error. MCP tool definitions are deferred by default and loaded on demand via tool search, so only tool names and server instructions use context until a tool is used. Skills load descriptions at session start and full content only on use (disable-model-invocation: true keeps descriptions out). Subagents use their own context window and return only a summary; a fork starts with a copy of the conversation. Sessions are independent with fresh context; /context shows what is using space; includeGitInstructions false removes built-in commit/PR instructions. Models: Sonnet for most tasks, Opus for stronger reasoning, switch with /model.
- **Numbers**: MEMORY.md loads first 200 lines or 25KB, whichever first. No prices, token counts or savings figures.
- **Token-cost implication**: Put persistent rules in CLAUDE.md instead of relying on chat history, run /context to find large consumers, push verbose work to subagents, make rarely used skills manual-only, rely on deferred MCP tool loading, and avoid single huge outputs that cause compaction loops.
- **Caveats**: Conceptual overview from the vendor, no measurements. Defers to separate "context costs" and "reduce token usage" pages not included in this file.
- **Topic**: context
