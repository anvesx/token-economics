# 103 — Speed (Codex): Fast mode and Ultrafast mode
- **Source**: https://learn.chatgpt.com/docs/agent-configuration/speed.md (OpenAI, undated)
- **Claim**: Codex can trade higher usage/cost for faster generation via Fast mode and Ultrafast mode; both bill at multiples of the Standard rate and draw from shared ChatGPT Work/Codex usage.
- **Mechanism**: Fast mode speeds up supported models (GPT-6.1 Sol/Terra, GPT-6 Astra/Sol/Luna); toggled with /fast in CLI, shown via /statusline, persisted with service_tier="fast" + [features].fast_mode=true in config.toml. Available in ChatGPT desktop, Codex CLI, and IDE extension with ChatGPT sign-in. Ultrafast supports GPT-6 Astra and GPT-6.1 Sol, available in Codex and ChatGPT Work on Pro $500 and eligible Enterprise/Edu; on Pro $500 it uses included usage first then credits. Enterprise has Ultrafast off by default (owners enable per user/workspace via permissions); per-user spend controls apply. With an API key, Codex uses API token pricing and ChatGPT credit multipliers don't apply. ChatGPT Work and Codex share pricing, credits, and usage limits.
- **Numbers**: Fast mode speed increase for GPT-5.6 is 1.5x. Fast mode uses included subscription limits at 2.5x Standard rate; purchased credits and Enterprise pay-as-you-go billed at 2x Standard rate. GPT-6 Astra Ultrafast generates tokens up to 8x faster than Standard. Ultrafast bills purchased credits and Enterprise PAYG at 6x Standard rate; uses included subscription limits at 8x Standard rate. GPT-6.1 Sol Ultrafast residency: US + Europe (EEA+Switzerland); GPT-6 Astra Ultrafast: US only. GPT-5.5 retires from Codex (ChatGPT sign-in) 14 October 2026, noon PDT / 19:00 UTC (API/API-key sessions unaffected).
- **Token-cost implication**: Reserve Fast/Ultrafast for latency-critical work — Fast consumes included limits 2.5x faster (credits 2x) and Ultrafast consumes included limits 8x faster (credits 6x), so default to Standard to conserve budget; if on an API key, speed modes bill at plain API token pricing with no multiplier, changing the cost calculus.
- **Caveats**: Official doc but undated; multipliers are relative to an unstated "Standard rate" (no absolute per-1M-token prices given here — deferred to the Pricing doc). Ultrafast gated to specific high tiers (Pro $500, eligible Enterprise/Edu) and limited inference-residency regions. Model lineup is a GPT-6-era snapshot.
