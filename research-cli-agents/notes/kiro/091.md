# 091 — Week 21 · May 18–22, 2026 (Claude Code changelog)
- **Source**: https://code.claude.com/docs/en/whats-new/2026-w21 (Anthropic, doc/changelog, 2026-05)
- **Claim**: Weekly release digest (v2.1.143 → v2.1.149) whose headline feature is auto mode on the Pro plan (replacing permission prompts with background safety checks), plus a cost-relevant `/usage` per-category breakdown and a new `/code-review` command.
- **Mechanism**: Auto mode (now on Pro, supporting Sonnet 4.6 alongside Opus) replaces permission prompts with background safety checks — routine actions run uninterrupted, destructive/suspicious ones are blocked and surfaced; cycle modes with Shift+Tab. `/usage` now shows a per-category breakdown attributing recent plan-limit usage to skills, subagents, plugins, and individual MCP servers. "Extra usage" renamed to "usage credits"; `/extra-usage` → `/usage-credits` (requires claude.ai subscription login, not API-key auth). New `/code-review` command reports correctness bugs at a chosen effort level (e.g. `/code-review high`), with `--comment` posting findings as inline GitHub PR comments; `/simplify` remains a separate cleanup-only review. `/plugin` marketplace browse pane shows projected context cost before install. Status-line JSON input now includes GitHub repo and PR info. Background sessions appear in `/resume` marked `bg`.
- **Numbers**: Releases v2.1.143 → v2.1.149. Models named: Sonnet 4.6, Opus. 1 headline feature. No prices, token counts, or percentage figures.
- **Token-cost implication**: Use the `/usage` per-category breakdown to see which skills, subagents, plugins, or MCP servers are driving plan-limit consumption and trim the expensive ones. Check a plugin's projected context cost in the marketplace browse pane before installing to avoid silently bloating the context window. Run `/code-review` at a lower effort level when you want cheaper reviews.
- **Caveats**: Vendor changelog; feature announcements only, no measured cost data. Auto mode availability depends on account/plan requirements. `/usage-credits` requires subscription login and is unavailable with API-key auth. Point-in-time (week 21, 2026) — behavior may have changed in later versions.
- **Topic**: observability
