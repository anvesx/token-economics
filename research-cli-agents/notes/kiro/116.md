# 116 — GitHub Copilot premium requests (request-based billing, legacy)
- **Source**: https://docs.github.com/en/billing/concepts/product-billing/github-copilot-premium-requests (GitHub, undated)
- **Claim**: Explains GitHub Copilot's legacy premium-request billing — a monthly per-user allowance of "premium requests" consumed by advanced models/features, with model multipliers, overages, and per-SKU budgets.
- **Mechanism**: Premium requests gate advanced models and features (Chat with premium models, large context / advanced reasoning, Copilot cloud agent, Spark app creation). Usage attributed to premium-request SKUs: Copilot premium requests (Chat, CLI, Code Review, Extensions, Spaces), Spark premium requests, and Copilot cloud agent premium requests (dedicated SKUs from 1 Nov 2025 for granular control). Each plan includes a fixed monthly allowance per user, resetting the 1st of each month at 00:00:00 UTC. Each premium-model interaction consumes from the allowance; some models apply multipliers so one interaction counts as several requests. Overages (if enabled) billed at standard rate to the account payment method (or Azure invoice). Copilot cloud agent consumes both GitHub Actions compute (from shared included compute) and premium requests — each cloud agent session = one premium request (session begins when you prompt a task or assign Copilot to an issue). Budgets: set bundled or per-SKU budgets with alerts at 75/90/100%; set budget to $0 + "Stop usage when budget limit is reached" to block paid overages while keeping the subscription (deleting a budget is not a substitute).
- **Numbers**: Allowance resets 1st of month 00:00:00 UTC. Advanced reasoning models may consume 5x or 20x the standard rate (multipliers). Each cloud agent session = 1 premium request. Dedicated Spark/cloud-agent SKUs from 1 November 2025. Budget alert thresholds 75%, 90%, 100%. Article applies only to Copilot Pro / Pro+ subscribers on an existing annual plan who stayed on legacy premium-request billing after 1 June 2026. No per-model or per-1M-token prices given.
- **Token-cost implication**: Treat premium requests as the scarce unit — avoid routing routine work through 5x/20x reasoning-model multipliers; prefer standard-rate models to stretch the monthly allowance; use per-SKU budgets (especially a $0 hard-stop) to prevent surprise overages from cloud-agent sessions, which also burn shared Actions compute; remember each cloud-agent session costs a whole premium request regardless of task size.
- **Caveats**: Official GitHub doc but explicitly legacy — applies only to a narrow set (Pro/Pro+ annual on legacy billing after 1 June 2026); undated page. Measures "premium requests," not tokens — no token or dollar rates here; multiplier values (5x/20x) are examples, exact model multipliers deferred to a separate "Requests in GitHub Copilot" page.
