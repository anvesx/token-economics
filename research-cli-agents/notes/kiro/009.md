# 009 — Claude Code Rate Limits & Usage Quotas Explained (2026)
- **Source**: https://www.truefoundry.com/blog/claude-code-limits-explained (TrueFoundry, 2026-10)
- **Claim**: Claude Code enforces a dual-layer usage system — a 5-hour rolling window plus a weekly cap on active compute hours — with the quota shared across Claude Code, Claude.ai, and Cowork; because tokens (not messages) are the true meter, context size, tool calls, and retries all burn quota faster than message count suggests.
- **Mechanism**: 5-hour window counter starts on your first prompt (not a fixed clock) and resets 5 hours later. Weekly cap counts "active compute hours" = time models actively process tokens/reason, excluding idle. Hitting either limit blocks all new prompts; no manual reset. Tokens meter everything: every prompt, file attachment, tool definition, and conversation-history line draws from the same quota; agentic sessions replay system prompt + file refs + tool defs each turn. Model choice is the biggest lever (Opus > Sonnet > Haiku in cost). Overflow requires API pay-as-you-go. Mitigations: clear context after milestones, keep CLAUDE.md lean, disable unused tools/MCP, use auto-compact carefully, model requests against the token-counting API before execution, time sessions to window resets, exponential backoff/batching. Teams route across Anthropic + Bedrock + Vertex (independent rate limits) via a gateway.
- **Numbers**: Pro $20/mo ($17/mo annual): ~10-45 prompts/5hr, ~40-80 Sonnet hrs/week, Sonnet 4.6 only. Max 5x $100/mo: ~50-225 prompts/5hr, ~140-240 Sonnet hrs + 15-35 Opus hrs. Max 20x $200/mo: ~200-900 prompts/5hr, 240-480 Sonnet hrs + 24-40 Opus hrs. Free $0: ~40 short msgs/day (Claude.ai only), no Claude Code. Team Premium $100/seat (5-seat min). API per MTok: Sonnet 4.6 $3 input / $15 output; Opus 4.6 $5 / $25. Input prompts over 200K tokens billed at 2× standard API rate. Opus 4.7 generates ~35% more tokens than 4.6 for same input. Referencing 5 medium files can burn 30,000+ tokens. "Ultrathink" can multiply consumption 5×. Max tiers may throttle after 50 sessions/month. Peak-hour throttling weekdays 5-11 AM PT (since March 2026). TrueFoundry gateway: ~3-4ms (also stated ~10ms) latency, 350+ RPS on 1 vCPU. Example: 20 devs × $200/mo = $4,000/mo.
- **Token-cost implication**: Treat tokens, not messages, as the budget. Trim context aggressively (lean CLAUDE.md, clear sessions, disable unused MCP/tools since MCP tool defs often exceed the prompt itself), reserve Opus for architecture and use Sonnet/Haiku for routine/well-scoped work, batch instructions into single well-scoped prompts, and schedule heavy work right after a window reset. At team scale, pool one enterprise contract across a gateway with failover to Bedrock/Vertex rather than per-seat subscriptions.
- **Caveats**: Vendor blog (TrueFoundry sells the gateway it recommends); heavily promotional. Prompt counts are "ranges from independent testing" with wide variance by prompt/context/model/load — not precise. Reflects "post-March 28 reality." Bedrock/Vertex/Foundry don't emit cost metrics. Model/price names (Sonnet 4.6, Opus 4.7, GPT-6.1) imply a 2026 future-dated snapshot; confirm against Anthropic's live pricing.
