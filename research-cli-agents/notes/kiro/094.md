# 094 — Run Claude Code programmatically
- **Source**: https://code.claude.com/docs/en/headless (Anthropic, doc, undated)
- **Claim**: The Agent SDK lets you run Claude Code non-interactively via `claude -p` (or Python/TypeScript packages), with a `--bare` mode that cuts startup cost and context by skipping auto-discovery, and structured JSON output that reports per-run and per-model token cost.
- **Mechanism**: `claude -p "<prompt>"` runs non-interactively; combine with `--continue`/`--resume` (conversation reuse), `--allowedTools` (auto-approve tools), `--output-format` (text/json/stream-json). `--bare` skips auto-discovery of hooks, skills, custom commands, subagents, plugins, MCP servers, auto memory, and CLAUDE.md — giving the same result on every machine and a smaller context; in bare mode Claude has only Bash/read/edit tools, no system reminders, no background tasks, and never reads OAuth credentials or keychain (set `ANTHROPIC_API_KEY`). Context is passed explicitly via flags (`--append-system-prompt`, `--settings`, `--mcp-config`, `--agents`, `--plugin-dir`). `--output-format json` returns `total_cost_usd` plus a per-model cost breakdown; with `--continue`/`--resume` the figure is the conversation's whole total. Background work at exit is waited on (default cap 10 minutes idle, settable via `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`, 0 = no cap). Subagent/forked-skill messages stream with `parent_tool_use_id`; text/thinking blocks forwarded only with `--forward-subagent-text`.
- **Numbers**: Background-task idle wait cap default 10 minutes. Monitor watch default timeout 5 minutes after Claude starts it. Piped stdin capped at 10MB (exceeding exits with non-zero status). Slow-stream-consumer drain wait capped at 30 seconds. `MCP_TIMEOUT` startup wait default 30 seconds. API-retry: on 401/403 for an apiKeyHelper credential, first two retries are quiet then events emit from the third. SIGTERM exit code 143; success exit 0, failure non-zero. Many version gates (e.g. `--bare` limits enforced fully from v2.1.286; `--permission-prompts` requires v2.1.259+; bg-session `--continue` v2.1.257+). No price-per-1M-token or percentage-savings figures.
- **Token-cost implication**: Use `--bare` for CI/scripted/SDK runs to cut startup time and avoid loading hooks/skills/MCP/CLAUDE.md you don't need (smaller context = lower token cost and deterministic results). Parse `--output-format json` `total_cost_usd` and the per-model breakdown to track spend per scripted run without the dashboard. Pre-approve tools with `--allowedTools` or a permission mode to avoid wasted turns, and cap unattended spend with `--max-budget-usd` (stops remaining background work at the cap).
- **Caveats**: Vendor doc. `total_cost_usd` and per-model figures are client-side estimates and can differ from the actual bill. `--bare` will become the default for `-p` in a future release. Without `--bare`, a `-p` session runs a project's hooks and MCP servers even in an untrusted folder (no trust dialog) — a security consideration. Behavior is heavily version-gated.
