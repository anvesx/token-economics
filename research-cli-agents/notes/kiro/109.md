# 109 — Codex CLI Rate-Limit Reset Banking and Usage Optimisation
- **Source**: https://codex.danielvaughan.com/2026/06/12/codex-cli-rate-limit-reset-banking-usage-optimisation-cost-control-profiles-token-budgets (Daniel Vaughan, 2026-06)
- **Claim**: Codex app 26.609 (11 June 2026) added rate-limit reset banking for Plus/Pro so developers can save and redeem resets; combined with config.toml keys, profiles, and flags, CLI cost is controllable as a configuration problem.
- **Mechanism**: Usage is metered against a 5-hour rolling window (resets 5h after the consuming usage). Reset banking lets eligible users save resets that would expire and redeem them manually (activating one immediately resets the current window), operated via the Codex app usage menu, not CLI. Credits = (input_tokens*input_rate) + (cached_input*cached_rate) + (output_tokens*output_rate). Cost-control config keys: model (default cheap model), model_reasoning_effort (minimal/low/medium/high/xhigh), plan_mode_reasoning_effort, tool_output_token_limit (cited as single most impactful), model_auto_compact_token_limit, service_tier="flex" (cheaper, may queue), model_verbosity="low", hide_agent_reasoning=true. Profiles (fast/deep/ci) switch posture at invocation (codex --profile fast). Workflows: front-load high-reasoning planning then drop effort for execution; batch with codex exec + flex; resume (codex resume --last) to hit cached rate instead of reprocessing AGENTS.md as fresh input; scope MCP servers per profile to cut idle tool-definition tokens; monitor with codex doctor. TUI Alt+, / Alt+. adjust reasoning mid-session.
- **Numbers**: Complimentary grant 1 free banked reset at launch; referral window 11–24 June 2026, up to 3 referrals each, team of 5 → up to 15 resets; resets valid 30 days. 5-hour window allocations (messages): Plus $20/mo GPT-5.5 15–80 / GPT-5.4 20–100 / GPT-5.4-mini 60–350; Pro 5x $100/mo 80–400 / 100–500 / 300–1,750; Pro 20x $200/mo 300–1,600 / 400–2,000 / 1,200–7,000. Credit rates per 1M tokens (input / cached input / output): GPT-5.5 125 / 12.50 / 750; GPT-5.4 62.50 / 6.25 / 375; GPT-5.4-mini 18.75 / 1.875 / 113. A message ~5–45 credits. GPT-5.5 vs GPT-5.4-mini ≈ 6.6x on output. Cached input costs 90% less (10% of fresh). Profile cost examples: fast ~5 credits/msg, default ~15, deep ~40. API-key break-even guidance: subscription for interactive; API key for >100 tasks/day or overnight loops.
- **Token-cost implication**: Default to the cheapest model and a medium reasoning floor; set tool_output_token_limit aggressively (e.g. 8,000–12,000); use flex tier and low reasoning for batch/CI; resume sessions to exploit the 90%-cheaper cached-input rate; trim connected MCP servers to cut per-turn system-prompt tokens; use API-key billing for high-volume/overnight work to bypass the rolling window.
- **Caveats**: Independent blog, not OpenAI; credit rates and message ranges cited from OpenAI pricing but are ranges reflecting message complexity, not guarantees. Reset banking is app-only (no CLI command) at time of writing. API-key usage charged at standard API rates and bypasses the window. Model names (GPT-5.4/5.5) reflect the article's June-2026 snapshot and will change.
