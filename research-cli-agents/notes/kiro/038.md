# 038 — Aider LLM Leaderboards
- **Source**: https://aider.chat/docs/leaderboards (Aider, 2025-11)
- **Claim**: Aider's polyglot benchmark ranks LLMs on 225 Exercism coding exercises across C++, Go, Java, JavaScript, Python, and Rust, reporting percent-correct, total run cost in dollars, and correct-edit-format rate so you can compare accuracy against cost per model/reasoning-effort/edit-format.
- **Mechanism**: Each model runs the full 225-case suite in a fixed edit format (diff, diff-fenced, whole, architect, editor-diff). Two-attempt protocol: pass rate 1 (first try) and pass rate 2 (after one retry with test feedback) — the headline "percent correct" is pass rate 2. Per-run the leaderboard records prompt tokens, completion tokens, total cost, seconds/case, well-formed-response %, and failure modes. Architect mode splits a reasoning model (planner) from a cheaper editor model. Reasoning effort (low/medium/high) and thinking-token budgets are varied for the same base model, exposing the accuracy-vs-cost-vs-latency tradeoff directly.
- **Numbers**: Top accuracy: gpt-5 (high) 88.0% at $29.08 (91.6% well-formed, 2,675,561 prompt / 2,623,429 completion tokens, 194s/case). gpt-5 (medium) 86.7% $17.69; gpt-5 (low) 81.3% $10.37. o3-pro (high) 84.9% but $146.32 (449s/case). gemini-2.5-pro-preview-06-05 (32k think) 83.1% $49.88. o3 (high) 81.3% $21.23; o1 (high) 61.7% $186.50. Cheapest strong models: DeepSeek-V3.2-Exp Reasoner 74.2% at $1.30; DeepSeek-V3.2-Exp Chat 70.2% at $0.88; Kimi K2 59.1% $1.24; DeepSeek R1 71.4% $4.80. claude-opus-4 (32k thinking) 72.0% $65.75; (no think) 70.7% $68.63. claude-sonnet-4 (32k think) 61.3% $26.58; (no think) 56.4% $15.82. gpt-4.1 52.4% $9.86; gpt-4.1-mini 32.4% $1.99; gpt-4.1-nano 8.9% $0.43. Grok 3 Mini Beta (high) 49.3% $0.73. gpt-4o-mini 3.6% $0.32. Benchmark = 225 cases. Last updated Nov 20, 2025.
- **Token-cost implication**: Accuracy and dollar cost are weakly coupled — DeepSeek V3.2 Reasoner reaches 74.2% for $1.30 while o3-pro's 84.9% costs $146.32 (~112× more for ~11 points). Use the leaderboard to pick the cheapest model that clears your accuracy bar, tune reasoning-effort down when the marginal points aren't worth the cost/latency, and consider architect mode (strong planner + cheap editor) to cut cost. Cost per run scales with completion tokens (reasoning/thinking budgets), so thinking-token count is a direct cost knob.
- **Caveats**: Vendor-run benchmark (Aider's own tool, measures instruction-following + edit success, not general coding ability). Costs are total for the 225-case run at the prices/dates shown (Dec 2024–Oct 2025), computed per the command/model version listed; some open/experimental models show $0 (free/local). Edit format and reasoning effort materially change scores for the same base model. Not a per-1M-token price table. Dates on individual rows vary; prices change.
