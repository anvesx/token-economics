# 085 — Track team usage with analytics
- **Source**: https://code.claude.com/docs/en/analytics (Anthropic, doc, undated; lastModified 2026-11-02)
- **Claim**: Claude Code provides analytics dashboards for organizations to track usage, cost/spend, adoption, and contribution metrics (PRs and lines of code shipped with Claude Code assistance). Team/Enterprise and API-console plans have separate dashboards.
- **Mechanism**: Two dashboards — claude.ai/analytics/claude-code (Teams/Enterprise: usage metrics, GitHub-integrated contribution metrics, leaderboard, CSV export) and platform.claude.com/claude-code (API/Console: usage metrics, spend tracking, team insights). For per-user token counts and cost estimates, configure OpenTelemetry export or download the spend report (lists token usage and estimated usage-credit spend per user and per model). Contribution metrics require installing the Claude GitHub app and enabling GitHub analytics; attribution matches Claude Code session activity against merged-PR diff lines using normalization (trim whitespace, collapse spaces, standardize quotes, lowercase) and multiple matching strategies, labeling PRs `claude-code-assisted`. Console team-insights table shows per-user Members, Spend (API cost), and Lines accepted.
- **Numbers**: PR attribution time window: sessions from 21 days before to 2 days after the PR merge date. Code rewritten by developers with more than 20% difference is not attributed to Claude Code. "Effective lines" counted = lines with more than 3 characters after normalization (excluding empty/bracket-only/trivial-punctuation lines). Lines over 1,000 characters excluded as likely minified/generated. Leaderboard shows top 10 users. Data appears within ~24 hours of enabling, daily updates. Enterprise Analytics API key scope `read:analytics`. No price-per-1M-token or percentage-savings figures.
- **Token-cost implication**: Use OpenTelemetry export or the spend report to get per-user, per-model token counts and estimated usage-credit spend — the route to attributing cost by developer and model. Use contribution metrics (PRs/user, lines with vs without CC) to measure ROI against spend, and the leaderboard to find power users. Spend figures in the Console dashboard are estimates; reconcile against the Cost page for actuals.
- **Caveats**: Contribution metrics are public beta, cover only users in the claude.ai org (not Console API or third-party), only github.com repos (GitHub Enterprise Server shows usage only), and are unavailable under Zero Data Retention. Metrics are deliberately conservative (underestimate real impact). Console spend figures are analytics estimates, not the actual bill. Vendor doc, no independent measurement.
- **Topic**: observability
