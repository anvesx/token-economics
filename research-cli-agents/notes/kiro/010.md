# 010 — Claude Code Billing & Usage Limits Explained (Oct 2026)
- **Source**: https://codersera.com/blog/anthropic-june-2026-billing-change-claude-code (Codersera, 2026-10)
- **Claim**: Explains Claude Code's billing (subscription usage windows vs per-token API), current per-token prices, the October 2026 changes (Opus 5.5 default on Pro, halved cache-read pricing, new Max/Team API credits), and the settings that most affect token burn rate.
- **Mechanism**: Two mutually exclusive payment routes: (1) a Claude subscription metered by a rolling 5-hour session window + weekly limits + separate per-model-family limits, shared with Claude chat and Cowork; (2) an API key billed per token. Prompt caching is central: Claude Code re-sends the whole conversation each turn, so cache hits dominate cost. Cache invalidates on prefix changes (model switch, fast mode, MCP server add/remove, plugin enable, /compact, many images, Claude Code upgrade); resuming a stale conversation re-sends history uncached. Levers: protect the prompt cache, set cache TTL explicitly (1h vs default 5min on API/credits), route cheap work to sub-agents (model/effort in frontmatter or CLAUDE_CODE_SUBAGENT_MODEL[_FORCE]), leave effort at the 5.5 medium default, /clear between tasks.
- **Numbers**: Plans: Pro $20/mo ($17/mo annual, $200 up front); Max from $100/mo (5x) and 20x tier; Team Standard $20–25/seat, Premium $100–125/seat; Enterprise $20/seat annual (20-seat min) + API usage. API per-1M (input/output/cache-read/cache-write 5m/1h): Fable 5.1 $10/$50/$0.25(2.5%)/$12.50/$20; Opus 5.5 $4/$20/$0.20(5%)/$5/$8; Sonnet 5.5 $2/$10/$0.10(5%)/$2.50/$4; Haiku 5.5 (≤100K prompt) $0.10/$0.50/$0.01(10%)/$0.125/$0.20, (>100K) $0.50/$2.50/$0.05/...; prev Opus 5 $5/$25/$0.50(10%); Sonnet 5 $2/$10/$0.20(10%). Cache-read cut from 10%→5% (2.5% on Fable/Mythos 5.1). Fast mode Opus 5.5 $8/$40 (2x). Claude 4.7+ tokenizer ~30% more tokens for same text. Monthly API credits (Oct 7): Max 5x $100, Max 20x $200, Team Standard $20/seat, Premium $100/seat, pooled, $500 cap — cover API/Agent SDK/Managed Agents/`claude -p` with linked-org key, NOT interactive Claude Code, GitHub Action runs, usage credits, or cloud providers; expire monthly. Limits shape: Pro ≥5x Free/session; Max 5x or 20x Pro. Anthropic enterprise avg ~$13/developer/active day, $150–250/dev/month, <$30/day for 90%. Break-even: Pro ~1.5 active days/mo, Max 5x ~7.7. Example 91% cache hit blended input: Opus 5.5 $0.542/M (−86%), Sonnet 5.5 $0.271/M, vs Opus 5 $0.905/M. On Opus 5.5 an uncached token costs 20x a cached one. Agent teams ~7x tokens of a standard session. 1M context no premium on 4.6+ except Haiku 5.5. Example scripted Sonnet run (240K cache read + 60K cache write + 20K output) = $0.374/run → Max 5x $100 ≈ 267 runs/mo.
- **Token-cost implication**: Guard the prompt cache above all (misses on Opus 5.5 cost 20x a hit); set 1h cache TTL when on an API key/credits; move mechanical sub-agents (tests, grep, log summaries) to Haiku 5.5 and code-writing sub-agents to Sonnet 5.5, keeping Opus for planning/review; now that Pro defaults to Opus 5.5 (2x Sonnet per token), run `/model sonnet` if limits run out faster; avoid resuming stale conversations and /compact on a cold session; watch for the 100K-token Haiku price step and agent-team 7x multiplier; run /usage weekly to attribute burn to a specific MCP server, loop, or Opus-inheriting sub-agent. For scripted/headless work on Max/Team, use a linked-org API key with `claude -p`/`--bare` so monthly credits pay first.
- **Caveats**: Third-party guide (Codersera), not Anthropic, though prices/versions sourced from Anthropic pricing pages, Claude Code docs, and changelog, checked 2026-10-26. Anthropic does NOT publish how subscription limits convert to tokens or how models are weighted, so any firm "X tokens/week" figure is guesswork; the $13/day benchmark lacks a stated model mix. The 91%-cache and scripted-run token counts are the author's illustrative assumptions, not Anthropic figures. June 2026 Agent-SDK billing change remains paused. Ends with a Codersera hiring pitch.
