# 127 — How to Reduce Aider Token Usage
- **Source**: https://tokenade.net/en/articles/reduce-aider-token-usage (Tokenade, 2026-09-07)
- **Claim**: Aider's two biggest token costs are the repo map re-sent on every request and the edit format (whole-file returns); both are controllable by a single flag each. Running `/tokens` first tells you which line item dominates.
- **Mechanism**: Aider sends a graph-ranked repo map (files + key symbols) with every change request — a standing per-turn input cost. The edit format controls output: `whole` returns the entire changed file (expensive), while `diff`, `diff-fenced`, and `udiff` return only changed parts. `--map-tokens` sets the map budget (default 1k) but the optimizer treats it as a target, not a ceiling, and balloons when the chat is empty. Architect mode splits work between a reasoning "architect" model and a cheap "editor" model (`--editor-edit-format`). `--cache-prompts` caches the system prompt, read-only files, repo map, and editable files; caching stats are unavailable while streaming, so use `--no-stream` to measure. `/tokens` reports context breakdown; `/drop`, `/clear`, `/ask`, `/read-only` manage context.
- **Numbers**: `--map-tokens` default = 1k tokens. Issue #752: launched with `--map-tokens 1024` but `/tokens` showed repo map using over 16,000. Issue #3796: banner announced 4,096 tokens but actual map was more than double. Output tokens billed at a higher rate than input (unspecified rate). Gemini cache hits cited elsewhere as up to 10× cheaper — not in this file. Output is "the size of the file rather than the size of the change" on `whole` format (example: 1,200-line file, 3-line fix).
- **Token-cost implication**: Run `/tokens` before changing anything; switch off `whole` edit format to `diff`/`udiff` on any model that handles it reliably (largest output-cost lever); set `--map-tokens` deliberately and verify with `/tokens`; add files to chat before big questions (empty chat balloons the map); turn on `--cache-prompts` and measure once with `--no-stream`; `/drop` files you are no longer editing.
- **Caveats**: Vendor (Tokenade) blog promoting its own optimizer product; no independent measurement. The two overshoot figures come from two open GitHub issues, reported as multiples not percentages. Does not test command-output filtering (test-runner output enters context unfiltered — called a separate, usually larger problem). Architect-mode savings described as "worth measuring rather than assuming in either direction." No date in header metadata beyond byline (Sept 7, 2026).
