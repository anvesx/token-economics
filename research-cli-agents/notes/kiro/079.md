# 079 — Explore the context window
- **Source**: https://code.claude.com/docs/en/context-window (Anthropic, doc, undated)
- **Claim**: An interactive walkthrough of what fills Claude Code's context window during a session — what loads before you type, what each file read and rule/hook adds, how subagents keep large reads out of the main window, and what survives `/compact`. The representative token figures teach where context (and thus token cost) goes.
- **Mechanism**: Before the first prompt, context is preloaded: system prompt, auto memory (MEMORY.md), environment/git info, deferred MCP tool names, skill descriptions, global and project CLAUDE.md. As Claude works, each file read, path-scoped rule, and PostToolUse hook adds tokens. Subagents run in a separate context window (own system prompt, own CLAUDE.md copy, task prompt) so their large file reads never touch the main window — only the final summary + small metadata trailer returns. `/compact` replaces the conversation with a structured summary; afterward the system prompt/output style still apply, project CLAUDE.md + unscoped rules + auto memory + skill descriptions are re-injected from disk, git status re-read, and up to five most-recently-modified read/edited files are re-read (files >5,000 tokens come back as a path reference, not content). Invoked skill bodies re-injected capped per-skill and total. Users reduce usage with focused `/compact`, `/rewind`, `/autocompact`, `/clear`, subagent delegation, or 1M context.
- **Numbers**: Representative (illustrative, not measured) token counts in the timeline: system prompt ~4,200; auto memory ~680; environment info ~280; MCP tools (deferred) ~120; skill descriptions ~450; global CLAUDE.md ~320; project CLAUDE.md ~1,800; example file reads 2,400 / 1,100 / 1,800 / 1,600; path-scoped rules ~380 / ~290; subagent reads 2,200 / 800 / 3,100 (6,100 total stays in subagent, returns ~420). Compaction re-reads up to 5 files; files >5,000 tokens become path references. Invoked skill bodies capped at 5,000 tokens per skill and 25,000 tokens total (oldest dropped first). Auto memory loads first 200 lines or 25KB. MCP tool-search deferral threshold 10% of context window. Default window 200K; extended 1M. Skill re-injection after compaction requires v2.1.304+.
- **Token-cost implication**: Keep project CLAUDE.md small (doc suggests <200 lines) and move reference content to skills or path-scoped rules so it loads only when needed. Delegate research/large reads to subagents to keep file contents out of the main window. Be specific in prompts so Claude reads fewer files. `/clear` between unrelated tasks and use focused `/compact` to preserve what matters. Put the most important instructions near the top of SKILL.md since truncation keeps the start.
- **Caveats**: All token counts are explicitly "representative" / "illustrative," not measured from a real session. Vendor doc. Actual values vary with CLAUDE.md size, MCP servers, and file lengths. Run `/context` for real per-category usage.
