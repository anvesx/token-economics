# 058 — Gemini CLI Free Tier: 1,000 Requests/Day and What Happens Next
- **Source**: https://inventivehq.com/blog/gemini-cli-free-tier-guide (InventiveHQ, 2026-07)
- **Claim**: Gemini CLI's free tier gives 1,000 model requests/day with a personal Google account (Gemini 3 models, full 1M token context), far more than paid-only competitors; quota is decided by how you authenticate, not which model you pick, and most paid Google AI plans don't raise CLI quota.
- **Mechanism**: Quota is per-user-per-day and tied to auth method. OAuth Google sign-in = free individual tier (1,000/day, 60/min, Gemini 3 Pro+Flash via Auto mode). An unpaid API key is a *downgrade* (250/day, Flash only). Only pay-as-you-go billing (paid API key or Vertex AI) removes the daily cap by billing per token. Each prompt turn = 1 request; agentic tool loops and sub-agent calls each consume additional requests; requests aggregate across all model families (switching to Flash saves latency, not quota). Context caching does not reset request counts. Check usage with `/stats model`; limits reset on rolling ~24hr basis (effectively UTC day start).
- **Numbers**: Free Google account: 1,000 req/user/day, 60 req/min, 1M token context. Google AI Pro: 1,500/day. Google AI Ultra: 2,000/day. Unpaid API key: 250/day (Flash only). Code Assist Standard: 1,500/day; Enterprise: 2,000/day. Competitor context windows: Claude ~200K, Codex/Copilot ~128K. Competitor pricing cited: Claude Code Pro $20/mo, Max $100/mo; Codex CLI Plus $20/mo (30-150 msg/5hr), Pro $200/mo; Copilot CLI $10-39/mo (300 premium/mo). Vertex AI usage estimates: light (100 req/day) ~$5-15/mo, medium (500/day) ~$25-50/mo, heavy (1000+/day) ~$75-150/mo. Flash-class ~order of magnitude cheaper per token than Pro; output tokens cost several times more than input. ~50,000 lines of code analyzable in one request.
- **Token-cost implication**: On the free tier, spend fewer *turns* (well-scoped prompts landing in one exchange) rather than switching models, since every model costs 1 request. Batch work into interactive sessions to reuse cached context. Sign in with Google rather than pasting an unpaid API key. Choose upgrade by reason: fixed-cap plans (Pro/Ultra) only move the wall; only metered billing removes it. Verify the plan actually applies to the CLI (AI Plus and Workspace plans don't).
- **Caveats**: Vendor-adjacent blog (consulting firm), self-reported from Google's published docs; "subject to availability in high demand" so limits are ceilings not guarantees. Pricing "changes often"; relative cost shapes given rather than exact Vertex rates. Dated 2026-07 but byline says 2025-05-31 — model names (Gemini 3) suggest later update. Not independently benchmarked.
