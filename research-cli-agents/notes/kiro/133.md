# 133 — Evaluating Memory Condensation Strategies for Coding Agents in Data-Driven Scientific Discovery
- **Source**: https://arxiv.org/abs/2605.18854 (Pacific Northwest National Laboratory / National Laboratory of the Rockies, 2026-05)
- **Claim**: Across 8 memory-condensation strategies on 60 DiscoveryBench tasks, no condenser significantly changes hypothesis quality; LLM-based condensers raise token cost 24–94%, while simple tool-output masking achieves the only meaningful net savings (8.6%). Cost, not quality, differentiates strategies, and the best condenser depends on domain and task length.
- **Mechanism**: Uses OpenHands CodeActAgent with GPT-4o as the agent and GPT-5-mini for LLM condensation; GPT-4o as LLM-as-Judge. 8 condensers: 5 heuristic (NoOp baseline, RecentEvents FIFO window, AmortizedForgetting halving to max_size/2, ObservationMasking replacing tool outputs outside an attention_window=5 with placeholders, ConversationWindow reactive-on-overflow) and 3 LLM-based (LLMSummarizing free-form, StructuredSummary 18-field function-calling, LLMAttention relevance-ranking). Triggering modes: proactive (event count > max_size=8), per-turn (ObservationMasking), reactive (ConversationWindow). keep_first=2. Quality score = 0.4×Context + 0.3×Variable-F1 + 0.3×Relation, with few-shot judge calibration.
- **Numbers**: 8 strategies × 60 tasks = 480 evaluations, 6 domains (10 tasks each). NoOp baseline ≈75,147 avg tokens, 9.0 events, quality 0.591. Net savings only for ObservationMasking (+8.6%, 68,718 tokens, quality 0.572) and ConversationWindow (+1.2%). Overheads: RecentEvents -14.4%, LLMSummarizing -23.6% (quality 0.637, highest), StructuredSummary -59.0%, LLMAttention -93.9%. Quality range 0.559 (RecentEvents) to 0.637 (LLMSummarizing); Wilcoxon p>0.05 Bonferroni-corrected (no significant differences). Heuristic completion 100%; LLM-based 93–98%. Input tokens = 94–98% of total. Domain: Sociology 52% savings with ObservationMasking; MetaScience ~none; Economics hardest (only LLMSummarizing +3.3%); LLM methods negative in Biology (-158%) and Engineering (-180%). Task length: net savings only on long tasks (>10 events) — ObservationMasking +33.5%, ConversationWindow +26.3%, RecentEvents +19.9%, Amortized +17.0%; LLMSummarizing ~+0.4%. NoOp cumulative prompt tokens ~9K (turn 0) → ~93K (turn 6) → ~376K (turn 18/19). Tasks range 5–22 events.
- **Token-cost implication**: For coding/discovery agents, use heuristic observation masking over LLM summarization — it is the only reliable net token saver and loses no measurable quality. Don't condense short tasks (overhead isn't amortized; -45% to -149% on ≤7-event tasks); condensation only pays off on long (>10-event) trajectories. Reducing total token count matters more than tuning input/output ratio. Select condenser by domain verbosity (verbose domains gain most). Motivates adaptive meta-condensers that switch strategy at runtime.
- **Caveats**: Single backbone model (GPT-4o; GPT-5-mini for condensation) — may differ for smaller-context or weaker models. Short tasks (5–22 events); real workflows with hundreds of iterations may shift the thresholds. Condenser choice treated as static per-run, not switched mid-task. Self-reported, under review (preprint). Note: arXiv id 2605.18854 and 2026 date appear forward-dated/possibly placeholder.
