# 088 — Run Claude Code through a gateway
- **Source**: https://code.claude.com/docs/en/gateways (Anthropic, doc, undated; lastModified 2026-10-19)
- **Claim**: A gateway is a proxy an organization runs between Claude Code and a model provider so that authentication, usage tracking, budgets, and audit logging happen in one controlled place. Claude Code ships a self-hosted gateway (Claude apps gateway) in the `claude` binary and also works with third-party LLM gateways.
- **Mechanism**: Each developer's Claude Code sends requests to the gateway with a gateway-issued developer credential; the gateway authenticates the developer, applies access/budget rules, and forwards to the provider (Anthropic API, Amazon Bedrock, Google Cloud's Agent Platform, or Microsoft Foundry) using one shared organization provider credential. Two credential types: developer credential (per-developer, identifies usage) and provider credential (one, shared). Claude apps gateway adds SSO sign-in via `/login`, per-IdP-group `availableModels` allowlists and managed settings, and OTLP usage-metric export to the org's observability stack. Billing: connecting with a gateway credential (or `ANTHROPIC_AUTH_TOKEN` / `/login`) bills usage to the org's provider account at API rates and turns off the developer's claude.ai subscription for that session; setting only `ANTHROPIC_BASE_URL` with no gateway credential keeps a saved claude.ai login active so subscription limits/billing apply. Model choice (`/model`), non-gateway traffic (version checks), client telemetry, and corporate proxies are configured separately from the gateway.
- **Numbers**: none (no prices, token counts, or percentages in this overview page)
- **Token-cost implication**: Route the team through a gateway to centralize budgets, per-developer usage tracking, and audit logging, and to cap model access by IdP group with `availableModels` — the control plane for managing token spend across a fleet. Note the billing switch: a gateway credential bills to the org at API rates and bypasses individual claude.ai subscriptions, whereas `ANTHROPIC_BASE_URL`-only keeps subscription billing — choose based on who should bear the cost.
- **Caveats**: Vendor doc, architecture overview only — no cost figures. Anthropic does not endorse/maintain/audit third-party gateways and does not support routing Claude Code to non-Claude models through any gateway. Claude apps gateway sign-in is browser SSO with no service-token flow, so CI pipelines with no developer present can't authenticate through it.
