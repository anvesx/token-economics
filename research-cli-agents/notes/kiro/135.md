# 135 — Multi-SWE-bench: A Multilingual Benchmark for Issue Resolving
- **Source**: https://arxiv.org/abs/2504.02605 (ByteDance Seed, 2025-04)
- **Claim**: Introduces Multi-SWE-bench, a human-verified issue-resolving benchmark of 1,632 instances across 7 languages (Java, TS, JS, Go, Rust, C, C++), and reports that current agents generalize poorly beyond Python and collapse on hard, multi-file, long-patch issues. Also releases 4,723 RL training instances.
- **Mechanism**: Five-phase construction pipeline: repository selection (>500 stars, CI/CD, buildable), PR crawling (linked issue + modified tests + merged), Dockerized environment determination, PR filtering via test-status transitions across run.log/test.log/fix.log (keep Any→FAILED→PASSED, drop regressions), and dual-annotation manual verification by 68 annotators (≥80% accuracy threshold, 14-engineer QA team). Three methods evaluated: MagentLess (fixed workflow, fault localization + repair), MSWE-agent (multi-turn ACI), MopenHands (CodeAct v2.1). Token consumption measured with GPT-4o tokenizer; cost computed from per-issue input/output tokens.
- **Numbers**: 1,632 verified instances (from 2,456 candidates), 39 repos, 7 languages; LoC 6.7k–698.6k, files 24–27,632. SWE-bench Verified resolve rate rose 0.40% (RAG+GPT-3.5) → 65.40% (Augment Agent v0) in <1 year. Resolved rates drop sharply when fix patches exceed 600 tokens or touch >1 file; issues >600 tokens resolve ~50% lower than <200-token issues. Multi-SWE-bench is 77.1% medium+hard vs SWE-bench-Verified 61.2%. Best model Claude-3.7-Sonnet with MopenHands: Java 52.2%, C++ 14.73%. Avg cost/issue: DeepSeek-V3/R1 and Qwen2.5-72B below $0.03 (pricing below $0.14/M input tokens); OpenAI-o1 most expensive ($15/M input tokens), up to $3.75/issue (MSWE-agent Python). Go lowest token consumption. MSWE-agent/MopenHands often hit the 50-round interaction limit. 9 LLMs × 3 methods evaluated.
- **Token-cost implication**: Fixed-workflow methods (MagentLess) cost less than LLM-driven multi-turn methods (MSWE-agent, MopenHands) because the latter require more environment interaction turns. Shorter, single-file fixes are far cheaper and more solvable; builders should scope agent tasks to <600-token single-file patches where possible. Cheap open models (DeepSeek, Qwen) achieve ~1/100th the per-issue cost of OpenAI-o1 at competitive resolve on some languages. Truncating long environment observations stabilizes agent runs and cost.
- **Caveats**: Benchmark authored and measured by ByteDance Seed (self-reported method adaptations). Methods were originally Python-optimized, biasing cross-language results downward. Tree-sitter extraction fails on loosely-bound JS; TS repo structures exceed context limits — some failures are tooling artifacts not model limits. Resolve rates are for the specific adapted harnesses (MagentLess/MSWE-agent/MopenHands), not the original agents. Hard issues (>1h human effort) mostly unresolved (~0%).
- **Topic**: agent-cost
