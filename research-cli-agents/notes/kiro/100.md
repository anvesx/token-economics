# 100 — ChatGPT usage limits and spend controls
- **Source**: https://learn.chatgpt.com/docs/enterprise/usage-limits.md (OpenAI, undated)
- **Claim**: Explains that ChatGPT workspace usage limits and spend controls apply to eligible workspace activity (which can include some Codex activity) but do not cover all Codex usage and do not govern OpenAI API Platform billing.
- **Mechanism**: Workspace usage controls apply when the org agreement uses shared/purchased ChatGPT workspace credits, eligible Codex activity can consume those credits, and admins need user guardrails, workspace-level spend controls, or usage notifications. Usage controls govern spend, not feature entitlement/permissions, though exhausted limits can pause access to eligible features; they don't affect source-system permissions or Platform API usage/billing. Ultrafast mode (GPT-6 Astra Ultrafast) is off by default in eligible Enterprise workspaces; workspace owners enable via workspace permissions, and existing per-user spend limits apply (higher usage rates consume budgets faster). Procedures link out to help-center articles for Enterprise/Edu overages and Business credits/spend controls.
- **Numbers**: none
- **Token-cost implication**: Before enabling higher-rate modes like Ultrafast, review per-user spend limits because elevated rates drain budgets faster; understand that workspace spend controls will not cap API-key/Platform usage, so route high-volume API work through separate controls.
- **Caveats**: Official doc but a thin administrative overview with no quantitative figures; mostly points to external help articles. Explicitly states it does not cover all Codex usage nor Platform API billing. Ultrafast billing details deferred to the Speed doc.
- **Topic**: pricing
