# 036 — Codex Context Management: Auto-Compact and /context
- **Source**: https://getunblocked.com/blog/codex-context-window-tools (Unblocked, 2026-11)
- **Claim**: Only ~245K of Codex's advertised 400K token window is actually usable, and context degrades well before it fills; the post ranks six tools (led by the vendor's own Unblocked context engine) for cutting MCP overhead, compacting sessions, and surviving context loss.
- **Mechanism**: Codex budget arithmetic: 400K advertised − 128K reserved for output = 272K effective input, and auto-compaction is clamped at 90% of that (~244,800 usable) since v0.100.0. Levers: run `/compact` early with a queued instruction telling Codex what to keep; keep AGENTS.md under its 32 KiB cap (tail silently truncated); filter `enabled_tools`/`disabled_tools` in config.toml to stop unused MCP schemas loading; tune `model_auto_compact_token_limit` (unset by default, clamped to ≤90%), `model_context_window`, and `model_auto_compact_token_limit_scope` (total vs body_after_prefix). Tools: Unblocked answers over MCP from PRs/Slack/Jira/Confluence so the model stops doing "repo archaeology"; context-mode sandboxes verbose tool output outside the session returning a compact reference (SQLite notes survive compaction); Repomix packs a curated repo slice with per-file token counts and Tree-sitter signature-only compression; Mem0 adds a semantic cross-session memory layer; tiktoken counts tokens before you paste.
- **Numbers**: Window 400,000; output reserve 128,000; effective input 272,000; usable before auto-compact ~244,800 (90%). AGENTS.md cap 32 KiB. Zylos Research (Jan 2026): models break down 30–40% before claimed limits; ~2/3 of tested models failed retrieval at contexts as small as 2,000 tokens. context-mode: 315 KB output → 5.4 KB in-window (98% reduction), 19,400 GitHub stars. Repomix Tree-sitter mode ≈70% token reduction. Seven-server MCP preload ≈71,000 tokens before first prompt. Codex: 5M weekly users (June 2026), 10M combined with ChatGPT Work (July 2026). Pricing: Unblocked $29/user/mo annual (21-day trial); Codex built-ins free; context-mode free (ELv2); Repomix free (MIT); Mem0 $19/mo Starter (Hobby free); tiktoken free (MIT). Stack Overflow May 2026: agentic AI use 59% of developers, 63% rarely/never run agents unsupervised.
- **Token-cost implication**: Subtract before adding — trim AGENTS.md, set the compaction threshold, filter enabled_tools first, because every added MCP server loads its schemas up front (Codex has no deferred tool loading). Pick one storage layer (output sandbox OR cross-session memory), not both. Prefer a single synthesized-answer context source over many raw connectors. Run `/compact` with an instruction before the automatic 90% pass for a better handoff summary. Bigger windows are not the fix; curation beats capacity.
- **Caveats**: Vendor blog whose #1 recommendation is its own paid product (Unblocked, $29/user/mo); rankings and the Webflow/UserTesting quotes are marketing. Budget numbers and the v0.100.0 90% clamp are attributed to OpenAI config reference and GitHub issues (#11805 etc.); third-party tool claims (context-mode 98%, Repomix 70%) are the tools' own README figures, not independently verified. No native `/context` command exists (open feature request #27898); `/status` shows total usage but not per-category breakdown. `features.context_management.experimental_mode` flag is marked not currently available.
