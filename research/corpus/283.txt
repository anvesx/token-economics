Good to know

On the Message Batches API, Claude Opus 5 supports up to 300k output tokens with the output-300k-2026-03-24 beta header.

The minimum cacheable prompt length is 512 tokens. See Prompt caching.

Query limits and capabilities programmatically with the Models APIPreview with links to the API reference available — press Tab until focus enters the card, Escape to return..
