                                             ABSTRACT

                                             Long-horizon LLM agents play an important role in solving complex and sustained tasks,
                                             with ever-growing interaction contexts. However, these accumulated contexts will raise
                                             substantial computational cost and obscure key decision-relevant evidence. Existing methods
                                             typically train external compressors or context-management agents to rewrite context as
                                             shorter hard-token sequences, but such external selection may not align with the LLM’s
                                             evolving representation and is necessarily lossy. In this paper, we introduce Agentic Soft-
                                             Token Compression (ASTC), a training-free compression method using soft tokens within
                                             LLM agent for long-horizon tasks. Specifically, ASTC uses the model’s native recurrent
                                             dynamics to determine the already absorbed information, leveraging the commonly-used
                                             hybrid Gated Delta Network (GDN)–attention. It then carries this information forward
                                             as agentic soft tokens while retaining exact values as hard tokens. The resulting compact
                                             sequence reduces later-layer computation and yields reusable KV caches, extending the
                                             savings across the agent’s trajectory. Extensive experiments on long-horizon tasks show
                                             that ASTC matches or exceeds the uncompressed agent’s accuracy with up to 50.68% fewer
                                             end-to-end Attention Pairs, while trained compressors require 15.4×–103.7× more Attention
                                             Pairs per successful task. These findings highlight agentic soft tokens as a model-native way
                                             to carry absorbed context forward as the task representation evolves.

                                         1 Introduction

                                         Large language models (LLMs) are increasingly deployed as agents that execute multi-step workflows
                                         rather than produce isolated responses (Hsu et al., 2026; Liu et al., 2026a; Dong et al., 2026). Each
                                         step appends system instructions, skills, earlier decisions, tool interactions, code, and environmental
                                         feedback to the next model call. The resulting context connects decisions across time, so losing an
                                         early constraint or observation can trigger an inconsistent action whose effects propagate through the
                                         remaining trajectory. Preserving the full context, however, increases prefill and attention computation,
                                         enlarges the key–value (KV) cache, and forces relevant evidence to compete with stale or redundant
                                         information. Long-horizon agents therefore face the central challenge of controlling this growing cost
                                         without disrupting the cross-step information flow required for coherent decisions.
                                         Reducing context under this constraint is not an ordinary summarization problem. Agent context
                                         mixes semantic content with exact values. Explanations, code, and repeated observations can become

and numerical values may determine later actions and must remain exact. Information that has little
effect on the current action may also become decisive several steps later. Such delayed relevance makes
one-shot importance estimates unreliable. Compressibility therefore cannot be inferred from length,
repetition, or semantic similarity alone. It depends on what the acting LLM has already absorbed, what
the current decision requires, and what a future step may need to recover. Because compression recurs
as the trajectory grows, each operation must save more computation than it consumes. Effective context
compression must therefore compact information already absorbed by the acting LLM, preserve exact
or potentially useful evidence as the task evolves, and deliver savings across subsequent decoding and
agent steps.
Existing context-compression methods typically rely on training, using either hard-token or soft-token
compression. Hard-token methods prune or rewrite text, risking irreversible loss of exact values (Jiang
et al., 2023; Pan et al., 2024; Xu et al., 2024a; Kang et al., 2026; Liu et al., 2026b). Soft-token methods
preserve continuous representations but require separately trained encoders or compressors (Mu et al.,
2023; Chevalier et al., 2023; Ge et al., 2024; Li et al., 2026). More fundamentally, separately trained
compressors create a model-taste gap. The information they learn to preserve may not match what the
acting LLM has already absorbed or will need later. This motivates an in-model approach that uses the
acting LLM’s recurrent state to determine compressibility and carries absorbed information forward
as agentic soft tokens.
In this paper, we introduce Agentic Soft-Token Compression (ASTC), a training-free approach that
uses the acting LLM’s own computation to decide what its growing context must retain. The early
layers have read the full context and the later layers would otherwise continue to process every
original token. Figure 1 places this boundary within a continuing agent workflow and shows how the
choice of compression stage changes task accuracy and workload. In hybrid Gated Delta Network
(GDN)–attention models (Yang et al., 2025), ASTC examines native recurrent updates and checks
whether the retained state can recover a token’s contribution. It keeps exact values explicit as hard
tokens and carries eligible content forward as agentic soft tokens. The shorter sequence reduces
attention work for the current prediction and creates smaller KV caches that remain reusable as the
agent continues. Each compression decision is therefore informed by what the model has already
absorbed, and its benefit extends across the trajectory.
Across diverse long-horizon tasks, ASTC maintains task quality close to or above the uncompressed
model while reducing end-to-end Attention Pairs by up to 50.68%. Preserving exact values avoids
the sharp accuracy loss seen when protection is removed, while the compact cache continues to
save attention work over later decisions with only small changes in action distributions. The same
training-free criterion extends beyond tool observations, matching uncompressed accuracy with 24.52%
fewer Decode KV interactions under full-history compression and reducing workload in additional
long-context and code-repair tasks. ASTC combines the highest task accuracy with the lowest Attention
Pairs per successful task, a 15.4×–103.7× advantage over trained compressors.

2 Motivation

2.1 In-Model Soft Tokens

Context compression determines both how many tokens remain and which evidence reaches the acting
LLM. Existing methods make this decision before the model processes the compressed context, either
pruning tokens or rewriting earlier interactions as shorter text (Jiang et al., 2023; Pan et al., 2024; Kang
et al., 2026; Liu et al., 2026b). This ordering creates a selection mismatch because the value of a context
span is not intrinsic to its text. It depends on how the acting LLM represents the current task, what it
has already absorbed, and which action it is about to take; the same observation can be redundant at
one step and decisive at another. An external compressor must approximate this model-dependent
boundary from text alone. In a long-horizon trajectory, a mistaken deletion can propagate because later
decisions are made from the retained context.Hard-token output adds a second bottleneck because
retained information must be serialized as a shorter sequence of vocabulary tokens, so exact structure
or features distributed across positions must be reconstructed as short text. Even a correctly selected
span can therefore lose task-relevant information when forced into a short textual rewrite. Moving
compression inside the model lets the acting LLM judge compressibility where task information is
represented, while soft tokens retain information in continuous contextual representations. In-model
selection and soft-token representation are therefore complementary, letting the acting LLM judge
what matters and preserve that information in its own representation space, thereby avoiding both
external selection mismatch and discrete textual reconstruction.

   2.3 Model-Native Selection

  Our initial approach followed existing work by training a separate in-model compressor to produce
  soft tokens. We inserted an attention–MLP compressor after either a single backbone layer or multiple
  layers, thereby compressing the hidden sequence once or repeatedly, and trained it with On-policy
  distillation (OPD). Comparing these variants with ACON and LCLM reveals a consistent pattern:
  training-based compression incurs substantial preparation cost yet delivers weak task performance,
  while repeated intervention across more layers offers no remedy (Figure 3) (Kang et al., 2026; Li
  et al., 2026). This failure reflects a difficult optimization problem. An auxiliary compressor must infer
  what the acting LLM has already absorbed, retain information that later steps may require, and emit
  features compatible with downstream layers, all through an objective separate from the LLM’s native
  prediction process.
   Hybrid GDN–attention models already compute a signal closely aligned with this decision during
   their normal forward pass. A GDN recurrent state acts as an online associative memory. Its gated delta
   update can be written as (Yang et al., 2025)

                                                        St = α t St −1 + β t rt k⊤
                                                                                 t ,                  rt = vt − α t St −1 kt ,                                        (1)

  where αt controls how much previous memory survives, β t controls the write strength, and rt is the
  part of the incoming value that cannot be recovered from the retained state. Information already
  represented by the state produces a small correction, whereas novel or conflicting information changes
  the memory more strongly. The update therefore measures information relative to what the acting
  LLM currently remembers, not importance inferred from surface form alone. Moreover, the gate
  and delta update are optimized jointly with the LLM’s predictions, so this distinction shares the
  representation space and task state used by downstream layers. Reusing GDN dynamics avoids
  teaching an auxiliary compressor to approximate the acting LLM’s own notion of novelty. Training-free
  selection is therefore not merely a cheaper alternative; it follows from recognizing that the acting LLM
  has already performed the information judgment that compression requires.


   3 Related Work

  Discrete context compression shortens the sequence before it reaches the acting LLM. Selective Con-
  text (Li et al., 2023) prunes redundant spans; LLMLingua (Jiang et al., 2023) and LongLLMLingua (Jiang
  et al., 2024) rank tokens for prompt pruning; LLMLingua-2 (Pan et al., 2024) learns selection from
  distilled labels; and RECOMP (Xu et al., 2024a) trains compressors for retrieved evidence. For extended
  agent workflows, ACON (Kang et al., 2026) optimizes textual compression guidelines from task
  failures, while Context as a Tool (CAT) (Liu et al., 2026b) trains SWE-Compressor to invoke context
  management during execution. MEM1 (Zhou et al., 2026) instead trains a compact memory jointly
  with agent reasoning. While these lines reduce accumulated context, text-level selection can discard
  exact evidence or diverge from the acting LLM’s evolving task representation, and learned memory
  policies require additional training. Meta Context Engineering (Ye et al., 2026) co-evolves agentic skills
  and context artifacts to optimize task-specific context construction.

separately trained compressor, it keeps compression tied to the model’s evolving task representation.

context compression in long-horizon LLM agents.

5 Experiments

We evaluate ASTC with a frozen Qwen3.5-9B acting model on AppWorld (Trivedi et al., 2024), Of-
ficeBench (Wang et al., 2024), and 8-Objective QA (Zhou et al., 2026; Kang et al., 2026). We compare
with uncompressed Base, prompted compression, LLMLingua (Jiang et al., 2023), LLMLingua-2 (Pan
et al., 2024), ACON UT and UTCO (Kang et al., 2026), and LCLM (Li et al., 2026). In Table 1, ASTC com-
presses only eligible tool observations. We measure task quality and end-to-end Decode KV, Attention
Pairs, and Generated Tokens. Decode KV counts decoding query–cache interactions; Attention Pairs
counts causal query–key pairs across prefill, decoding, and auxiliary calls. Supplementary analyses
and detailed setups are in Appendices C–I.

5.1 Main Results

Table 1 shows that ASTC offers a favorable balance of task quality and inference workload under
the distinct interaction demands of the three benchmarks. On AppWorld, it is the only evaluated
method that improves accuracy over Base while reducing all three workload measures; competing
compressors obtain isolated savings but sacrifice accuracy or increase work elsewhere. On OfficeBench,
ASTC remains close to Base in accuracy while substantially reducing Decode KV and Attention Pairs;
Prompting achieves higher accuracy but uses more Decode KV and generated tokens than ASTC.
On 8-Objective QA, ASTC achieves the best answer quality while reducing generated tokens. LCLM
has the lowest measured workload but answers none of the tasks correctly; ACON UTCO reduces
Decode KV and Attention Pairs further than ASTC but has lower answer quality. Taken together, these
results place ASTC’s value at the trajectory level, where retained task quality and cumulative inference
workload must be judged together.

5.3 Persistence After One Commit

Compression helps a long-horizon agent only if its shorter KV cache remains useful when later steps
revisit it, without substantially changing the agent’s decisions. To isolate this mechanism, we branch
from archived Base trajectories, allow at most one ASTC commit in one branch, and replay identical
subsequent action tokens and tool results in both. This fixed continuation separates the effect of
persistent cache compression from changes caused by diverging actions or observations. With no
further commits allowed, savings at later horizons reflect reuse of the initial cache update rather than
repeated compression. At successive action horizons during the shared continuation, we measure KL
divergence between conditional action-token distributions and cumulative Attention Pairs saved since
the commit. Figure 6 shows that the distributions remain close while savings recur at later actions,
supporting the proposed amortization across the trajectory. A separate autonomous one-commit run
probes whether this local stability carries through to task outcomes; its success is somewhat lower
than archived Base and full ASTC, and differing archive versions make the comparison descriptive.
Appendix H reports all replayed actions and a fixed task cohort, showing how savings accumulate as
the compact cache is reused.

6 Conclusion

Long-horizon agents must retain evidence for future decisions as context grows, while separately
trained compressors may drift from the acting LLM’s evolving task representation. ASTC uses native
recurrent dynamics after early layers have read the full sequence, carrying absorbed content as
agentic soft tokens and keeping exact values as hard tokens. The shorter sequence cuts later-layer
computation and creates a compact KV cache whose savings persist across subsequent decisions.
Without compressor training, ASTC keeps accuracy close to or above the uncompressed agent with
up to 50.68% fewer end-to-end Attention Pairs; in the controlled comparison, it attains the highest
accuracy and lowest Attention Pairs per successful task. Ablations and fixed-continuation analysis
link these gains to exact-value protection, model-native selection, and persistent cache reuse. These
results show how the acting LLM can compact absorbed context into reusable state without losing
exact evidence for later decisions.

A Theoretical Derivations

The distributional comparisons below fix an agent history, a next-token prefix, and a compression
boundary while preserving original logical positions. They bound one conditional next-token distribu-
tion and do not claim that independently generated trajectories remain identical. The workload proof
separately counts later queries while the compressed cache persists, and the attention-mass proof fixes
one downstream query.

A.1 Surrogate-Objective Mismatch

I Experimental Setup and Protocols

I.1 General Setup

Benchmarks. We evaluate ASTC on three long-horizon agentic benchmarks with distinct interaction
structures. AppWorld provides a simulated ecosystem of everyday applications and APIs for interactive
coding agents; we use its full 168-task Test-Normal split (Trivedi et al., 2024). OfficeBench covers
realistic office-automation workflows that require planning, application switching, and grounded
actions across productivity software (Wang et al., 2024). 8-Objective QA groups eight Natural Questions
into each task and requires an agent to gather evidence with a Wikipedia search tool before returning
all eight answers (Kwiatkowski et al., 2019; Zhou et al., 2026; Kang et al., 2026). Together, they test
compression across API interaction, office automation, and multi-question information gathering.
Implementation. The three main benchmarks use the frozen Qwen3.5-9B acting model. For Table 1,
all methods within each benchmark share the acting-model serving configuration and evaluation
protocol. Base and ASTC also share the agent scaffold, prompts, decoding policy, context limit, and
action budget.
Model checkpoints. The main experiments use Qwen/Qwen3.5-9B at Hugging Face revision
c202236235762e1c871ad0ccb60c8ee5ba337b9a (Qwen Team, 2026). The transfer study also
uses moonshotai/Kimi-Linear-48B-A3B-Instruct at revision e1df551a447157d4658b
573f9a695d57658590e9 (Moonshot AI, 2025). The cross-model study in Section 5.5 also uses
the frozen Qwen/Qwen3.8-27B model in BF16.
Bounded pooling. Selected positions are divided into at most M groups in causal order. In each
group, an existing member closest to the mean direction anchors an initial trim by relative ℓ2 error.
ASTC then averages the remaining states in FP32, casts the mean to the runtime dtype, and accepts
a group of at least two members only if its maximum post-cast relative error is at most τh . Rejected
and trimmed positions remain hard tokens. This check bounds hidden-state reconstruction, not
downstream attention scores.
Baselines. Base is the uncompressed acting LLM. We compare ASTC with representative hard-token
approaches, including prompted compression, LLMLingua (Jiang et al., 2023), LLMLingua-2 (Pan et al.,
2024), and the UT and UTCO variants of ACON (Kang et al., 2026), as well as LCLM, a trained soft-
token compressor (Li et al., 2026). These external-compressor comparisons are reported on AppWorld
and OfficeBench; 8-Objective QA also includes Prompting, both LLMLingua variants, both ACON
variants, and LCLM. The newly reported AppWorld LLMLingua-2 and OfficeBench Prompting and
LLMLingua runs compress observations; the remaining hard-token baselines compress the full context,
whereas ASTC compresses eligible tool observations in-model. All methods that require training
use Qwen3.5-9B as the backbone and are evaluated with the same benchmark protocol. End-to-end
workload includes acting-model requests, auxiliary compressor-service calls, compressor-generated
tokens, and repeated prefills. The 8-Objective QA counts include the LLMLingua v1 and LLMLingua-2
service forwards.
Workload metrics. Decode KV counts query–cache interactions during autoregressive decoding.
Attention Pairs also includes prefill and auxiliary model calls, while Generated Tokens counts all
discrete outputs. These are analytical counts, not measured latency or GPU operations. Each workload
metric in Table 1 is normalized to Base within its benchmark.
Related context and cache optimization. Meta Context Engineering (MCE) co-evolves agentic skills
and context artifacts for task-specific context construction (Ye et al., 2026). Archer reuses prompt
K/V while recomputing mutable responses in rollback-capable diffusion language models (He et al.,
2026). These works address context construction and rollback-aware caching, respectively, while ASTC
focuses on in-model compression and persistent cache reuse along agent trajectories.

I.3 Additional-Dataset Protocols

RULER. We evaluate the same 32K inputs in Base and ASTC with the frozen Qwen3.5-9B model and
a 32,768-token context limit. RULER scores answers by task-specific string matching and averages
over its 13 task configurations. We use 20 examples per task, rather than the reference configuration’s
500. Thus the reported accuracy is a 260-example aggregate; matching aggregate scores do not imply
identical results on every task or at the larger default sample size. ASTC uses the Stage-3 data branch
with (χ, ψ) = (0.60, 0.80) and merge-error threshold 0.50. Decode KV and Attention Pairs are analytical
query–cache and causal-pair counts; Gen. is generated tokens, all normalized to Base.
LongBench v2. We use all 503 four-choice questions in the public train split (Bai et al., 2024). Base
and ASTC share the frozen Qwen3.5-9B model and a 262,144-token context limit; examples that
exceed the limit are truncated before either method processes them. Of the 503 examples, 100 require
truncation. The inference configuration permits at most 16 new tokens; the recorded runs generate two
tokens per example in both variants. ASTC uses the Stage-3 catalog branch with (χ, ψ) = (0.55, 0.74),
merge-error threshold 0.55, and minimum net removal of one token. Overall and subgroup accuracy
are exact-match rates for the extracted choice. Reported KV counts and cache bytes are analytical
logical workload measures, not latency or measured peak device memory.
For MBPP, we use the sanitized task snapshot from Archer (He et al., 2026).
MBPP. We use its 427 sanitized MBPP problems (Austin et al., 2021). This interactive code-repair
protocol is not numerically comparable with one-shot MBPP evaluations. The model submits a
complete Python program, receives public-test feedback, and revises it; a third attempt is allowed if
the second fails. The final program is scored once. Both variants use greedy decoding, at most 768
generated tokens per attempt, and a 32,768-token context limit. ASTC uses its Stage-3 calibration,
thresholds, and 16-soft-token bound. Initial prompts, completed code, and public-test feedback are
eligible for compression, while special control tokens remain explicit. Both variants re-prefill the full
transcript before each turn; workload includes these repeated prefills and all decoding calls.
