# 018 — s1-llm-auto-router
- **Source**: https://huggingface.co/decisionmodels/s1-llm-auto-router (Decision Models, 2026-10)
- **Claim**: A small CPU-run classifier that labels each request on seven routing questions (category, difficulty, stakes, needs_tools, needs_vision, needs_long_context, follow_up) in about 14 ms so a policy can pick a model. Vendor reports it beats larger hosted/GPU decision models on its own test set.
- **Mechanism**: mmBERT-small pruned to 11 layers and distilled (alpha 0.9, 12 epochs, lr 1.5e-4, one RTX 4090 about 1 hour) from a fine-tuned mmBERT-base teacher, with seven classification heads and per-head calibration temperatures. Categories: coding, agentic, math, knowledge, long_context, tool_use, design, summarisation, general; difficulty 5 levels (trivial to frontier); stakes 4 levels (negligible to high); four yes/no probabilities. ONNX int8 (183 MB), no PyTorch needed. Input: user turn up to 512 tokens plus first 600 characters of an optional conversation summary. An open-source "auto-model-router decision policy" maps predicted labels to a model from a catalogue. Training data: ~39k synthetic requests (22 languages, 29 stacks), labeled by soft vote of five open LLMs; split 34,671 train / 2,275 dev / 2,175 test.
- **Numbers**: Latency engine-only about 14 ms p50 and 47 ms p99 on 4 pinned cores of AMD EPYC 9555; 26 ms p50 on 4 threads of Xeon E5-2680 v4; hosted API about 93 ms p50 end to end (measured 2 Oct 2026). Hosted price USD 0.001 / EUR 0.001 per million input tokens, output free (launch price as of 15 Oct 2026). Held-out n=2,175: category 0.898, flags mean 0.974, all 7 exact 0.819, routing agreement 0.742 vs Jev 1.13 hosted 0.845 / 0.935 / 0.603 / 0.630 (247 ms), Winnow-12B 0.841 / 0.928 / 0.608 / 0.577 (671 ms GPU), Weiche-395M 0.784 / 0.903 / 0.553 / 0.622 (499 ms CPU). Blind Claude Opus labels, n=100: s1 category 0.88, routing agreement 0.60; Jev 0.80 / 0.57; Winnow-12B 0.75 / 0.35 (about +-8 points uncertainty). Calibration ECE 0.018 category, 0.008-0.028 flags. Weakest languages Greek, Korean, Italian (category accuracy 0.73-0.78, n about 20 each).
- **Token-cost implication**: Request classification for routing can cost roughly $0.001 per million input tokens or run free on CPU at ~14-26 ms, so the classifier is negligible next to LLM spend. Using difficulty/stakes/needs_* flags lets you send trivial requests to cheap models; validate routing agreement on your own traffic first.
- **Caveats**: Vendor-built and self-reported ("treat the comparison as a vendor result"). Synthetic training data, LLM-generated gold labels, no real traffic. Routing agreement is against a labeled policy output, not measured dollar savings or end-quality. Fixed schema; text only; truncates input at 512 tokens. Routing agreement is only 0.60 on the independent Claude-labeled set.
- **Topic**: routing
