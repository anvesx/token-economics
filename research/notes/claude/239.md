# 239 — Cost tracking cookbook (Helicone)
- **Source**: https://docs.helicone.ai/guides/cookbooks/cost-tracking (Helicone, 2026-03)
- **Claim**: Helicone shows how to track LLM cost per session and per business dimension, route to the cheapest provider through its AI Gateway, alert on budget thresholds, and cache to eliminate redundant calls.
- **Mechanism**: Cost accuracy: via the AI Gateway costs are exact (Model Registry v2); for direct provider integrations costs are best-effort estimates from an open-source cost repository covering 300+ models. Sessions: header Helicone-Session-Id (and Helicone-Session-Name) group requests into a workflow. Segmentation: Helicone-Property-* headers (for example UserTier, Feature, Environment). Gateway routing: BYOK keys first, then cheapest available provider, with fallbacks to the next cheapest. Alerts: graduated thresholds at 50%, 80%, 95% of budget, with separate limits for dev and prod. Caching: Helicone-Cache-Enabled: true with Cache-Control: max-age=3600 for response caching (suited to FAQ bots, static content, dev/test). Weekly email/Slack reports.
- **Numbers**: Illustrative figures only: support chat $0.12 average with 5 API calls; document analysis $0.45 with 12 calls; quick query $0.02 with a single call; example dashboard 73% cache hit rate saving $1,247 per month; premium users shown generating 3x more value than cost; example price $3/1M tokens for claude-3.5-sonnet on both Bedrock and Anthropic keys. Alert thresholds 50%, 80%, 95%.
- **Token-cost implication**: Measure cost per session and per feature rather than per call, tag every request with tier/feature/environment, set tiered budget alerts, and cache deterministic or repetitive requests.
- **Caveats**: Vendor cookbook; dollar figures are example screenshots, not measurements; non-gateway costs are estimates. The page ends with a large site-config blob with no content.
- **Topic**: observability
