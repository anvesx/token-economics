# 066 — LLM Inference Benchmarking: How Much Does Your LLM Inference Cost?
- **Source**: https://developer.nvidia.com/blog/?p=102298 (NVIDIA, 2025-06-18)
- **Claim**: Gives a step-by-step method to convert GenAI-Perf latency/throughput benchmarks into hardware sizing and a total-cost-of-ownership figure per 1,000 prompts and per 1M tokens for self-hosted LLM inference.
- **Mechanism**: (1) Benchmark with GenAI-Perf (TTFT, ITL, tokens/s, requests/s; works with OpenAI-compatible APIs, vLLM, SGLang, NIM, Dynamo, Triton, TensorRT-LLM) across concurrency levels to build a latency-throughput curve and Pareto front (also across FP4/FP8/BF16). (2) Apply a latency limit (e.g. chat: average TTFT at or below 250 ms), pick the highest-throughput point under it, then instances = planned peak requests/s / requests/s per instance; servers = instances x GPUs per instance / GPUs per server. (3) Yearly server cost = initial server cost / depreciation period + yearly software + yearly hosting; total = servers x yearly cost. Cost per 1,000 prompts = yearly server cost / (requests served per year at 100% uptime, adjustable for uptime). Cost per 1M tokens is derived by splitting using the input:output price ratio and the use case's ISL/OSL.
- **Numbers**: Example inputs: server $320,000, 8 GPUs per server, 4-year depreciation, $3,000 per server per year hosting, $4,500 per year software. Reference price ratio $1 per 1M input tokens and $3 per 1M output tokens (formulas themselves were not rendered in the text). Chat TTFT target <=250 ms.
- **Token-cost implication**: Self-hosted cost per token = amortized hardware over achieved throughput at your latency SLA, so utilization and concurrency tuning drive unit cost. Compare resulting $/1M tokens against API prices before deciding to self-host.
- **Caveats**: NVIDIA tutorial with hypothetical figures; the final cost-per-prompt and per-token equations and the worked result are not in the text. Assumes 100% uptime by default; no power or staff costs listed.
