# 005 — Router-R1: Teaching LLMs Multi-Round Routing and Aggregation via Reinforcement Learning
- **Source**: https://arxiv.org/abs/2506.09033 (UIUC, 2025-06; v3 24 Oct 2025)
- **Claim**: Router-R1 trains a small LLM with reinforcement learning to act as a router that alternates "think" and "route" steps, calling several candidate LLMs over multiple rounds and aggregating answers. With a cost term in the reward it learns to try cheaper models first and escalate only when needed.
- **Mechanism**: The router is Qwen2.5-3B-Instruct or LLaMA-3.2-3B-Instruct trained with veRL using PPO. Output format: <think> reasoning, <search> Candidate LLM: sub-query </search> to route, <info> returned response </info> (masked out of the loss), <answer> final </answer>. Max 4 routing steps per query. Reward = Rformat + (1-a)*Routcome + a*Rcost. Rformat is -1 if malformed (then the other terms are zeroed) else 0. Routcome is Exact Match. Rcost is proportional to -m(P_LLM)*T_out (model-size price tier times output tokens), square-root transformed, normalised by the 5th/95th percentile of a 1,000-item sliding window, inverted as 1 - clip(norm,0,1), and 0.5 if the range is tiny. The prompt carries short descriptors of each candidate (size, price, latency, example performance, generated by GPT-4o from model cards), so new models can be added by appending a descriptor with no retraining.
- **Numbers**: Training: 14K samples (7K NQ + 7K HotpotQA), batch size 64, max 225 steps, cost coefficient a = 0.0 in main runs, converges within about 100 steps, A6000 GPUs. Pool of six models: Qwen2.5-7B, LLaMA-3.1-8B, LLaMA-3.1-70B, Mistral-7B, Mixtral-8x22B, Gemma-2-27B via NVIDIA NIM. Eval: 500 random test items per dataset (Bamboogle about 120), seven QA sets. Average Exact Match: Router-R1-Llama 0.409, Router-R1-Qwen 0.416. Baselines on the Qwen base for NQ: Prompt LLM 0.300, Largest LLM 0.296, GraphRouter 0.276, RouterDC 0.278. Cost study: a in {0.6, 0.7, 0.8, 0.9} on Router-R1-Qwen shows EM falling and cost reward rising as a rises (read from a figure; no table values given). Unseen-model test (adding Palmyra-Creative-122B and LLaMA3-ChatQA-1.5-8B with no retraining): average EM 0.352 to 0.346 and F1 0.458 to 0.463 for Router-R1-Qwen. Average LLM API calls per query range from about 1.01 to 1.36 across datasets, higher on multi-hop than general QA.
- **Token-cost implication**: A learned router can be cheap because it is a 3B model, and the cost reward lets you set the accuracy-cost point by changing a. For multi-hop work, expect about 1 to 1.4 extra model calls per query, so budget for call count, not just per-token price. Prefer descriptor-conditioned routing if the model pool changes often.
- **Caveats**: Authors' own benchmarks, QA only (NQ, TriviaQA, PopQA, HotpotQA, 2Wiki, Musique, Bamboogle), small test samples (500). Cost reward priced by size tier, not real API prices, and the authors note it may be unstable across heterogeneous tasks (math, code). Main results use a = 0, so cost-saving results are only a side analysis shown in a figure. No dollar or token savings stated.
- **Topic**: routing
