# 086 — Sentence-Anchored Gist Compression for Long-Context LLMs
- **Source**: https://arxiv.org/abs/2511.08128 (arXiv, Tarasov, Goncharova, Kuznetsov, FusionBrainLab, 2025-11-11)
- **Claim**: A pretrained LLM can be fine-tuned to compress its context into learned "gist" tokens inserted at sentence ends, giving 2x to 8x KV-cache compression without significant degradation on short- and long-context benchmarks (tested on Llama-3.2-3B).
- **Mechanism**: Add Ng new gist tokens to the vocabulary (init by sampling from a Gaussian fit to existing embeddings, "mean-resizing"; resize LM head). Insert Ng gist tokens after every sentence-ending punctuation mark (. ! ?). Attention mask: gist tokens attend to all tokens in their own sentence plus all earlier gist tokens; regular tokens attend only within their sentence plus earlier gist tokens, so later text sees the compressed history. Implemented as a mask change, so prefill is a single parallel forward pass and no BPTT. Trained with the plain LM loss (no reconstruction loss). Three stages: (1) freeze the model, train only gist embeddings; (2) full fine-tuning; (3) large-batch cold-down (up to 1M-token batches, linear LR decay). Trained 4 checkpoints (Ng = 1, 2, 4, 8) on ~4B FineWeb-Edu tokens, 8x A100, bf16, 4096 max sequence length.
- **Numbers**: Abstract: 2x to 8x compression. Short-context (Llama-3.2-3B base vs Sentence Ng=4, final stage): ARC 59.21 vs 54.59; HellaSwag 70.90 vs 68.07; MMLU (cloze) 42.50 vs 39.73; WinoGrande 65.11 vs 61.48. Ng=8: ARC 55.17, HS 67.86, MMLU 39.89, WG 61.17. Compression rate = regular tokens / gist tokens; on short benchmarks 16.55 (HellaSwag) to 82.96 (WinoGrande) at Ng=1, roughly halving per doubling of Ng. Long-context (HELMET Tiny, 100 samples/task, 4K-8K tokens): average compression about 6x at Ng=4, versus 2x for Activation Beacon (Qwen2-7B). Task rates at Ng=4: cite 8.19, longqa 7.83, recall 4.44, rerank 6.29, icl 1.75 (icl at Ng=8 is 0.88, i.e. sequence longer than original). HELMET recall at Ng=4 is 96.00 (stage 3) vs 100.0 vanilla; rerank NDCG@10 at Ng=8 is 7.32 vs 0.40 base. Training cost: stage 1 about 3 hours, stages 2 and 3 about 30 hours each.
- **Token-cost implication**: Learned context compression can shrink KV-cache memory by several times for self-hosted models, but needs fine-tuning per model; it is not a drop-in for hosted APIs. Expect a few accuracy points of loss on short benchmarks.
- **Caveats**: Authors' own results on a single 3B model; no larger models. Compared against 7B baselines (SepLLM, Activation Beacon) on a tiny benchmark subset. Compressed model does not fully recover base performance. Sensitive to punctuation (one extra period nearly doubled ICL score). Rule-based placement and fixed budget per sentence. Implementation materializes the full attention mask, memory-prohibitive near 128K tokens. Compression rate counts only gist-token ratio. Table text in the file is partly garbled.
