# 183 — Using the Anthropic API
- **Source**: https://api-docs.deepseek.com/guides/anthropic_api (DeepSeek, no date)
- **Claim**: DeepSeek exposes an Anthropic-format endpoint so Anthropic SDK clients and Claude Code can call DeepSeek models by changing the base URL and key.
- **Mechanism**: Base URL https://api.deepseek.com/anthropic. Model mapping: names starting claude-opus map to deepseek-v4-pro (billed at the V4 Pro price); claude-haiku and claude-sonnet map to deepseek-flash; other non-claude names return 400. Ignored fields: cache_control (on tools, messages, tool_use, tool_result), service_tier, anthropic-version, container, mcp_servers, top_k, citations, thinking budget_tokens (adaptive treated as enabled); documents, search_result and redacted_thinking blocks unsupported. Usage accounting: input_tokens excludes cache hits, cache_read_input_tokens reports cache hits, cache_creation_input_tokens is currently 0; total input = input_tokens + cache_read_input_tokens + cache_creation_input_tokens. In streaming, use the final message_delta.usage and do not add it to message_start usage. Server web search reports usage.server_tool_use (web_search_requests may exceed max_uses; tool_search counts successful searches).
- **Numbers**: Example usage: input_tokens 2912, cache_read_input_tokens 256, cache_creation_input_tokens 0, output_tokens 52, one web search. For some Claude Code or OpenCode main-agent thinking requests, effective max_tokens can exceed the requested value. No prices on this page.
- **Token-cost implication**: Caching on DeepSeek is automatic, not driven by cache_control markers, so Anthropic-style cache breakpoints have no effect; read cache_read_input_tokens to verify hits. Any claude-opus-named client request is billed at the V4 Pro rate and max_tokens may not cap output in thinking mode, so budget for overruns. Sum all three input fields when computing cost.
- **Caveats**: Compatibility doc only; no pricing, no cache discount rate stated; usage example is a single sample and "can vary between requests".
- **Topic**: caching
