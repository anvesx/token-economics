# 026 — Block level verification accelerates speculative decoding
- **Source**: https://research.google/pubs/block-level-verification-accelerates-speculative-decoding (Google Research, 2025-01)
- **Claim**: Verifying a drafted block of tokens jointly, instead of token by token, gives a speculative decoding verifier that is never worse than the standard one and optimal in expected accepted tokens, with no extra compute or draft tokens.
- **Mechanism**: In speculative decoding a small model drafts a block of tokens and the large model verifies them in parallel, keeping a subset so the output distribution equals the large model's. Standard verification accepts/rejects each token independently; this paper proposes a block-level verification that considers the whole block jointly. A second variant is also described.
- **Numbers**: none (abstract only: "consistent improvements in wall-clock speedup", "improvements are not huge").
- **Token-cost implication**: Lossless speculative decoding implementations should switch to block verification by default for small extra speedup; it does not change output quality or draft cost. Mainly relevant to self-hosted serving, not API pricing.
- **Caveats**: Only the abstract is in the corpus; no speedup figures, models, or datasets. Authors' own evaluation.
- **Topic**: serving
