# 178 — Different Types of API Keys and Rate Limits
- **Source**: https://docs.cohere.com/v2/docs/rate-limits (Cohere, no date)
- **Claim**: Cohere distinguishes free-but-limited trial keys from paid production keys, with per-model and per-endpoint request-per-minute limits.
- **Mechanism**: Rate limits are enforced per key type and endpoint. Prod keys behave like trial keys on newer Chat variants until sales enables production use.
- **Numbers**: Trial keys (and prod keys on newer Chat variants) limited to 1,000 API calls per month. Chat: trial 20 req/min for all listed models; production 500 req/min for Command A, Command R+, Command R, Command R7B, North Mini Code; Command A+, A Reasoning, A Translate, A Vision production "contact sales". Other endpoints (trial / production): Audio Transcriptions 5 req/min / contact sales; Embed 2,000 inputs/min both; Embed (Images) 5 / 400 inputs/min; EmbedJob 5 / 50 req/min; Rerank 10 / 1,000 req/min; Tokenize 100 / 2,000 req/min; Parse 500 / 500; default 500 / 500 req/min.
- **Token-cost implication**: Capacity planning: rate limits (not price) gate throughput; plan on 500 req/min per model in production, and budget time for sales approval for the newest models.
- **Caveats**: Limits are requests, not tokens; no pricing on this page. Vendor doc, point-in-time.
