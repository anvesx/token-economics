# 095 — L1: Controlling How Long A Reasoning Model Thinks With Reinforcement Learning
- **Source**: https://arxiv.org/abs/2503.04697 (arXiv, Carnegie Mellon University, Aggarwal and Welleck, COLM 2025, 2025-03)
- **Claim**: Length Controlled Policy Optimization (LCPO) trains a reasoning model to obey a token budget written in the prompt, giving a smooth cost-accuracy trade-off. It beats the S1 budget-forcing method at every length, and at short lengths the 1.5B model matches or exceeds GPT-4o at the same token count.
- **Mechanism**: Append "Think for n tokens." to each prompt, with n sampled uniformly from 100 to 4000. Fine-tune with GRPO using a reward. L1-Exact: reward = 1[correct] - alpha * |n_gold - n_y|, alpha = 0.0003. L1-Max: reward = 1[correct] * clip(alpha * (n_gold - n_y) + delta, 0, 1), delta = 0.5, a soft penalty for exceeding the budget. Base model DeepScaleR-1.5B-Preview; trained on the 40K-question DeepScaleR-Preview dataset; 700 steps for L1-Exact, then 120 more steps for L1-Max; training context 4K, evaluation context 8K; learning rate 1e-6, batch 128; VeRL. At inference you pick one target length for all prompts.
- **Numbers**: Versus S1 under the same conditions: 100-150% relative and 20-25% absolute gain at 512 and 1024 token budgets. Log-linear scaling slope 0.24 for L1 vs 0.37 for S1. L1-Exact is about 1% below the unconstrained DeepScaleR-4K, mostly on AIME. L1-Max can match or beat L1-Exact with up to 2x fewer tokens. Mean length error is about 3% on math datasets and 20-40% on out-of-domain sets. L1-Max soft-violation rate (more than 500 tokens off) is 0.3% to 2.3%, average 1.3%. Short-CoT results (Table 1): L1 averages 5% above its non-reasoning base and 2% above GPT-4o at equal length. Temperature 0.0 to 1.0 gives 5.6-6.3% mean length deviation. Target lengths tested: 512, 1024, 2048, 3600 tokens, 16 seeds, temperature 0.6. Sequential scaling beats parallel majority voting at equal token budgets (appendix, no figures given in the main text).
- **Token-cost implication**: A user-set budget lets you buy accuracy by the token: set a low target for easy traffic and a higher one for hard traffic. Prefer a max-length variant when you want a worst-case cost ceiling, since it spends fewer tokens on easy problems. At the 512-1024 token range, a small RL-trained reasoning model can replace a larger non-reasoning model. Truncation or forced "Wait" insertion costs much more accuracy than training for length awareness.
- **Caveats**: Self-reported by the authors, small scale (1.5B primary, 7B in appendix), math-focused training. Models may not generalize to lengths longer than trained (max 4000). The length reward covers total output length, not only the thinking tokens. Out-of-domain length error is large (20-40%). Hyperparameters were not tuned extensively. SFT did not work for length control (per the paper). Figure values were garbled in the extraction, so only prose and Table 1 figures are cited. Appendix text was not read in full.
