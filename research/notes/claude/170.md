# 170 — Inference Endpoints pricing
- **Source**: https://huggingface.co/docs/inference-endpoints/pricing (Hugging Face, no date)
- **Claim**: Hugging Face dedicated Inference Endpoints are billed per instance-hour (computed per minute) while an endpoint is ready and running, with a formula for autoscaling costs.
- **Mechanism**: Cost = instance hourly rate * ((hours * min replicas) + (scale-up hours * additional replicas)). Billed while endpoints are initializing and running. Paused endpoints do not count against quota; scaled-to-zero endpoints still count as used quota until paused.
- **Numbers**: Hourly rates (USD): AWS CPU intel-spr x1 $0.033, x2 $0.067, x4 $0.134, x8 $0.268, x16 $0.536; Azure intel-xeon x1 $0.060 to x8 $0.480; GCP intel-spr x1 $0.050 to x8 $0.400. GPU: AWS T4 x1 $0.5; L4 x1 $0.8; A10G x1 $1; L40S x1 $1.8; A100 x1 $2.5 (x8 $20); H200 x1 $5 (x8 $40); GCP T4 $0.5, L4 $0.7, A100 x1 $3.6 (x8 $28.8), H100 x1 $10 (x8 $80). Accelerators: AWS inf2 x1 $0.75, x12 $12; GCP TPU v5e 1x1 $1.2, 2x2 $4.75, 2x4 $9.5. Worked examples: AWS T4 with min 1/max 3 replicas and a 15-minute spike hourly = $0.75/hr, $547.5/month (730 hr base + 182.5 hr x 2 replicas). Basic CPU example gives $46.72/month using $0.064/hr while the hourly line uses $0.067 (the page is internally inconsistent).
- **Token-cost implication**: Dedicated endpoints are priced per GPU-hour, so cost per token depends on utilization; compute effective $/1M tokens as hourly rate divided by sustained tokens per hour and compare with per-token APIs. Idle replicas bill, so pause or scale down.
- **Caveats**: Rates are list prices as shown on the page at crawl time, no throughput or tokens/hour data, so no per-token price can be derived from this page alone. Scale-to-zero still consumes quota.
