# 153 — Setting an AI credit session limit in GitHub Copilot CLI
- **Source**: https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/set-session-limit (Microsoft GitHub, no date)
- **Claim**: Copilot CLI can cap the AI credits spent in one session (public preview), stopping the agent when the cap is hit.
- **Mechanism**: Interactive: `/limits set max-ai-credits NUMBER` applies to the whole session and depletes with every message; `/limits unset` removes it; at the limit you are prompted to reset it and continue. Non-interactive: `copilot -p "PROMPT" --max-ai-credits NUMBER`; the run ends at the limit. It is a soft limit: an in-progress response completes, so usage can slightly exceed it.
- **Numbers**: 1 AI credit = $0.01 USD; minimum limit is 30 AI credits (i.e. $0.30).
- **Token-cost implication**: Set a per-session or per-run credit ceiling on agent runs (especially scripted/CI runs) as a runaway-spend guard; budget for slight overshoot.
- **Caveats**: Public preview, subject to change. Soft cap, not hard. Credit cost depends on model and tokens, no per-model rates given here.
- **Topic**: agent-cost
