# 065 — Beyond Benchmarks: The Economics of AI Inference
- **Source**: https://arxiv.org/abs/2510.26136 (WiNGPT Team, Winning Health AI Research, 2025-10)
- **Claim**: Treats LLM inference as a production function and builds a cost-quality frontier from a 2,993-request medical benchmark, finding diminishing returns to concurrency, an optimal concurrency range per model, and that reasoning-style models cost several times more through output tokens.
- **Mechanism**: Hourly GPU cost = depreciation + power + maintenance (A800 80G about $0.79/hour, range $0.51-$0.99). Test-set cost = hourly cost for 2 cards ($1.58) x total run time / 3600, run on vLLM-style serving at concurrency 8, 16, 32, 48, 64, 128 on WiNEval-3.0 (2,993 requests, 10 clinical scenarios). Per model, choose the lowest-cost (shortest-time) concurrency that still meets TTFT <1 s and throughput >20 tok/s; plot quality (WiNEval score) vs cost.
- **Numbers**: Cloud comparable GPU price $2.82-$5.64/hour (AWS P4de $5.08/hour; Alibaba gn7e-c16g1.4xlarge $4.80/hour). Depreciation assumption: $120,000 purchase over 3 years = about $0.64/hour; power $0.08; maintenance (3%) $0.06. WiNGPT-3.5 (30B): concurrency 8 to 48 cut total time from 2034 s to 774 s; at 48: cost $0.34, score 76.2, 1,347,535 input / 796,836 output tokens; above 48 throughput drops sharply. Optimal-config table (cost, score): Seed-OSS-36B $0.55, 72.2; WiNGPT-3.0 $3.47, 69.6; GLM-4-32B $0.69, 68.5; Qwen3-30B $0.27, 66.9; WiNGPT-2.7 $0.36, 65.5; Mistral-Small $0.25, 59.8; medgemma-27b $0.97, 55.9; gpt-oss-20b (low) $0.11, 56.4. WiNGPT-3.0 output tokens 3,440,393, 4-8x most models (thinking model). Mistral-Small input tokens 2,113,182 vs about 1.3M for others (tokenizer less efficient on Chinese). Appendix: gpt-oss-20b-low cost fell from $0.34 (conc. 8) to $0.07 (conc. 128); WiNGPT-3.0 at conc. 64-128 had TTFT 5.2 s and 57.4 s.
- **Token-cost implication**: Cost per task depends on output-token volume (reasoning models inflate it 4-8x), tokenizer efficiency for the language, and running near but below the saturation concurrency. Measure cost per benchmark run, not just per-token price.
- **Caveats**: Chinese medical workload; single hardware setup (2x A800 80G) and a single run per config (no confidence intervals); GPU cost excludes servers, rack, networking, labor, and assumes 100% utilization (authors note true cost = base / u); costs exclude training. Authors are the WiNGPT team and their own models lead the table; quality score is a proxy.
