# 135 — The Price of a Second Thought: On the Evaluation of Reasoning Efficiency in Large Language Models
- **Source**: https://arxiv.org/abs/2505.22017 (arXiv, Fan, Qin, Han, Shang, Wang, Sun; UESTC / BAAI / NTU, 2025-05; v2 14 Oct 2025)
- **Claim**: Thinking (long-CoT) models are less token-efficient than instruct models overall, wasting tokens on easy problems and paying off only on hard ones. A two-stage pipeline, CoThink, where an instruct model drafts an outline and a thinking model expands it, cuts tokens by 21.1% on average while keeping accuracy.
- **Mechanism**: Token efficiency tau = quality / cost; relative reasoning efficiency eta = tau(thinking) / tau(instruct), with the instruct model as minimal-effort baseline. Under test-time scaling Q proportional to C^beta (beta < 1), eta is approximately (C_R/C_I)^beta (hypothesized, beta 0.3 and 0.5 shown as reference lines). CoThink: Stage 1, Qwen2.5-32B-Instruct gets a system prompt "reasoning strategist" to break the problem into 2-4 high-level steps with no numbers, formulas or answers. Stage 2, the thinking model gets "Use only the following steps to solve the problem. Do not change or add steps. Show the work for each step briefly" plus the outline, answer in \boxed{}. Tested with DAPO-Qwen-32B, DeepSeek-R1-Distill-Qwen-32B, QwQ-32B, Qwen3-32B (thinking on and off) on GSM8K (1,319), MATH500 (500), AIME24 (30). Baselines: Solo-Thinking, No-Thinking (inject "Okay, I think I have finished thinking."), Best-of-N (N=5, shortest chosen). Token counts include outline tokens and all candidates. A case study shows the instruct model solved failing AIME24 questions using only 27.5% of the thinking episodes and 11.9% of the tokens when given the thinking model's first episodes as prefix.
- **Numbers**: Average output length on AIME24: Qwen2.5-32B-Instruct 770 tokens, DAPO 3,610, DeepSeek-R1-Distill 4,774, QwQ 6,067 (thinking models 5-10x longer on solved problems). Example question: 822 vs 1,580 tokens. CoThink vs each model's own Solo-Thinking: average -21.1% total tokens (up to -41.8%) and +1.66% average accuracy; win rate 37/60 (61.7%) (GSM8K 37.5%, MATH500 87.5%, AIME24 60%). Avg outline tokens: GSM8K 78, MATH500 154, AIME24 264. Selected rows: DeepSeek-R1-Distill GSM8K Pass@1 94 -> 92 (-2.1%) with tokens 3,199 -> 2,027 (-36.6%); Qwen3 thinking GSM8K 96.5 -> 94 with tokens 1,696 -> 850 (-49.9%); Qwen3 thinking AIME24 80 -> 73.3 (-8.4%) with tokens 12,390 -> 11,888 (-4.1%). Best-of-N costs roughly 4-5x the tokens of Solo-Thinking (e.g. 30,210 vs 6,639 on one AIME24 row). The extracted results table is partly garbled, so only these rows are cited.
- **Token-cost implication**: Do not send easy requests to a long-CoT reasoning model; draft a short outline with a cheap instruct model and have the reasoning model follow it, or route by difficulty. Evaluate reasoning cost relative to an instruct baseline and include intermediate tokens (best-of-N, outlines).
- **Caveats**: Authors' own results; math benchmarks only (GSM8K, MATH500, AIME24), 32B open models, AIME24 has 30 problems so accuracy deltas are noisy. CoThink gains vary by model (QwQ > R1-Distill > DAPO) and GSM8K win rate is low (37.5%). Some cells show accuracy drops (Qwen3 thinking AIME24 -8.4%). Scaling law is explicitly speculative. Token counts only, no dollar prices.
