# 222 — Prompt Caching (xAI)
- **Source**: https://docs.x.ai/developers/advanced-api-usage/prompt-caching (xAI, 2025-03; page last updated March 16, 2026)
- **Claim**: The xAI API automatically caches the leading messages shared by consecutive requests and serves matches from cache, giving faster time-to-first-token and a reduced rate for cached tokens. Only the overview of the page is in the text.
- **Mechanism**: Automatic prefix caching: messages at the beginning of the array that match exactly the previous request are served from cache. Setting the x-grok-conv-id HTTP header is recommended to maximize hit rate; prompt_cache_key is also mentioned. Sub-pages (How It Works, Maximizing Cache Hits, What Breaks Caching, Usage & Pricing) are listed but their content is not in the text.
- **Numbers**: none
- **Token-cost implication**: Keep static content (system prompt, tools, documents) at the start of the messages array and variable content last. Send a stable x-grok-conv-id per conversation.
- **Caveats**: Only the landing page was captured; no cached-token price or discount figure, no TTL, no benchmarks. Vendor documentation.
- **Topic**: caching
