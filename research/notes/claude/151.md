# 151 — Provisioned throughput for Foundry Models
- **Source**: https://learn.microsoft.com/en-us/azure/ai-services/openai/concepts/provisioned-throughput?wt.mc_id=MVP_407589 (Microsoft, last updated 2026-07-15)
- **Claim**: Provisioned throughput in Microsoft Foundry reserves fixed model capacity (PTUs) billed per hour whether or not requests are made, as an alternative to pay-per-token Standard, Priority and Batch deployments.
- **Mechanism**: You allocate PTUs (model-independent, region- and deployment-type-specific quota). Billing is $/PTU/hr from deployment creation to deletion; Azure Reservations (1-month or 1-year) discount the PTU meter and are bought separately from deployments (they do not guarantee capacity, so create the deployment first). Sizing inputs: requests per minute, average input and output tokens, an output-to-input token ratio (for GPT-4.1 and later generally matches the Global Standard price ratio), and cache rate (for models before GPT-6 Astra cached input tokens do not consume PTU capacity; for GPT-6 Astra and later, cache reads and writes count). These are normalized to a TPM figure and divided by the model's Input TPM per PTU. Three types: Global, Data Zone, Regional Provisioned (separate quota pools). Optional spillover routes 429/non-200 overflow to a standard deployment in the same resource, for all requests or per request via the `x-ms-spillover-deployment` header; not supported for DeepSeek or Llama.
- **Numbers**: none (no prices or PTU-to-TPM values in this page; it says minimum PTU counts and ratios are per model elsewhere).
- **Token-cost implication**: Move predictable, high-volume, latency-sensitive traffic to provisioned plus a reservation; keep variable or low-volume traffic on Standard; batch for non-latency work. Raise cache rate to cut required PTUs on pre-GPT-6 Astra models. Do not scale PTUs up and down with traffic: capacity may be unavailable on scale-up and continuous hourly billing at high utilization typically exceeds reservation pricing. Configure spillover for bursts.
- **Caveats**: Vendor documentation, no measured savings or break-even utilization. Quota does not guarantee capacity; deployment fails if the region lacks capacity. Approval of quota requests can take several days.
- **Topic**: pricing
