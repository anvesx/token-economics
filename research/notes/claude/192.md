# 192 — Auto Router
- **Source**: https://developers.cloudflare.com/ai-gateway/features/routing/auto-router (Cloudflare, last updated 2026-11-04)
- **Claim**: Cloudflare AI Gateway's Auto Router picks a model per request by weighing expected quality against cost, to reduce cost while keeping response quality.
- **Mechanism**: Build a pool of eligible models (supports the request format and inputs such as images; respects credentials, billing config and spend limits; unhealthy providers excluded and restored on recovery). A classification step estimates task type and difficulty; a scoring step ranks candidates by quality versus cost; the top model is tried first with fallback to the next. Use `cloudflare/auto` as the model via Chat Completions or Responses API (WebSockets not supported). Session affinity: send `cf-aig-session-id` so the same model serves a whole turn (user message plus tool-call follow-ups) and the prompt cache can be reused; without it, requests in one conversation may hit different models and cannot reuse the cache. At each turn start it switches models only when the expected benefit outweighs the cost of losing the cache. `cf-aig-turn-id` overrides turn detection; `cf-aig-no-session-affinity: true` disables pinning. Response headers: cf-aig-routed-model, cf-aig-routing-reason (cost_optimal_within_pool, forced_by_candidate_pool, pinned_by_turn, fallback_candidate_unavailable, fallback_key_not_in_candidates, fallback_router_error, fallback_router_timeout, fallback_unsupported_input), cf-aig-routing-decision-id, cf-aig-request-id. Restrict models with cf-aig-allowed-models (supports `*` but not across `/`) and cf-aig-allowed-providers, or use a model alias with Smart routing. Default pool: deepseek-v4-flash-0731 and kimi-k3 (workers-ai), claude-haiku-5.5, claude-opus-5.5, claude-sonnet-5.5, gpt-6-luna, gpt-6.1-sol, grok-4.7; many more selectable via headers. OpenCode config and plugin (/aig-show, /aig-capture) shown.
- **Numbers**: none on cost or savings. Example OpenCode limits: context 1,000,000, output 128,000, max_completion_tokens 32,000. Plugin requires OpenCode 1.18.29 or later.
- **Token-cost implication**: Routing trades model price against task difficulty per request, but switching models mid-conversation forfeits cached prefixes, so always send a session id for agents and chats. Log cf-aig-routing-reason to see how often fallbacks bypass cost optimization.
- **Caveats**: Vendor documentation with no measured savings or accuracy figures; the pool is managed by Cloudflare and may change; classifier and scoring internals are not disclosed.
- **Topic**: routing
