# 241 — AI Gateway (Portkey)
- **Source**: https://portkey.ai/docs/product/ai-gateway (Portkey, 2026-08)
- **Claim**: Feature index of Portkey's AI Gateway (now branded Prisma AIRS AI Gateway): a universal API with caching, fallbacks, routing, retries, budget and rate limits, controlled through gateway configs.
- **Mechanism**: Strategies are expressed as gateway configs. Features listed: universal API for any supported model; simple and semantic cache; MCP support; fallbacks between providers/models; conditional routing on custom checks; automatic retries; circuit breaker; load balancing across API keys to counter rate limits; canary testing of new models in production; gRPC transport (beta); request timeout; budget limits by cost incurred or tokens used; rate limits per minute, hour or day on requests or tokens; custom hosts for private or local models; pass-through to other APIs (rerank, video, listen). Open source gateway runs with npx @portkey-ai/gateway.
- **Numbers**: none
- **Token-cost implication**: Put budget limits, rate limits, caching and conditional routing at the gateway layer so spend control is enforced centrally rather than per application.
- **Caveats**: Feature list only; no mechanism details, prices or measurements. Vendor doc.
- **Topic**: routing
