# 212 — About premium requests
- **Source**: https://docs.github.com/en/enterprise-cloud@latest/copilot/managing-copilot/monitoring-usage-and-entitlements/about-premium-requests (GitHub, 2025-11)
- **Claim**: Describes GitHub Copilot's legacy premium-request metering: what counts as a request, per-feature consumption, plan allowances and overage price. Applies only to Pro/Pro+ annual subscribers still on legacy billing after June 1, 2026.
- **Mechanism**: Chat, CLI and Spaces use one premium request per user prompt times the model multiplier. Agentic tool calls do not count; only user prompts do (for example /plan in Copilot CLI counts as one, a follow-up counts as another). Cloud agent uses one request per session times the multiplier, plus one per real-time steering comment. Code review consumes 13 per review. Allowance resets on the 1st of each month at 00:00:00 UTC and does not carry over. After exhaustion, included models remain usable subject to rate limits.
- **Numbers**: Copilot Pro $10/month, 300 premium requests; Copilot Pro+ $39/month, 1500 premium requests. Extra requests $0.04/request. Code review 13 requests per review. Billing for premium requests began June 18, 2025 on GitHub.com and August 1, 2025 on GHE.com.
- **Token-cost implication**: Per-prompt metering makes long autonomous agent runs cost the same as one prompt, so cost is decoupled from tokens; vendors then limit or reprice (see the usage-based move). Builders should not assume per-request pricing will last for agentic workloads and should track tokens.
- **Caveats**: Vendor doc; legacy model, superseded by usage-based billing for most users. No token figures.
