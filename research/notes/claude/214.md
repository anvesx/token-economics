# 214 — Models and pricing for GitHub Copilot
- **Source**: https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing (GitHub, no date given)
- **Claim**: Copilot now bills per token, converted to GitHub AI Credits (1 credit = $0.01 USD), with a price table per model covering input, cached input, cache write and output, plus tiered long-context rates.
- **Mechanism**: Cost = input, output and cached tokens priced per model, converted to credits. Models with a long-context tier switch to a higher rate when input exceeds a threshold (for example above 200K or 272K for the listed models). Some models add a cache write charge. Code completions and next edit suggestions are not billed in credits. Copilot code review uses an undisclosed auto-selected model and also consumes GitHub Actions minutes. Budgets can be set to $0 with "Stop usage when budget limit is reached" to avoid overage.

- **Token-cost implication**: Cached input is 10% of input price on most listed models (5% on GPT-6.1 Sol, Claude Sonnet 5.5 and Opus 5.5; 2.5% on Claude Fable 5.1), so keep prefixes stable. Watch long-context thresholds, which roughly double price. Cache writes add 25% over input on Anthropic models. Pick the lightest tier that works.
- **Caveats**: Vendor price list, GitHub's resale rates, not provider list prices. Review costs are estimates and the review model is undisclosed.
