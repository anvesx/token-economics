# 208 — GPT-5 prompting guide
- **Source**: https://developers.openai.com/cookbook/examples/gpt-5/gpt-5_prompting_guide (OpenAI cookbook, Aug 7, 2025; page marked archived, may reference outdated models or APIs)
- **Claim**: GPT-5 agent cost and latency are governed by reasoning_effort, verbosity, explicit context-gathering limits, and reusing reasoning items through the Responses API; contradictory prompts waste reasoning tokens.
- **Mechanism**: Lower reasoning_effort (default medium; low or medium often sufficient) and add a `<context_gathering>` prompt with early-stop criteria, parallel batched search and a fixed tool-call budget (example: maximum of 2 tool calls) with an escape hatch to proceed under uncertainty. Use the Responses API with previous_response_id so earlier reasoning items are passed back, conserving chain-of-thought tokens and avoiding re-planning after each tool call (works for ZDR organizations). New `verbosity` parameter controls final answer length, not thinking length; natural-language overrides can set a different level per context (Cursor: low globally, high only for code tools). Minimal reasoning effort is the fastest option, suited to latency-sensitive and GPT-4.1 users, and needs prompted planning, persistence reminders and brief explanations. Contradictory or vague instructions make the model spend reasoning tokens reconciling them. Cursor found an older "be THOROUGH when gathering information" prompt caused repetitive search tool calls on small tasks and softened it. Split separable tasks across turns; tool preambles for progress updates; Markdown instruction may need re-appending every 3-5 user messages. Appendix holds benchmark prompts and tool definitions.
- **Numbers**: Tau-Bench Retail rose from 73.9% to 78.2% by switching from Chat Completions to the Responses API with previous_response_id. Fixed tool-call budget example: max 2. Early-stop signal: top hits converge about 70% on one area. Markdown reminder every 3-5 user messages. No prices or token counts.
- **Token-cost implication**: Control spend with reasoning_effort and verbosity rather than prompt length alone, cap exploratory tool calls, pass reasoning items back so CoT is not regenerated, and remove conflicting instructions that burn reasoning tokens. Prompts written to push thoroughness for older models can cause over-searching on GPT-5.
- **Caveats**: Vendor guide, archived and written for GPT-5 (Aug 2025); the Tau-Bench figure is a single reported comparison without sample size or token counts. Cost effects of the other advice are described qualitatively. Much of the file is long prompt examples and tool definitions rather than analysis.
