# 145 — Gemini for Google Cloud pricing
- **Source**: https://cloud.google.com/products/gemini/pricing?hl=en (Google Cloud, undated)
- **Claim**: Pricing page for Gemini Code Assist Standard and Enterprise (per-seat licenses billed hourly/monthly), plus Gemini Cloud Assist and Gemini in BigQuery feature availability.
- **Mechanism**: Per-seat licensing, not per-token. Subscriptions have monthly or 12-month commitment terms and are billed monthly. Licenses bought via the Gemini Admin console or sales. Enterprise adds code customization on private repos, Apigee, Application Integration, Cloud Assist features and increased daily agent-mode/Gemini CLI usage limits. Core Gemini in BigQuery features (SQL/Python code assist, Data Canvas, Data preparation) are no extra cost in all editions.
- **Numbers**: Code Assist Standard: $0.031232877/hour (monthly commitment), $0.026027397/hour (12-month commitment). Enterprise: $0.073972603/hour (monthly), $0.061643836/hour (12-month). (Hourly rates; the text gives no monthly dollar totals.)
- **Token-cost implication**: For IDE coding assistance, per-seat flat pricing makes cost independent of token volume; commit for 12 months for a lower rate. Higher agent usage limits are an Enterprise differentiator.
- **Caveats**: Vendor price list. Does not state token quotas or the exact daily limits. Preview features noted as free during preview.
