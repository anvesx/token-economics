# 046 — RouterArena: An Open Platform for Comprehensive Comparison of LLM Routers
- **Source**: https://arxiv.org/abs/2510.00202 (arXiv, Rice University, 2025-10; v3 27 Nov 2025)
- **Claim**: RouterArena is an open platform and live leaderboard that ranks 12 LLM routers (open-source and commercial) on one dataset with difficulty levels and five metric families. Result: no router wins on every metric, commercial routers are not automatically better, and all routers fall short of the oracle because they fail to defer to cheaper models when those suffice.
- **Mechanism**: Dataset of 8,400 queries from 23 source datasets, 9 Dewey Decimal domains, 44 categories; Bloom levels labelled by a DeepSeek-V3.1 judge only for coverage. Difficulty is empirical: count of 42 LLMs answering correctly, hard (<=4/42), medium (5-19/42), easy (>=20/42). Metrics: accuracy; actual cost from official API prices (self-hosted models priced by Together.ai size tier); routing optimality (optimal selection ratio, optimal accuracy ratio, optimal cost ratio); robustness (same model chosen under paraphrase/grammar/synonym/typo perturbations, 420 queries perturbed with GPT-4o); latency. Arena score = weighted harmonic mean S = (1+b)*A*C/(b*A+C) of accuracy A and log2-normalised cost C (cmin = 0.0044, cmax = 200 per 1k queries, default b = 0.1). Open-source routers get budget-based masking via confidence scores to draw deferral curves; commercial routers appear as single points. Prefix caching and cached results are reused across routers.
- **Numbers**: Leaderboard accuracy: MIRT-BERT 66.9, Azure-Router 66.7, NIRT-BERT 66.1, GPT-5 64.3, vLLM-SR 64.3, CARROT 63.9, RouterBench-MLP 57.6, NotDiamond 57.3, GraphRouter 57.2, RouterBench-KNN 55.5, RouteLLM 48.1, RouterDC 33.8 (Figure 1 score). - **Token-cost implication**: Do not buy a router on accuracy alone; compare cost per 1k queries on your own mix. Measure router overhead (some add 250-550 ms) and robustness to typos before putting one on the critical path. Check how much a router spends on hard queries, since cost-flat routers leave savings on the table. Use the log-cost arena score with b chosen for your budget.
- **Caveats**: Run by the platform authors (self-reported, academic), not independent of the leaderboard design. Router pools differ per router, so GPT-5 (OpenAI-only pool) is penalised by pool restriction rather than routing quality. Costs use list API prices, MoE and self-hosted models use size-tier estimates. Academic routers were trained with their own repos' data, not tuned for this dataset. Mostly multiple-choice / QA-style tasks; the LongBench-v2 subset is only 100 queries. Some commercial routers hide their model choice so optimality metrics are missing ("-" in Table 2).
