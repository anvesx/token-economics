# 216 — Track cost and usage (Claude Agent SDK)
- **Source**: https://code.claude.com/docs/en/agent-sdk/cost-tracking (Anthropic, 2026-11)
- **Claim**: Documents how the Claude Agent SDK reports token usage and estimated cost per step, per model and per call, and the pitfalls (double counting, placeholder output tokens, subagent exclusion, resumed sessions) plus prompt-cache TTL controls. Costs are client-side estimates, not billing data.
- **Mechanism**: total_cost_usd and costUSD are computed locally from a bundled price table (or a modelPricing table); data-residency pricing multiplies list price by 1.1 when usage reports inference_geo "us". Hierarchy: query() call, step, session. Parallel tool calls in one turn share a message ID, so deduplicate by ID. Per-step output_tokens is a placeholder (value at message_start); read output tokens from the result message. result.usage excludes subagents; total_cost_usd and modelUsage include them (use modelUsage for whole-tree accounting, per model with costBasis list/managed/unknown). A resumed session's result already includes earlier spend (do not sum); independent calls must be summed. In streaming input mode read the latest result, resetting at /clear, /reset, /new. maxBudgetUsd counts only the call's own spend. Error results still carry cost; error_max_budget_usd usage omits the response that crossed the budget, so prefer total_cost_usd. Cache: usage has cache_creation_input_tokens (higher rate) and cache_read_input_tokens (reduced rate). Default cache TTL is 5 minutes for API key, Bedrock, Google Cloud, Microsoft Foundry and Claude Platform on AWS; set ENABLE_PROMPT_CACHING_1H, or CLAUDE_CODE_PROMPT_CACHE_TTL / promptCacheTtl (main conversation) and CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL / subagentPromptCacheTtl (others), each 5m or 1h.
- **Numbers**: Data residency multiplier 1.1x list price (US inference_geo; requires TypeScript SDK v0.3.239 or Python SDK v0.2.144). Cache TTL 5 minutes default, 1 hour optional; 1-hour writes cost more than 5-minute writes (rate not given in text). Other version gates: costBasis needs Claude Code v2.1.246; resumed-session totals from v2.1.277.
- **Token-cost implication**: Use modelUsage, not usage, for cost accounting with subagents; split tracking of cache creation vs read tokens; enable the 1-hour TTL when sessions on the same prefix are more than 5 minutes apart; set max budgets and do not bill customers from these estimates.
- **Caveats**: Vendor doc; estimates can drift from billing (price changes, unknown models, unmodelled billing rules). No measured savings. The page ends with a large site-config blob with no content.
- **Topic**: observability
