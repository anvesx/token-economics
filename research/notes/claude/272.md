# 272 — Introducing pplx-api
- **Source**: https://www.perplexity.ai/hub/blog/introducing-pplx-api (Perplexity, 2023-10)
- **Claim**: Perplexity launches a public-beta inference API for open-source LLMs (Mistral 7B, Llama2 13B/70B, Code Llama 34B) claiming lower latency than TGI, Replicate and Anyscale, and reports a 4x cost reduction after moving one internal feature from an external API to it. The page notes the models are deprecated.
- **Mechanism**: Proprietary inference stack on NVIDIA TensorRT-LLM (optimized FlashAttention and masked MHA kernels) on AWS p4d instances with A100 GPUs, scaled elastically with Kubernetes. OpenAI-client-compatible REST API.
- **Numbers**: Up to 2.92x faster overall latency and 4.35x faster initial response latency than TGI (Llama-2-13B-chat on 2 A100s, single-stream and Poisson-load server scenarios up to 1 request/second; requests averaged about 700 input and 550 output tokens). Max throughput 1.90x-6.75x higher than TGI under decoding-speed constraints; TGI failed the 60 and 80 tokens/second constraints. Up to 2.9x lower latency than Replicate and 3.1x than Anyscale. Switching one feature from an external API saved $0.62M/year, about 4x cost reduction, with no statistically significant difference in a 2-week A/B test. Load: over one million requests daily, almost one billion tokens daily. Human reading speed cited as 5 tokens/second.
- **Token-cost implication**: Self-hosting or hosting open models for a high-volume, narrow feature can cut cost about 4x when quality parity is A/B tested; measure with A/B tests rather than assuming parity.
- **Caveats**: 2023 vendor-reported results on old models; API and models deprecated; one feature, one comparison baseline; Replicate and Anyscale comparison lacked controlled hardware; no per-token price given.
- **Topic**: serving
