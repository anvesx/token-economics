# 022 — Language Model Cascades: Token-level uncertainty and beyond
- **Source**: https://arxiv.org/abs/2404.10136 (Google Research, 2024-04)
- **Claim**: For a small-then-large LM cascade, deferral scores built from the sum or average of per-token log-probabilities suffer length bias. Using quantiles of the per-token probability vector, and a small learned deferral rule on top of them, gives better cost-quality tradeoffs.
- **Mechanism**: Run the small model first (greedy decoding), compute a deferral score from its own token probabilities, defer to the large model if score < threshold t. Chow-Sum = sum of per-token log-probs (defers long outputs too much). Chow-Average = length-normalised (over-corrects, defers short outputs). Chow-Quantile-a = a-quantile of per-token probabilities (a=0 is the minimum token probability, which catches repetitions and unknown "??" tokens). Post-Hoc-Quantile trains a 5-layer MLP on quantile features plus Chow-Sum and Chow-Average; label is 1 where the large model is right and the small is wrong (logistic loss), or the BLEURT difference for translation (square loss). Post-Hoc-Embed-1 adds the small model's mean final decoder embedding; Embed-1+2 also adds the first-token embedding from the first decoder layer of the large model. Cost model: cost = c1 + deferral_rate * c2 (small model always runs). Metric is area under the deferral curve (AUC-DF).
- **Numbers**: Models FLAN-T5 Small (80M) to XXL (11B); main experiments Base to Large, few-shot, greedy. 17 datasets; AUC-DF averaged over 5 runs. TriviaQA AUC-DF: Chow-Sum 0.073 (-13.09% vs random baseline), Chow-Average 0.087 (+3.57%), Post-Hoc-Quantile 0.097 (+15.47%), Post-Hoc-Embed-1+2 0.100 (+19.56%). MNLI: Chow-Sum 0.627 (-2.63%), Post-Hoc-Quantile 0.711 (+10.4%), Embed-1+2 0.722 (+12.24%). ANLI-R1: Chow-Sum 0.524 (+4.59%), Embed-1+2 0.563 (+12.51%). WMT FR to EN: Chow-Sum 0.618 (+2.82%), Embed-1+2 0.618 (+2.89%). No dollar prices or token prices.
- **Token-cost implication**: If you cascade cheap model to expensive model, do not defer on total sequence log-probability. Use the minimum or a low quantile of token probabilities as a baseline, and train a small classifier on quantile features if you have labelled (small right / large right) data. You pay for the small model on every request, so the cascade only saves money when the deferral rate is low.
- **Caveats**: Google Research, self-reported, FLAN-T5 encoder-decoder models only (no decoder-only or RLHF models, which the authors note may be miscalibrated). Quality metrics are accuracy and BLEURT, with cost as deferral rate, not measured latency or dollars. No single quantile wins across tasks. The embedding variants need access to the large model's internals and still cost some compute; the paper says so. Needs token log-probs, which not all APIs expose.
