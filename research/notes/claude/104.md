# 104 — The Benefits of a Concise Chain of Thought on Problem-Solving in Large Language Models
- **Source**: https://arxiv.org/abs/2401.05618 (arXiv, Renze and Guven, Johns Hopkins University, 2024-01; v3 19 Oct 2024)
- **Claim**: Adding a "Be concise" instruction and a concise few-shot example to a chain-of-thought prompt (CCoT) cut output length by about half with negligible accuracy loss, except GPT-3.5 on math.
- **Mechanism**: Three prompts on an MCQA exam: answer-only (one-shot), standard verbose CoT ("think step-by-step", one-shot example with verbose reasoning), and CCoT (same as CoT plus a final "Be concise." line and a one-shot example with a short reasoning chain). Response length measured in output tokens; accuracy = correct/total. Each problem solved 10 times; Mann-Whitney U tests for significance. Exam: 1,000 questions, 100 randomly drawn from each of 10 sets (ARC Challenge, AQUA-RAT, HellaSwag, LogiQA, LSAT-AR/LR/RC, MedMCQA, SAT-English, SAT-Math). Models via Azure OpenAI.
- **Numbers**: Output length reduction CCoT vs CoT: 48.70% average (GPT-3.5 47.62%, GPT-4 49.77%; p < 0.001). Accuracy change: GPT-3.5 -2.95% (p = 0.55), GPT-4 +0.25% (p = 0.21), both not significant. GPT-3.5 on math (AQUA-RAT, SAT Math): -27.69% accuracy (p < 0.001). Cost per 1,000 problems, at 2023 pricing GPT-3.5 $0.001/1K input and $0.002/1K output tokens, GPT-4 $0.03/1K input and $0.06/1K output: GPT-3.5 CoT $0.88 (input 0.55, output 0.33) vs CCoT $0.69 (0.51, 0.17), saving 21.85%; GPT-4 CoT $26.90 (16.37, 10.53) vs CCoT $20.58 (15.29, 5.29), saving 23.49%. Headline: average per-token cost reduction 22.67%. Paper states the study cost was roughly 10x the reported values (10 repeats). GPT-4 costs about 30x more per output token than GPT-3.5.
- **Token-cost implication**: Cheap first lever: tell the model to be concise and show concise worked examples in CoT prompts. Output tokens dominate the saving; total saving is about 22% to 23% because input cost is unchanged. Do not apply to math with weaker models without testing.
- **Caveats**: Authors' own study. Only GPT-3.5 and GPT-4, one CoT/CCoT prompt variant, multiple-choice tasks only. GPT-4 median accuracy was 1.0 (ceiling effect). Pricing is from 2023. Does not cover modern reasoning models with hidden thinking tokens.
