# 059 — Analyzing and Mitigating Cost-Inefficient Behaviors in Coding Agents
- **Source**: https://arxiv.org/abs/2609.30725 (Purdue University, arXiv preprint under review, 2026-09; v3 12 Oct 2026)
- **Claim**: Three recurring behaviors (subsumed retrieval, similar script generation, test re-execution) appear in 79.00-98.00% of coding-agent tasks and account for 6.86-22.75% of task cost. Short developer-written behavioral principles cut cost far more reliably than structure-aware retrieval or agent-generated skills.
- **Mechanism**: Trajectories from Claude Code (Sonnet 4.6) and Mini-SWE-Agent (Sonnet 4.6, MiniMax-M3, Qwen-3.5 Plus) are labelled step by step (rules first, an LLM judge fallback). Detectors: SubRetrv = a retrieval fully covered by an earlier one; SimScrpt = a generated script with line-level Jaccard similarity of at least 0.60 to a preceding one; ReTest = an identical test run with no patch change in between. Mitigations compared: (1) CodeGraph structure-aware retrieval; (2) agent-synthesized skills (SynSkills: 23-41 configuration-specific operational rules distilled from diagnosed trajectories); (3) developer-designed skills (DevSkills: seven general principles, including state a hypothesis before retrieval, reuse context, justify re-reads, persist and revise scripts instead of regenerating, capture test output and rerun tests only when code or evidence changes, break unproductive loops). Evaluated on held-out SWE-bench Verified-200 and Pro-100 (300 tasks), over 10k trajectories, with noise floors from repeated baseline runs.
- **Numbers**: RQ1: 1,200 trajectories on 300 SWE-bench Verified tasks, four configurations. SubRetrv: up to 92.33% of tasks, up to 11.41% of cost (5.01-11.41%). SimScrpt: up to 68.00% of tasks, up to 9.57% of cost, 5.91-9.98x more frequent in Mini-SWE-Agent than in Claude Code. ReTest: 49.67-83.00% of tasks, up to 5.39% of cost. Claude Code Figure 1 example (Django-13158): three behaviors take 17.25% of the task cost. CodeGraph: cost increases of up to 28.14%; for Claude Code it shifts work from the cheaper subagent model to Sonnet 4.6 (token price 3x that of Haiku 4.5), raising cost 8.30% on Verified-200 and 12.19% on Pro-100. SynSkills: robust cost reduction in 3 of 8 settings, by 8.86-22.32%. DevSkills: robust reduction in 6 of 8 settings, by 7.88-41.73%, with one small Pass@1 drop (-1.50 pp, Claude Code on Verified-200); behavior-level maxima 38.57-88.91%. For MSA with Sonnet 4.6, DevSkills cut SubRetrv by 51.52% and 43.57% on the two benchmarks versus 11.38% and a 2.50% increase for SynSkills. Claude Code runs used a $3.00 per-task cost limit (Verified) and $5.00 (Pro).
- **Token-cost implication**: Audit agent trajectories for repeated reads, regenerated near-duplicate scripts and unchanged test reruns, then add a short, general instruction file or skill that tells the agent to reuse context, persist scripts and rerun tests only after changes. Do not assume a smarter retrieval tool (code graph) saves money without measuring end-to-end cost, because verbose tool output and changed subagent delegation can raise it. Track cost per resolved task, not only retrieval counts.
- **Caveats**: Academic preprint by the authors who designed DevSkills, so the best-performing intervention is their own. Single benchmark family (SWE-bench Verified and Pro) and two agent frameworks. Most approach cells are single runs, with noise floors transferred from three-run baselines under an equal-variance assumption. Detection and labelling can err (the LLM fallback handles 31.17% of steps in one configuration). Only CodeGraph was tested as structure-aware retrieval. Results are cost in dollars for these specific model prices.
