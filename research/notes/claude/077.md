# 077 — HeadInfer: Memory-Efficient LLM Inference by Head-wise Offloading
- **Source**: https://arxiv.org/abs/2502.12574 (arXiv preprint; authors from Caltech, UW-Madison, CMU, Rutgers, Microsoft, 2025-02)
- **Claim**: Offloading the KV cache to CPU RAM at attention-head granularity, so only one head (or head group) lives on the GPU at a time, cuts GPU memory for long-context inference without approximating attention. It lets a single 24 GB consumer GPU run Llama-3-8B at multi-million-token context.
- **Mechanism**: Combines chunked prefill (10K chunks), layer-wise offload and head-wise offload. KV for the current layer and head group is fetched from CPU over PCIe, attention is computed exactly, and the new KV is written back. A ping-pong asynchronous prefetch/update overlaps PCIe transfer with compute. Adaptive head grouping picks granularity by context length: all heads fused for 1-500K, 2 groups for 500K-1M, 4 groups for 1M-2M, 8 groups for 2M-4M. Head-group size 8 equals layer-wise offload. It is compatible with duo-attention head sparsity. Roofline analysis in the appendix: prefill is compute-bound for sequence length >= 10K and memory-bound at <= 1K (turning point near 2K); decode is memory-bound, so PCIe offload hurts decode speed.
- **Numbers**: Llama-3-8B at 1M tokens: baseline 207 GB total (15 GB weights, 64 GB activation, 128 GB KV); HeadInfer cuts KV on GPU from 128 GB to 1 GB and total GPU memory from 207 GB to 17 GB (92% reduction); 17 GB in prefill, 16.4 GB in decode. Max context on one RTX 4090 24GB, Llama-3-8B: standard 25K, chunked prefill 30K, 4-bit KV quant 45K, layer-wise offload 45K, HeadInfer 4096K. Other models on the same GPU: Llama-2-7B 1024K, Mistral-7B 4096K, Qwen2-7B 4200K, Gemma-2-9b 1300K. Llama-3-70B on 8x RTX 4090 with pipeline parallelism: 950K (10k chunk) and 1000K (5k chunk) vs 10K standard. Throughput at 1M tokens: prefill 516 tok/s, decode 0.15 tok/s. At 20K tokens: HeadInfer 7210 tok/s prefill and 6 tok/s decode vs standard 7235 and 33. Decode latency table (s/token): standard 0.03 at 1K; HeadInfer adaptive 0.09 at 10K, 0.17 at 20K, 0.28 at 40K; layer-offload and HeadInfer about 27.2 s/token at the 4M column. LongBench v2 overall: standard 28.4, chunked prefill 28.2, layer-wise 29.0, HeadInfer 30.2; Long subset 25.9, 25.9, 26.9, 30.6. SCBench examples: vt 4.6 standard vs 42 HeadInfer; choice-eng 36.5 vs 59.8. Hardware: PCIe 4.0 x16 at 25 GB/s, 1 TB DDR5; KV capacity capped by 512 GB CPU RAM. Prefill latency table was garbled in extraction, so those rows are not cited.
- **Token-cost implication**: For self-hosted long-context workloads, the binding cost is GPU memory, not tokens. Head-wise KV offload turns a multi-GPU 1M-context job into one 24 GB card plus large host RAM, but only for batch-style prefill-heavy work. Do not use it for latency-sensitive or decode-heavy serving: 0.15 tok/s decode at 1M is unusable interactively. Choose group size by context length.
- **Caveats**: Self-reported by the authors; preprint and work in progress. Consumer-GPU, single-request setup; no batching or API dollar cost measured. Long-context accuracy was tested on a Llama-3-8B-Instruct-Gradient-1024k model; NIAH shows parity with standard inference. Decode throughput collapses at long context because of PCIe. Needs very large CPU RAM (up to 512 GB for max context).
