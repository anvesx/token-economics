# 057 — Subagents have arrived in Gemini CLI
- **Source**: https://developers.googleblog.com/en/subagents-have-arrived-in-gemini-cli (Google, 2026-04-15 per post, corpus date 2026-05)
- **Claim**: Gemini CLI can delegate tasks to subagents that each run in their own context window with their own system prompt and tools, keeping the main session lean and cost-effective.
- **Mechanism**: Subagents are Markdown files with YAML frontmatter (name, description, tools list, model: inherit) in ~/.gemini/agents (global) or .gemini/agents (project), or bundled in extensions. The main agent auto-routes by description or the user calls @agent-name. All dozens of tool calls inside a subagent collapse into one response back to the main agent. Built-ins: generalist, cli_help, codebase_investigator. Parallel subagents are supported (multiple agents or instances at once); /agents lists them.
- **Numbers**: none.
- **Token-cost implication**: Offload high-volume exploration, searches and test runs to isolated subagents so only a summary enters the main context; avoid context pollution that inflates every later turn. Parallel subagents hit usage limits faster because requests run concurrently, and parallel code editing can cause conflicts.
- **Caveats**: Product announcement; no measurements of savings. The post itself warns parallel subagents consume usage limits faster. Related-post list mentions a Nov 3 2026 "Cost per task: Using cheap classifiers to route across Gemini models and thinking levels" but that content is not in this text.
- **Topic**: agent-cost
