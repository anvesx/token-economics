# 211 — Model multipliers for annual plans on request-based billing (legacy)
- **Source**: https://docs.github.com/copilot/reference/copilot-billing/model-multipliers-for-annual-plans (GitHub, no date given)
- **Claim**: GitHub moved Copilot to usage-based billing on June 1, 2026. Legacy request-based billing remains only for Copilot Pro and Pro+ annual subscribers, and each model there deducts a premium-request multiplier from the allowance.
- **Mechanism**: Each prompt consumes 1 premium request times the model's multiplier. Auto model selection in Copilot Chat, CLI, the Copilot app or cloud agent gets a 10% discount (a 1x model bills 0.9x). Copilot code review has a flat multiplier of 13 per review.
- **Numbers**: Multipliers: Claude Haiku 4.5 0.33; Claude Opus 4.8 27; Claude Sonnet 4.6 9; GPT-5.3-Codex 6; MAI-Code-1.1-Flash 0.25. Code review 13 per review. Auto-selection discount 10%.
- **Token-cost implication**: Under request billing, cost was a function of model tier, not tokens. A flat per-request multiplier hides token variance. Builders should expect model-tier price ratios (27 vs 0.33 here, about 82x) to dominate and should route cheap tasks to small models.
- **Caveats**: Vendor doc, legacy plans only, multipliers subject to change. Does not apply to the new usage-based billing.
