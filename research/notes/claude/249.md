# 249 — Codex Prompting Guide
- **Source**: https://developers.openai.com/cookbook/examples/gpt-5/codex_prompting_guide (OpenAI, no date given)
- **Claim**: OpenAI's guide to prompting and building a harness for its Codex-tuned coding model (gpt-5.3-codex in the API). It claims the model is faster and uses fewer thinking tokens, and gives a starter system prompt, tool recommendations, compaction and truncation guidance.
- **Mechanism**: Recommends "medium" reasoning effort for interactive use and high or xhigh for the hardest tasks. First-class compaction: call /responses/compact when context grows; it returns an encrypted_content compaction item to pass into later /responses calls so the model keeps key state with fewer conversation tokens (ZDR compatible; the input to compact must fit the context window). Tool-output truncation: limit to 10k tokens (approximate as num_bytes/4); keep half the budget from the start and half from the end and truncate the middle. Parallel tool calls (batch reads in one multi_tool_use.parallel call) to cut round trips. Use the built-in apply_patch tool, a string-typed shell command, and an update_plan tool. Remove prompts for upfront plans and preambles on older Codex models because they cause early stopping. On gpt-5.3-codex the phase field (commentary or final_answer) on assistant items must be persisted and passed back, or performance degrades. AGENTS.md files are injected as separate user-role messages near the top of history.
- **Numbers**: Tool output cap 10k tokens (bytes divided by 4). Preamble cadence every 1-3 execution steps, hard floor within 6 steps or 10 tool calls. No cost, price or percentage savings figures.
- **Token-cost implication**: Default coding agents to medium reasoning effort, reserve high or xhigh for hard tasks; truncate tool output to about 10k tokens with head and tail kept; use the compaction endpoint instead of ad-hoc summarization for long sessions; batch independent reads in parallel; do not request chatty preambles or plans (extra output tokens and early stopping risk).
- **Caveats**: Vendor guidance, self-reported claims ("more token efficient") with no benchmark numbers or cost measurements; written for one model family; most of the page is prompt text and tool code samples rather than cost analysis.
