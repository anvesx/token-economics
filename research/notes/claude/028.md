# 028 — Conformal Cascade: Distribution-Free Accuracy Guarantees for Multi-Tier LLM Inference
- **Source**: https://arxiv.org/abs/2607.25018 (arXiv, Florida State University, 2026-07; v3 31 Jul 2026)
- **Claim**: A small-to-large LLM cascade can defer using conformal prediction set size instead of a confidence threshold. Accept at a tier when the calibrated set has exactly one answer; this gives a finite-sample accuracy bound and a closed-form expected cost.
- **Mechanism**: At each tier draw N=16 samples at temperature 0.7. Nonconformity score of answer a = 1 - (fraction of samples giving a), so it needs black-box access only, no logprobs. Per tier, calibrate q-hat as the ceil((1-alpha)(n+1))-th smallest score on a labelled held-out set (n >= 200 recommended). Prediction set = answers with score <= q-hat. If set size is within kappa (default 1) accept the most frequent answer; an empty or larger set escalates; the last tier falls back to argmin. Coverage at the accepting tier is >= 1 - K*alpha (union bound), tightening to 1 - alpha under an assumed "selection preservation" condition. Two-tier expected cost = c1 + c2 * Pr[|C1| != 1]. Guard rail: if calibration tier-1 acceptance is below 1/r (r = c2/c1), use Always-Strong instead.
- **Numbers**: Eighteen multiple-choice benchmarks, four open-weight families (Llama, Gemma, Ministral, Phi), two-tier only, 30%/70% calibration/test split, assumed cost ratio c1=1, c2=2.7. Worked example: 80% acceptance gives E[Cost] = 1.54, a 43% saving over Always-Strong (cost 2.7). Break-even acceptance 1/2.7 = about 0.37. CC beat the best oracle-tuned heuristic cascade (agreement, entropy, random defer; 12 configs) on 49 of 72 family-benchmark pairs, tied 6, lost 17; biggest gains Ministral/MathQA +4.6 pp, Phi/GPQA-Diamond +4.3, Phi/MedMCQA +3.6; worst Phi/AGI-Eval -4.5 pp. Llama MMLU: CC 75.1% at cost 2.86 vs Always-Strong 74.8% at 2.70. Ministral MMLU: CC 83.7% at cost 2.01 vs Agreement(0.8) 82.5% at 1.97. Tier-1 acceptance at alpha=0.10 on Llama ranges from 0% (MMLU-Pro, GPQA-Diamond) to 95.6% (Belebele-Eng). Empirical miscoverage at alpha=0.10: 0.000 to 0.130 on Llama; MedMCQA 0.130 and ARC-Challenge 0.124 exceed alpha but stay under 2*alpha.
- **Token-cost implication**: Each cascade query pays for N=16 samples at the small tier before any escalation, so savings depend on tier-1 acceptance exceeding c1/c2. Measure acceptance on a calibration set before shipping, and fall back to the strong model alone when it is below break-even. Choose alpha from your error budget instead of hand-tuning a confidence threshold.
- **Caveats**: Academic preprint, self-reported; costs are a fixed ratio (1 vs 2.7), not real token prices, and sample-count overhead is not priced separately. Only K=2 tested, only multiple-choice with a finite answer set; open-ended generation left for future work. Guarantee is marginal, not per-query, and assumes calibration and test data are exchangeable (needs recalibration under shift). Both methods are tuned on test-set argmax. The tight 1 - alpha bound rests on an assumption not proved; the 1 - K*alpha bound holds. Collapses when the small model's samples are diffuse (Phi on AGI-Eval defers 100%).
