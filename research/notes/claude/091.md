# 091 — Wait, We Don't Need to Wait! Removing Thinking Tokens Improves Reasoning Efficiency
- **Source**: https://arxiv.org/abs/2506.08343 (arXiv; University College London and University of Washington, 2025-06)
- **Claim**: NoWait is a training-free inference-time method that bans self-reflection tokens such as "Wait", "Hmm" and "Alternatively" from reasoning-model output. It shortens chain-of-thought length by 27%-51% across five R1-style model series with little or no accuracy loss for RL-trained models.
- **Mechanism**: Build a keyword list from 32 runs of QwQ-32B on AIME 2025, split on "\n\n", taking the 15 most frequent monolingual words (final list includes wait, alternatively, hmm, but, however, alternative, another, check, double-check, oh, maybe, verify, other, again, now, ah, any). For each model, expand to all vocabulary tokens whose text contains a keyword as a substring (for example " wait", "Wait", " Wait", ".wait", "WAIT"), manually dropping false matches ("Ohio" for "oh"). At decode time, a logit processor sets those tokens' logits to a large negative value so they are not sampled. No weights or architecture change.
- **Numbers**: Max 32,768 tokens per instance, five runs per benchmark; unfinished generations count as wrong. Original to NoWait (accuracy % and average tokens): QwQ-32B AIME 2025 66.67 / 15240 to 68.00 / 10548 (-31% length); AMC 2023 91.25 / 7542 to 95.50 / 5267 (-30%); AIME 2024 73.33 / 14142 to 71.33 / 11907 (-16%). Phi4-Reasoning-Plus: AMC 2023 90.00 / 6366 to 96.00 / 4524 (-28%); AIME 2025 59.33 / 16257 to 62.67 / 12490 (-23%). Qwen3-32B: lengths down 13%-16% (AIME 2025 14987 to 12930 tokens, -14%). NoThink baseline on QwQ-32B: AMC 72.50, AIME 2024 46.67, AIME 2025 40.00 (large accuracy loss). Comparison on QwQ-32B-Preview (accuracy / tokens): AIME 2024 baseline 42.00 / 8979, Token-Budget 46.67 / 8734, O1-Pruner 33.33 / 4289, NoWait 42.00 / 5764; AMC 2023 baseline 82.50 / 4143, Token-Budget 82.50 / 3636, O1-Pruner 77.50 / 2399, NoWait 86.00 / 3396. Multimodal: Kimi-VL-A3B-Thinking MMMU-Pro 61.27 / 2975 to 58.73 / 1457 (-51%); average length cut 49%, average accuracy drop 3.42 points; EMMA-mini 34.75 to 27.50 (-7.25 points) with -60% length. QvQ-72B-Preview up to -30% tokens, accuracy change -0.11 to -4.00; video MMVU 64.10 / 1734 to 62.20 / 1260 (-27%); VSI-Bench 32.00 / 2097 to 28.00 / 1554 (-26%). GPQA-Diamond: 11.67% overall token reduction. Distilled Qwen3-4B/8B/14B degraded: gap similar to RL model on AMC, above 5 points on AIME 2024 and above 12 points on AIME 2025.
- **Token-cost implication**: If you self-host an RL-trained reasoning model and control the sampler, add a logit-bias or logit-processor that suppresses reflection tokens. It cuts output tokens roughly 13% to 51% without retraining. Test per model; do not apply it to distilled reasoning models, which lose accuracy. Hosted APIs usually do not expose the needed per-token logit bias on hidden reasoning tokens.
- **Caveats**: Authors' own tests on open-weight models only (QwQ, Phi4-Reasoning-Plus, Qwen3, Kimi-VL, QvQ), mostly math and a few multimodal benchmarks; five runs each. Some accuracy drops are large (Kimi-VL EMMA-mini -7.25, VSI-Bench -4.00). Savings measured in tokens, not dollars or latency. Authors note existing benchmarks do not cover all reasoning abilities. Keyword list tuned on QwQ-32B and AIME 2025.
