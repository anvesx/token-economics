# 144 — Quotas and limits (Gemini for Google Cloud)
- **Source**: https://docs.cloud.google.com/gemini/docs/quotas (Google Cloud, no date; page last updated 2026-10-28)
- **Claim**: Documents the quotas (adjustable) and fixed system limits that Gemini for Google Cloud enforces per project/user to maintain fair resource allocation and prevent overload.
- **Mechanism**: Cloud Quotas monitors and restricts consumption, generally at the Google Cloud project level (shared across apps/IP addresses within a project); exceeding a quota blocks the resource and fails the task. Quotas have defaults and can be adjustment-requested via the console; system limits are fixed. Agent mode / Gemini CLI requests are combined and aggregated across all model versions/families, limited per user per minute, and subject to availability under high demand; one agent-mode or CLI prompt can trigger multiple model requests.
- **Numbers**: Requests per second: 2 (per user per project). Requests per day: 6,000 for Gemini Code Assist or Gemini in BigQuery code requests (code generation/completion); 960 for chat, visualization, data insight table scans, metadata generation, data preparation, and Cloud Assist panel responses. Gemini Code Assist: local codebase awareness 1,000,000-token context window; code customization repositories 20,000. Agent mode + Gemini CLI combined max requests per user per day: Standard 1,500, Enterprise 2,000. Gemini Code Assist on GitHub (Preview): at least 100 pull request reviews per day per installation (can be significantly higher depending on codebase and model calls per review).
- **Token-cost implication**: Builders on Gemini for Google Cloud must architect around hard per-user/per-project caps — 2 req/s, and daily request ceilings — and note that agent-mode/CLI prompts multiply into several model requests against a shared aggregated daily quota (1,500 Standard / 2,000 Enterprise), so agentic loops exhaust quota faster than single calls. The 1M-token local codebase context window bounds how much repo context can be sent.
- **Caveats**: Vendor documentation; limits are request-count quotas (not token prices) and apply only to Gemini for Google Cloud / Code Assist surfaces. GitHub PR-review quota is Pre-GA ("as is", limited support). No cost or token-price figures given. Quotas reset on Google Cloud schedules.
- **Topic**: agent-cost
