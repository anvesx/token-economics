# 122 — Cost-of-Pass: An Economic Framework for Evaluating Language Models
- **Source**: https://arxiv.org/abs/2504.13359 (arXiv, 2025-04)
- **Claim**: Introduces "cost-of-pass" — the expected monetary cost to generate one correct solution — as an economically grounded metric (from Farrell's productive-efficiency / stochastic-frontier theory) combining accuracy and inference cost, plus a "frontier cost-of-pass" benchmarked against a human-expert baseline.
- **Mechanism**: For model m on problem p, cost-of-pass v(m,p) = C_m(p) / R_m(p), where C_m(p) is expected cost of one inference attempt (input tokens × input price + output tokens × output price + extras) and R_m(p) is probability of a correct answer; 1/R is expected attempts. Frontier cost-of-pass V_p(M) = min over models of v(m,p); human expert added as baseline strategy (R_expert≈1, cost≈labor cost/problem). Gain G measures reduction in frontier when a new model is added. Counterfactual analysis measures each model family's "essentialness" by removing it. Progress tracked by fitting exponential decay V_p(M_t)≈a·e^(−bt)+c, with halving time T½=ln2/b. Pass is binary (0/1); 8 runs per model-problem, temp 0.7 (reasoning models temp 1.0), 128 instances/dataset.
- **Numbers**: MATH-500 frontier cost-of-pass halved every ~2.6 months; AIME-2024 every 7.1 months (May 2024–Feb 2025). Model families (<$1/M tokens = lightweight) show distinct niches: lightweight best on basic quantitative, large on knowledge-based, reasoning on complex quantitative. Essentialness %: lightweight drives basic quant (93.5% Two-Digit Add, 50.4% GSM8K); reasoning drives complex quant (74.4% MATH500, 81.0% AIME24). Inference-time technique gains: self-refinement +24.9% on GPQA-Diamond, TALE-EP +66.6% GSM8K / +50% GPQA / +24.5% BBQ; majority voting (k=3,4) gave 0% economic benefit across all datasets. Sample per-token prices (per M tokens): GPT-4o $2.50 in/$10.00 out; Claude Sonnet-3.5 $3.00/$15.00; o1 $15.00/$60.00; Llama-3.1-8B $0.18/$0.18; o3-mini $1.10/$4.40; DeepSeek-R1 $7.00/$7.00. Human-expert cost estimates: AIME $9–20/Q, GPQA-Dia $58/Q, GSM8K $2–3.50/Q, Two-Digit Add $0.01–0.02/Q, BBQ $0.10/Q.
- **Token-cost implication**: Select models by cost-of-pass (cost ÷ success rate), not raw accuracy or raw price — match task type to the cheapest-per-correct-answer family; be skeptical of accuracy-boosting inference techniques (majority voting rarely pays for itself), and prefer budget-aware methods (TALE-EP). Also exclude cheap random guessers, which can hack the metric on forgiving multiple-choice tasks.
- **Caveats**: Self-reported (Stanford authors), ICLR 2026 paper. Binary success only; costs modeled simply (per-token API prices, no verification/tool/orchestration overhead in core results). Pricing/performance vary by provider. Benchmarks (GSM8K, MATH, GPQA, BBQ, AIME, Two-Digit Add) may be partially contaminated in pretraining, giving an optimistic frontier. Human-expert costs are estimates from market-rate sources. Metric reports expectations only (no variance/risk). Documented structural weakness: a cheap random guesser attains artificially low cost-of-pass on multiple-choice (BBQ, GPQA) tasks.
