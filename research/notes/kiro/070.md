# 070 — Token-saving updates on the Anthropic API
- **Source**: https://claude.com/blog/token-saving-updates (Anthropic, 2025-07)
- **Claim**: Three Anthropic API updates for Claude 3.7 Sonnet — cache-aware rate limits, simpler prompt caching, and token-efficient tool use — let developers increase throughput and reduce token usage/cost with minimal code changes. (Same article content as 068, hosted at the claude.com URL with a 2025-07 date.)
- **Mechanism**: (1) Prompt caching stores and reuses frequently accessed context between API calls so large docs/instructions/examples aren't resent each request. (2) Cache-aware rate limits: prompt cache READ tokens no longer count against the Input-Tokens-Per-Minute (ITPM) limit for Claude 3.7 Sonnet; the Output-Tokens-Per-Minute (OTPM) limit is unchanged. (3) Simpler cache management: setting a cache breakpoint makes Claude automatically read from the longest previously cached prefix, removing manual segment tracking. (4) Token-efficient tool use via beta header `token-efficient-tools-2025-02-19` (beta SDK / anthropic.beta.messages) cuts tool-call output tokens. (5) New `text_editor` tool makes targeted edits to portions of text (code/docs) rather than full rewrites, reducing tokens/latency and improving accuracy.
- **Numbers**: Prompt caching reduces costs by up to 90% and latency by up to 85% for long prompts. Token-efficient tool use reduces output token consumption by up to 70%; average early-user reduction 14%. For Claude 3.7 Sonnet. Caching on Anthropic API and Google Cloud Vertex AI; token-efficient tools and text_editor also on Amazon Bedrock and Vertex AI.
- **Token-cost implication**: Same as 068 — cache large stable context (codebases, knowledge bases, docs) and rely on automatic longest-prefix reads; combined with cache-aware ITPM limits this cuts cost (up to 90%) and increases throughput headroom. Enable token-efficient tool use for tool-heavy agents and use text_editor for edit workflows to avoid full-rewrite output tokens.
- **Caveats**: Self-reported by Anthropic; byte-for-byte duplicate of the article in note 068 (different URL/date — claude.com, 2025-07 vs anthropic.com, 2025-03), so it is not independent corroboration. "Up to" figures are best-case for long prompts; realistic token-efficient-tool average is 14%. Cache-read ITPM exemption stated only for Claude 3.7 Sonnet on the Anthropic API. Cognition/Devin spotlight is a vendor testimonial. No absolute prices.
