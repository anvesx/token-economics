# 219 — Batch processing (Claude)
- **Source**: https://platform.claude.com/docs/en/build-with-claude/batch-processing (Anthropic, 2025-03)
- **Claim**: The Message Batches API processes large volumes of Messages requests asynchronously at 50% of standard API prices, with most batches finishing in under 1 hour (24-hour ceiling). Prompt-caching discounts stack on top of the batch discount.
- **Mechanism**: Submit a list of requests, each with a unique custom_id and standard Messages params; the batch is processed asynchronously and independently per request. Poll processing_status (in_progress → ended) via the retrieve endpoint; download results from results_url as .jsonl (stream recommended). Results may return out of order — match via custom_id. Result types: succeeded, errored, canceled, expired (you are not billed for errored/canceled/expired). Supports nearly all Messages features (vision, tool use incl. all server tools, system messages, multi-turn, extended thinking, most beta features) mixed in one batch. Unsupported params: stream:true, speed (fast mode), fallbacks, max_tokens:0. Prompt caching works best-effort (concurrent/any-order processing); use identical cache_control blocks, steady request stream, and the 1-hour cache duration for shared context. Server tools run the same agentic loop; batch worker throttles web_search per org and auto-retries.
- **Numbers**: Discount = 50% of standard API prices (input, output, special tokens). Batch limits: 100,000 requests or 256 MB, whichever first. Most batches complete <1 hour; results available when all complete or after 24 hours (whichever first); batches expire if not done in 24h. Results downloadable/viewable for 29 days after creation. Each request max_tokens ≥1. Batch prices per MTok (input/output): Fable 5.1 $5/$25; Opus 5.5 $2/$10; Sonnet 5.5 $1/$5; Haiku 5.5 $0.05/$0.25 (prompts ≤100k tokens) or $0.25/$1.25 (>100k); Opus 5 / 4.8 / 4.7 / 4.6 / 4.5 $2.50/$12.50; Opus 4.1 and Opus 4 $7.50/$37.50; Sonnet 5 $1/$5; Sonnet 4.6/4.5/4 $1.50/$7.50; Haiku 4.5 $0.50/$2.50. Prompt-cache hit rates in batches typically 30%–98%; ephemeral cache lifetime 5 min. Extended output beta (output-300k-2026-03-24) raises max_tokens cap to 300,000; a single 300k generation can take >1 hour.
- **Token-cost implication**: For any workload that doesn't need an immediate response (evals, bulk classification/extraction, content generation, moderation), route it through Batches for a flat 50% token discount; stack prompt caching with identical cache_control blocks and the 1-hour cache to compound savings. Dry-run one request shape synchronously first to avoid validation errors (validation happens after the whole batch ends). Use extended-output batch for long-form single-turn generation.
- **Caveats**: Vendor pricing doc (dated 2025-03 but lists later models like Opus 5.5 / Fable 5.1, so price table is newer than the date). Cache hits in batch are best-effort, not guaranteed. Not ZDR or HIPAA eligible; stores inputs/outputs up to 29 days. Extended output only on Claude API and Claude Platform on AWS (not Bedrock/Google/Foundry). Batches may slightly exceed the configured Workspace spend limit due to concurrency.
