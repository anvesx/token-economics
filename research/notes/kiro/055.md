# 055 — Introducing upgrades to Codex (GPT-5-Codex)
- **Source**: https://openai.com/index/introducing-upgrades-to-codex (OpenAI, 2025-09)
- **Claim**: OpenAI released GPT-5-Codex, a version of GPT-5 optimized for agentic coding, that dynamically adapts how much it "thinks" to task complexity, plus revamped Codex CLI/IDE/cloud and automated code review.
- **Mechanism**: GPT-5-Codex adapts thinking time to task complexity — snappy on small/interactive requests, long-running on large tasks (observed working independently >7 hours on big tasks, iterating and fixing test failures). Trained on real engineering tasks (full builds, features+tests, debugging, large refactors, code review). Code review navigates the codebase, reasons over dependencies, and runs code/tests to validate correctness, matching PR intent to the actual diff. Cloud completion time cut by caching containers. Codex auto-detects and runs setup scripts; configurable internet access allows runtime dependency installs. Runs sandboxed with network access disabled by default to reduce prompt-injection/exfiltration risk. Available in Responses API only.
- **Numbers**: On OpenAI employee traffic, for the bottom 10% of user turns by model-generated tokens (incl. hidden reasoning + output), GPT-5-Codex uses 93.7% fewer tokens than GPT-5; for the top 10% it spends ~2× longer reasoning. Median completion time for new cloud tasks and follow-ups cut by 90% via container caching. SWE-bench Verified now reported on all 500 tasks (previously 477; exact score numbers not in this text). Code refactoring eval example: a Gitea PR changing 232 files / 3,541 lines. GPT-5-Codex priced same as GPT-5. Treated as High capability in Biological/Chemical domains.
- **Token-cost implication**: A coding model that scales reasoning to task difficulty means token spend concentrates in hard tasks and collapses on easy ones — don't pay flat deep-reasoning cost for trivial agent micro-decisions. Container/context caching dramatically cuts repeat-task latency and cost; rely on it for follow-ups. Use GPT-5-Codex only for agentic coding in Codex-like environments, not general-purpose work.
- **Caveats**: Self-reported by OpenAI; the 93.7%/90%/2× figures are from internal OpenAI employee traffic, not independent benchmarks. No absolute SWE-bench score or dollar figures given in this text. "Available in API soon" at original publish; Sept 23 update says it is in the Responses API at GPT-5 price. Code review recommended as an additional reviewer, not a human replacement.
