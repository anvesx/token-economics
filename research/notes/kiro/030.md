# 030 — Knowing When to Quit: A Principled Framework for Dynamic Abstention in LLM Reasoning

- **Source**: https://arxiv.org/abs/2604.18419 (arXiv / University of Oxford + Amazon, 2026-04)
- **Claim**: LLMs waste compute producing long, incorrect chain-of-thought answers. Dynamic value-thresholding abstains mid-generation when the estimated value function (probability of eventual correctness) drops below a fallback reward r⊥, provably dominating fixed-position and no-abstention baselines and saving tokens.
- **Mechanism**: Model generation as a KL-regularized RL / MDP with sparse binary terminal reward (1 if correct, 0 otherwise) and an added abstention action ⊥ with fixed reward r⊥. The decision rule a(π) abstains at a prefix whenever the value function V(x,y₁:ₜ) < r⊥, else continues with the base policy. For binary rewards and β=0, the value function equals P(correct | current prefix), so it is estimated by a two-layer MLP probe on the final-layer hidden state, trained with binary cross-entropy in parallel at all non-terminal token positions of completed trajectories (one gradient target = the trajectory's correctness label). The threshold Tα is set as the α-quantile of estimated values on a small held-out set; selective accuracy depends only on the ranking V induces, so it's invariant to monotone miscalibration. r⊥ gives direct control: lower r⊥ → higher selective accuracy, higher r⊥ → more compute savings.
- **Numbers**: The MLP probe adds ~10^4 parameters (negligible). Phi-3 baseline accuracy: GSM8K 87%, OlympiadBench 16%; Qwen2.5 baseline: GSM8K 88%, OlympiadBench 43%. OlympiadBench at 90% abstention: Phi-3 dynamic 64% selective acc vs 34% best input-only / 33% best fixed-position (≈2×); Qwen 91% vs 69% input / 75% fixed. GSM8K: dynamic 0.92 selective acc at α=0.1 → 0.99 at α=0.9 (both models). Token savings retained vs input-only methods: 63–86% at 10% abstention, rising to 92–95% at 90% abstention. Threshold tracks target abstention rate with mean absolute error <1.2 percentage points. Abstention occurs in the first half of generation on average. Toxicity (RealToxicityPrompts, Qwen2.5-Math-7B): dynamic reaches 1.00 non-toxic rate at α=0.3. Prior refs: Zhang et al. 2025 early-exit cut tokens 24% w/o accuracy loss; Manvi et al. prune 50–75% of samples; probes predict CoT success 60–76% before any token.
- **Token-cost implication**: Add a cheap hidden-state probe to kill unpromising reasoning traces early, concentrating compute on answerable prompts. Savings and selective accuracy are tunable via a single threshold; the upfront cost (generate trajectories + fit probe) is quickly amortized, and the probe transfers across datasets with <1.2 pp error.
- **Caveats**: Self-reported (Oxford/Amazon). Theoretical guarantees assume an oracle value function; experiments estimate it. Tested only on two LLMs (Qwen2.5-Math-7B, Phi-3-mini-4k) and math reasoning (GSM8K, OlympiadBench) plus one toxicity task. k for fixed-position baselines (20/100) is admittedly arbitrary. Fails when hidden states don't encode correctness signal; fixed r⊥ ignores partially-solved questions. When r⊥ is specified directly (not via quantile), calibration matters and shows room for improvement.
