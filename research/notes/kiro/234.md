# 234 — Track and optimize coding agent usage (Langfuse)
- **Source**: https://langfuse.com/coding-agents (Langfuse, no date)
- **Claim**: Coding agents make AI spend unpredictable, so teams should govern it centrally — track spend per team/developer/repo/use case and trace sessions to improve token efficiency — via either an LLM gateway (platform teams) or hooks (single-agent tracing).
- **Mechanism**: Two setup patterns. (1) Via gateways: route coding-agent traffic through a gateway that enforces budgets (LiteLLM, OpenRouter, or Langfuse AI Gateway (beta)), give teams/departments a spend envelope, and trace every call into Langfuse for dashboards by team/repository/model/use case with threshold alerts. A gateway cannot be disabled by a developer the way a local hook can. (2) Via hooks: hook integrations (Claude Code, Codex, OpenCode, Cursor, GitHub Copilot) log tool calls, retries, skill usage, and model turns, attach a user identifier so dashboards break cost down per person/repo, and let you compare sessions to find unused tools, repeated file reads, bloated context, failed tool loops, and prompts that should become shorter or shared org/team "skills"; roll a skill out once and measure whether token spend actually drops.
- **Numbers**: Illustrative dashboard figures only (sample "Last 30 days · Eng"): Implementation $486, Code review $379, Planning $321, Bug fix $178, Documentation $104, Other $72; Total spend $1,540; Sessions 4,812; Budget left 28%. These are example/mock UI numbers, not measured results.
- **Token-cost implication**: For coding-agent fleets, put budget enforcement at a gateway (hard, non-bypassable) and use tracing to attribute spend per developer/repo/task category, then target the highest-spend categories (e.g. implementation, code review) for optimization. Convert repeated context and repeated work into shared skills and verify the token reduction with before/after traces rather than assuming.
- **Caveats**: Vendor marketing/landing page; the spend breakdown numbers are illustrative dashboard mockups, not independently measured savings. No benchmark, no quantified efficiency gain. Prescriptive guidance without evidence of magnitude.
