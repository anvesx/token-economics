# 191 — Spend limits (Cloudflare AI Gateway)
- **Source**: https://developers.cloudflare.com/ai-gateway/features/spend-limits/ (Cloudflare, 2026-11)
- **Claim**: Spend limits set dollar-cost budgets on an AI Gateway; when cumulative spend hits the limit in a time window, the gateway blocks further requests with a 429 (or falls back to a cheaper model) until the window resets.
- **Mechanism**: Each rule defines a dollar budget over a rolling or fixed window. The gateway computes each request's cost from token usage and model pricing and tracks cumulative spend in real time. Before forwarding, it evaluates all applicable rules at once; if any rule is over budget the request is blocked (429). Rules scope by dimension — provider, model, or custom metadata (e.g. user ID, team, agent_id) — each in "Split by value" (independent budget bucket per distinct value) or "Filter by value" (rule applies only when the dimension equals a set value); unconfigured dimensions share one bucket. With Cloudflare Access, the authenticated user ID is auto-added as reserved `cf.user_id` metadata for per-user budgets; without Access, pass your own `user_id` metadata. On exceed: either block (default) or route to a fallback model via a dynamic route.
- **Numbers**: Maximum 20 spend-limit rules per gateway. Example fallback: `anthropic/claude-opus-4.7` primary with fallback to `@cf/moonshotai/kimi-k2.6`. No prices given.
- **Token-cost implication**: Enforce per-user/per-team/per-agent dollar budgets centrally instead of in app code; attach custom metadata (agent_id, user_id) to get per-entity buckets; pair with a dynamic-route fallback to a cheaper model so hitting budget degrades gracefully instead of erroring.
- **Caveats**: Vendor doc. Spend limits are eventually consistent — the current request's cost is recorded after completion, so a burst of concurrent requests can briefly exceed the limit before enforcement catches up. Cost tracking is best-effort estimation from token counts and model pricing; the provider dashboard is authoritative for exact billing. `cf.user_id` is only present on Access-protected custom-domain requests with a valid user subject (not service-token requests). Max 20 rules.
- **Topic**: agent-cost
