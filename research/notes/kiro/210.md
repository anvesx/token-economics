# 210 — Requests in GitHub Copilot (legacy)
- **Source**: https://docs.github.com/en/copilot/concepts/billing/copilot-requests (GitHub, none)
- **Claim**: GitHub Copilot bills "premium requests" per user prompt multiplied by a per-model multiplier; agentic tool calls the model makes autonomously do not count, only prompts you send. Plans carry a fixed monthly premium-request allowance with overage priced per request.
- **Mechanism**: A request = any user interaction (chat prompt, code generation, extension trigger). Premium requests are consumed as one-per-user-prompt × model multiplier across Copilot Chat (ask/edit/agent/plan modes), Copilot CLI, Copilot Spaces, Codex VS Code integration, third-party coding agents. For agentic features only prompts you send count; autonomous tool calls do not (e.g. /plan in CLI = 1 premium request, each follow-up = another). Copilot cloud agent = 1 premium request per session × multiplier, plus 1 per real-time steering comment × multiplier. Copilot code review = flat 13 premium requests per review (PR or IDE) starting June 1 2026. Allowances reset on the 1st of each month 00:00 UTC; unused requests do not roll over. Running out drops you to included models (rate-limited) for the rest of the month. Spark and cloud agent tracked in dedicated SKUs from Nov 1 2025.
- **Numbers**: Copilot code review multiplier = 13 (each review deducts 13 premium requests), effective June 1 2026. Copilot Pro: $10/month (free for some), 300 premium requests/month. Copilot Pro+: $39/month, 1500 premium requests/month. Additional premium requests: $0.04/request. Inline suggestions: unlimited on paid plans. Billing for premium requests began June 18 2025 (GitHub.com) / Aug 1 2025 (GHE.com).
- **Token-cost implication**: Budget by premium-request count, not tokens. Agent/plan workflows are cheap on the request meter because autonomous tool calls are free — the cost driver is how many prompts you send and the model multiplier you pick. Avoid triggering Copilot code review casually: each run costs 13× a normal request. Pick lower-multiplier models for routine prompts; monitor the monthly counter since it resets with no carryover.
- **Caveats**: Vendor billing doc; "legacy" page applying only to Pro/Pro+ annual subscribers who stayed on request-based billing after June 1 2026. Model multiplier table is linked, not included here. No token-level pricing given. Allowances/exclusions (e.g. no add-on requests via GitHub Mobile iOS/Android) subject to change.
