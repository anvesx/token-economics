# 256 — Serverless Inference Overview (Fireworks)
- **Source**: https://docs.fireworks.ai/serverless/overview (Fireworks, 2026-11)
- **Claim**: Fireworks Serverless is multi-tenant, pay-per-token inference for popular open models on Fireworks-managed infrastructure, with four modes (Standard, Priority, Fast, Ultra-fast) sharing one framework but routing and pricing differently; prompt caching is on by default and billed at a discount.
- **Mechanism**: Point the client at api.fireworks.ai, pay per token. Modes: Standard (default, no param), Priority (`service_tier: "priority"`, premium price, better reliability at peak), Fast (switch model ID to a Fast variant for latency-sensitive loads), Ultra-fast Preview (switch to an Ultra-fast model ID, premium, targets 6–8x generation speed). Billing has three dimensions: input tokens, cached input tokens (discounted, default 50% of input), and generated tokens. Decision models (e.g. Rune 26B-A4B) are billed on input only and never generate tokens. The `usage` object (prompt_tokens/completion_tokens/total_tokens) is the source of truth for billing. Prompt caching is replica-local, so pass a stable `x-session-affinity` key (or OpenAI `user` field) to pin prompts sharing a prefix to the same replica and maximize hit rate. Response headers expose `fireworks-prompt-tokens`, `fireworks-cached-prompt-tokens`, and several X-Ratelimit TPM headers; streaming needs `perf_metrics_in_response`.
- **Numbers**: Cached input tokens discounted at default 50% of input price (text and vision models, unless a model lists a different cached rate). Batch inference billed at 50% of standard Serverless rates on both input and output. Ultra-fast targets 6–8x generation speed. Model lifecycle: ≥2 weeks advance notice before removing a model (longer for popular ones). No absolute $/1M-token figures on this page.
- **Token-cost implication**: Default to Standard + prompt caching (route repeat-prefix traffic with x-session-affinity to actually realize the 50% cached discount); send large async jobs through Batch for 50% off both input and output; only pay the Priority/Ultra-fast premium for reliability/latency-critical paths. Trust the response `usage` object, not estimates, for what you were billed.
- **Caveats**: Vendor doc, self-reported, no independent benchmarks and no concrete per-token prices on this page (deferred to the pricing page). "6–8x" is an aim for a Preview mode. Cached discount default is 50% but varies by model. Higher spend tiers unlock higher TPM caps; Serverless carries no SLA.
