# 156 — Phi-4-Mini Technical Report: Compact yet Powerful Multimodal Language Models via Mixture-of-LoRAs
- **Source**: https://www.microsoft.com/en-us/research/publication/phi-4-mini-technical-report-compact-yet-powerful-multimodal-language-models-via-mixture-of-loras (Microsoft Research, 2025-02)
- **Claim**: Phi-4-Mini is a 3.8B-parameter language model that matches models twice its size on math/coding reasoning, and Phi-4-Multimodal adds vision and speech/audio via LoRA adapters and modality-specific routers in a single model.
- **Mechanism**: Phi-4-Mini is trained on curated high-quality web + synthetic data (emphasizing math/coding). It uses an expanded 200K-token vocabulary for multilingual support and group query attention (GQA) for more efficient long-sequence generation. Phi-4-Multimodal integrates text, vision, and speech/audio through a Mixture-of-LoRAs approach: LoRA adapters plus modality-specific routers let multiple inference modes (vision+language, vision+speech, speech/audio) run without interference. A further-trained experimental version boosts reasoning.
- **Numbers**: 3.8 billion parameters (language model); vocabulary 200K tokens; speech/audio LoRA component only 460 million parameters; ranks first on OpenASR leaderboard (as of report). Experimental reasoning version reportedly on par with or surpassing DeepSeek-R1-Distill-Qwen-7B and DeepSeek-R1-Distill-Llama-8B. No price-per-token or latency figures.
- **Token-cost implication**: A 3.8B model with GQA and small modality LoRAs can replace much larger models for math/coding/ASR workloads, cutting serving cost and enabling edge/local deployment; GQA reduces long-sequence generation cost.
- **Caveats**: Vendor (Microsoft Research) self-reported benchmark claims; the fetched text is the abstract/landing page only, so exact benchmark tables, datasets, and evaluation conditions are not included here. "Matching models twice its size" is scoped to math/coding reasoning tasks.
