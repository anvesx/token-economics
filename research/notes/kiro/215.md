# 215 — Manage costs effectively (Claude Code)
- **Source**: https://code.claude.com/docs/en/costs (Anthropic, 2026-11)
- **Claim**: Claude Code bills by API token consumption; token cost scales with context size, and the doc gives tracking tools (/usage, /insights, OpenTelemetry) plus concrete tactics to cut token usage (clear between tasks, right-size model and reasoning, hooks/skills, subagents).
- **Mechanism**: /usage Session block shows per-model input/output/cache-read/cache-write tokens and a locally computed dollar figure (list price unless a modelPricing managed-settings table sets contracted rates; 1.1× data-residency multiplier applies to those responses). Prompt cache (main) line reports request count, % input from cache, misses, expected rebuilds (compaction/tool-result clearing), warm/cold TTL. Plan usage breakdown attributes recent usage to skills/subagents/plugins/MCP servers and recommends changes for any behavior ≥10% of usage; the `f` fix shortcut runs /effort commands and prompts Claude to apply other recommendations. Cost-reduction levers: /clear between unrelated tasks (clearing costs nothing vs /compact which reads the whole context); choose Sonnet over Opus (Opus reserved for complex reasoning; haiku for simple subagents); defer MCP tool definitions / prefer CLI tools (gh, aws, gcloud); PreToolUse hooks to grep/filter verbose output before Claude sees it; move specialized instructions out of CLAUDE.md into on-demand skills (keep CLAUDE.md <200 lines); lower extended-thinking effort via /effort or MAX_THINKING_TOKENS; delegate verbose ops to subagents so only summaries return.
- **Numbers**: Enterprise average ~$13 per developer per active day and $150-250 per developer per month; costs stay below $30 per active day for 90% of users. Example session: Total cost $0.55 — claude-sonnet-4-6: 1.2k input, 5.3k output, 940.0k cache read, 50.0k cache write. Example cache line: 14 requests, 91% of input tokens from cache, 2 misses (310.2k tokens re-cached), 1h TTL. Data-residency multiplier 1.1×. CLAUDE.md target <200 lines. Agent teams use ~7× more tokens than standard sessions (teammates in plan mode). /insights analyzes up to 200 new sessions per run. cleanupPeriodDays default 30 days. Idle goal check-ins capped at 3 per goal between prompts. Rate-limit recommendations per user: 1-5 users 200k-300k TPM / 5-7 RPM; scaling down to 500+ users 10k-15k TPM / 0.25-0.35 RPM (200 users × 20k = 4M total TPM example).
- **Token-cost implication**: Treat long-lived sessions as the main cost leak — every request resends full conversation (at cached rate), so /clear between tasks and keep context small. Set a modelPricing table so reported figures match contracted rates. Use the /usage breakdown + `f` to act on the biggest-share behaviors. Keep agent teams tiny (≈7× cost), run subagents on smaller models, and preprocess verbose output with hooks rather than feeding it to the model.
- **Caveats**: Vendor doc; the $13/day and $150-250/month figures are "across enterprise deployments" with no methodology or sample size stated. Dollar figures are local estimates, not invoices. Many features gated behind specific Claude Code versions. Usage figures are per-machine local history (exclude other devices and claude.ai).
