# 260 — Fast Open Model Inference: Serverless and On-Demand (Fireworks)
- **Source**: https://fireworks.ai/product/inference (Fireworks, 2026-11)
- **Claim**: Fireworks' inference product page claims a proprietary serving stack (custom kernels, speculative decoding, advanced caching, FireOptimizer) that delivers up to 4x higher throughput than vLLM with industry-leading latency, optimized for "cost per finished task" rather than raw price per token.
- **Mechanism**: One optimized stack from GPU memory layout to runtime; custom attention kernels + speculative decoding + caching + FireOptimizer tuning per workload. Cost-per-finished-task framing combines: (1) KV caching + session affinity to keep each agent on the same server where its context is already cached (high cache hit rate), (2) intelligent routing models that are both cache- and task-difficulty-aware to pick the right model per turn, and (3) execution modes matched to the job — Batch (async, 50% off), Fast (100+ TPS interactive), Priority (peak-traffic reliability), Reserved Throughput (guaranteed capacity). Prefill and decode run in separate independently-scaling GPU pools. Quality gates applied before a model serves. Deployment options: Serverless (pay per token), Reserved Throughput (reserved $/minute, SLA), Bring-Your-Own-Cloud (stack runs on your k8s).
- **Numbers**: Up to 4x higher throughput than vLLM. Cache hit rates up to 99.6% on long agent sessions; cached input billed at half price or less, cache writes free. Fast mode "100+ TPS". Batch 50% off. Quality thresholds: KL divergence below ~0.007 and token rejection below ~3% vs an unquantized reference. Multi-region deployments reached 99.99%+ request success across 30+ regions. Customer quote (Juicebox): task time 25s → 2–3s, ~80% latency improvement, annual spend $4M → $800K (an 80% cost reduction). Notion quote: latency ~2s → 350ms. Model prices shown: Kimi K3 $3/M input, $15/M output (1,048,576 ctx); DeepSeek V4.1 Flash 1017 $0.3/M input, $1.2/M output; MiniMax M3.1 Flash $0.15/M input, $0.6/M output. DeepSeek-V4.1-Flash claimed "Astra-level DeepSWE at 1/15th the cost".
- **Token-cost implication**: Optimize for cost per finished task, not sticker $/token: exploit session affinity + KV caching to push cache hit rates up (cached input ≤50% price, writes free), use intelligent routing to send easy turns to cheaper models, and pick the execution mode per job (Batch for async −50%, Reserved for guaranteed throughput). For big savings consider cheaper "Flash" variants that claim frontier-level quality at a fraction of the cost.
- **Caveats**: Vendor marketing page — "up to 4x vs vLLM", "up to 99.6%" cache, and the $4M→$800K / 80% figures are self-reported best-case claims and customer testimonials, not independently verified, and conditions (workload, config) are unspecified. Quality thresholds (~0.007 KL, ~3% rejection) are Fireworks' own published limits. Prices are point-in-time catalog values that change.
