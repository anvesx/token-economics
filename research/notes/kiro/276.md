# 276 — Inference pricing (Together AI)
- **Source**: https://docs.together.ai/docs/inference/pricing (Together AI, 2026-07)
- **Claim**: Together AI's serverless inference pricing docs explain the per-unit billing model (per token for text, per megapixel/image, per second for audio/video), and describe cost levers: batch workloads, automatic prefix caching, and geo-specific (US-only) inference.
- **Mechanism**: Serverless billing is usage-based with no minimums/provisioning cost. Units by model type: chat/language/embedding/rerank per input+output token; image per megapixel OR provider per-request charge; video per second; speech per second of audio. Batch inference runs asynchronous workloads at a discount. Cached input: select chat models bill a repeated prompt prefix at a steep discount — caching is automatic (no header/param/toggle), prefix-based (only the longest matching prefix counts; tokens after the first difference bill at standard rate), and best-effort/short-lived (shared fleet cache, entries evicted as traffic shifts, no guaranteed hits or retention window). For predictable caching, use a dedicated endpoint where prompt caching is on by default and scoped to your own replicas. Only models with a value in the "Cached input pricing" column support cached billing. Geo-specific (US-only) inference: send requests to `us-api.together.ai`. Image models bill either by true per-megapixel rate (doubling pixels doubles cost, scaled up past default step count) or by passthrough provider per-image estimate (varies with resolution, quality, reference images, grounded search).
- **Numbers**: Batch workloads discounted up to 50% ("up to 50% lower cost"). US-only (geo-specific) inference costs 1.25× standard serverless rates for input, cached input, and output tokens. Image resolution scaling: a 4096×4096 image ≈ 16× the pixels of 1024×1024 and ≈ 64× the pixels of 512×512. Minimum cacheable behavior and per-model token rates are not in this page (point to catalog/pricing page). No specific per-1M-token dollar figures on this page.
- **Token-cost implication**: Move non-real-time workloads to batch for up to 50% savings. Structure prompts so the shared/stable content is a common prefix to maximize automatic prefix-cache hits; put variable content at the end. For guaranteed cache hits (predictable latency/cost), use a dedicated endpoint rather than relying on the best-effort serverless cache. Avoid US-only inference unless you need it — it adds a flat 25% surcharge. For image workloads, test one image at target resolution/quality before committing, since cost scales with the square of linear resolution.
- **Caveats**: Vendor pricing documentation; describes billing mechanics, not independent benchmarks. Concrete per-model rates and the exact cached-input discount amount are not on this page (deferred to the catalog and together.ai/pricing). "Up to 50%" and "1.25×" are the only hard multipliers. Serverless caching is explicitly best-effort with no guarantees. Image per-image estimates come from external providers and may not state the output size they were priced at.
