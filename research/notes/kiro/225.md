# 225 — xAI pricing
- **Source**: https://docs.x.ai/developers/pricing (xAI, none)
- **Claim**: xAI publishes per-1M-token text prices (with separate cached and long-context rates), per-item tool-invocation fees, and modifiers for Batch (discount), Priority (premium), US regional endpoint (premium), and a "Fast" variant — plus media, voice, storage, and violation fees.
- **Mechanism**: Text models bill input / cached / output per 1M tokens, with a second "long context" tier that applies to ALL tokens in a request once the prompt crosses the model's long-context threshold (≥200k for grok-4.x). Cached tokens are billed at a reduced rate (roughly 1/4 of input). Server-side tools cost token usage PLUS a per-invocation fee (agent decides how many calls, so cost scales with query complexity). Batch API discounts all token types (input/output/cached/reasoning) but varies by model. Priority Processing bills 2× all token types for higher scheduling priority, only when the response confirms "service_tier":"priority"; caching discounts applied before the 2× multiplier. US regional endpoint bills 1.1× all token types (caching discount applied first). Grok 4.7 Fast = same model on faster infra, 2× standard (1.5× long-context), Cursor/Grok Build only.
- **Numbers**: grok-4.7 (500k ctx, long ≥200k): short $2.00 input / $0.50 cached / $6.00 output per 1M; long $4.00 / $1.00 / $12.00. grok-build-0.1 (256k): $1.00/$0.20/$2.00 short, $2.00/$0.40/$4.00 long. grok-4.6: same as 4.7. grok-4.5: $2.00/$0.30/$6.00 short. grok-4.3 and grok-4.20 variants (1M ctx): $1.25/$0.20/$2.50 short, $2.50/$0.40/$5.00 long. Tool invocation: Web Search $5/1k calls; X Search $5/1k posts + $10/1k profiles; Code Execution $5/1k calls; File Attachments $5/1k calls; Collections Search (RAG) $2.50/1k calls; image/x-video understanding token-based. Batch discount 20% for grok-4.7/4.6/4.5/4.3/4.20 variants (others no discount; text/language only). Priority = 2× all token types. US regional (us.api.x.ai) = 1.1×: grok-4.7 = $2.20/$0.55/$6.60 (<200k), $4.40/$1.10/$13.20 (>200k). Grok 4.7 Fast: <200k $4.00/$1.00/$12.00, >200k $6.00/$1.50/$18.00. Voice: S2S $0.08/min ($4.80/hr); STT $0.10/hr REST, $0.20/hr streaming; TTS $15/1M chars. Storage: file $0.025/GiB/day, collection $0.10/GiB/day; downloads $0.20/GiB. Usage-guideline violation fee $0.05/request (Responses API, caught pre-generation). US endpoint = 10% premium. Last updated October 10 2026.
- **Token-cost implication**: Lean on cached-token pricing (~4× cheaper than input) and keep prompts under the 200k long-context threshold, since crossing it reprices every token (including cached) at 2× the base rate. For non-latency-sensitive bulk work use Batch for a 20% discount on eligible Grok 4.x models (stacks across all token types). Avoid Priority (2×) and the US regional endpoint (1.1×) unless latency/residency is required. Budget server-tool invocation fees separately from tokens — agentic queries can rack up $5/1k web-search or code-exec calls independent of token spend.
- **Caveats**: Vendor pricing page, no benchmarks or measured savings — list rates only. Batch discount only 20% and only for listed models (text/language only; media billed at standard rates in Batch). Fast variant not on the public API. Prices change (page dated Oct 10 2026; some items newer, e.g. Nov 2 2026 Imagine retirement referenced).
