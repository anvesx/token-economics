# 193 — Other LLM gateways (Claude Code)
- **Source**: https://docs.anthropic.com/en/docs/claude-code/llm-gateway (Anthropic, undated)
- **Claim**: Claude Code can route through an organization's existing LLM gateway (any product exposing a supported API format) to centralize credentials, usage tracking, cost controls, audit logging, and provider switching — at the cost of the org operating that gateway as infrastructure.
- **Mechanism**: Deploy the gateway with the org's provider credential; issue each developer a gateway credential (so usage attributes per developer and offboarding revokes one credential); distribute base URL + credential via a managed settings file so developers configure nothing. `ANTHROPIC_BASE_URL` points Claude Code at the gateway. To pin the gateway as the only allowed destination, set `allowedProviders` to `["customEndpoint"]` in managed settings with the gateway URL in the `env` block (requires Claude Code v2.1.285+); for provider-specific endpoints like `ANTHROPIC_BEDROCK_BASE_URL` the `allowedProviders` entry names the variable. While a gateway credential or `apiKeyHelper` is active, requests carry that credential instead of the claude.ai subscription login, so subscription usage limits don't apply and traffic is billed per token to the credential owner (org Anthropic Console account, or Bedrock/Google Cloud/Microsoft Foundry account). Setting only `ANTHROPIC_BASE_URL` without a gateway credential keeps the saved claude.ai login active, so subscription limits and billing still apply.
- **Numbers**: none (one version string: Claude Code v2.1.285+)
- **Token-cost implication**: Route developer traffic through a gateway to enforce budgets/rate limits and attribute per-token spend centrally; be aware that supplying a gateway credential switches billing from a flat subscription to per-token billing against the credential owner's account — a potential cost increase if the subscription was the cheaper path.
- **Caveats**: Vendor doc, no figures. Anthropic doesn't endorse/maintain/audit third-party gateways and doesn't support routing Claude Code to non-Claude models through any gateway. The gateway must be kept updated as Claude Code adds features, or it breaks them. Gateways passing traffic to Anthropic must forward the OAuth capability in `anthropic-beta`.
- **Topic**: routing
