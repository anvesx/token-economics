# 207 — The builder's guide to GPT-5.6
- **Source**: https://openai.com/index/builders-guide-to-gpt-5-6 (OpenAI, 2026-10)
- **Claim**: GPT-5.6 delivers frontier-level agent performance at a fraction of prior cost by combining smaller models, lower reasoning effort, and new Responses API primitives (retained reasoning, compaction, programmatic tool calling, native multi-agent). The same harness plus architectural controls can roughly triple task performance while using far fewer output tokens.
- **Mechanism**: Four levers. (1) Model selection: smaller 5.6 models (Luna, Terra) with more test-time compute match prior flagships (5.4/5.5) at much lower cost, used for high-volume/latency-sensitive/extraction steps. (2) Lower reasoning effort now often beats prior high-effort defaults, so drop the effort knob. (3) Responses API primitives trained end-to-end: persist reasoning across turns + native compaction to compress long conversations; native multi-agent orchestration (primary agent spawns parallel subagents, synthesizes output — same as ChatGPT "ultra"); programmatic tool calling where the model writes JavaScript to filter/aggregate/orchestrate tool outputs outside the context window, reserving tokens for judgment. (4) Prompt caching: TTL extended to ≥30 min, deterministic cache breakpoints within context, prompt_cache_key to land on same inference engine.
- **Numbers**: Agents' Last Exam: 5.6 Sol "low" reasoning > 5.5 "high" (constant harness). BrowseComp: GPT-5.5 Extra High 84.36% at $33.27 (3 months prior); GPT-5.6 Luna Extra High 84.04% at $1.33. Luna: 98% of 5.5 extraction accuracy at 1/18 the cost (Hypha). Browser Use: Luna completed 78% of 106 hardest browser tasks for ~$14 vs SOTA 80% for ~$235. PlayerZero code exploration: inference cost −64%, response time −90%, F1 +5 points. ARC-AGI-3: 5.6 Sol 13.3% standard harness → 38.3% with retained reasoning + compaction, using ~6× fewer output tokens. Rogo financial research: matched rubric quality with 21% fewer input tokens via programmatic tool calling. Ploy: cache breakpoints + workspace-specific keys on a shared 29,000-token prompt cut uncached input by 28%.
- **Token-cost implication**: Stop defaulting to the flagship at max reasoning for every step. Route extraction/retrieval/repeated steps to smaller models; lower reasoning effort and measure; persist reasoning + enable native compaction for long horizons; push deterministic data-wrangling into programmatic tool calling so intermediate tool outputs never enter the model context; set deterministic cache breakpoints and stable prompt_cache_key to exploit the 30-min cache.
- **Caveats**: Vendor blog; all figures are customer testimonials or OpenAI's own benchmark runs (self-reported, not independent). Model names (Sol, Luna, Terra) and dated benchmarks are specific to OpenAI's harness and may not transfer. Cost comparisons mix "3 months ago" prices with later price cuts. No methodology detail on how accuracy/F1 were measured.
