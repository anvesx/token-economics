# 263 — Usage-based billing for organizations and enterprises (GitHub Copilot)
- **Source**: https://docs.github.com/en/copilot/concepts/billing-and-usage/organizations-and-enterprises/billing (GitHub, date not stated in file)
- **Claim**: Under usage-based billing, metered GitHub Copilot usage in orgs/enterprises is measured in "GitHub AI Credits" where 1 AI credit = $0.01 USD; each interaction's cost depends on the model and the input/output/cached tokens consumed, converted to credits.
- **Mechanism**: An interaction consumes input tokens, output tokens, and cached tokens; each token is priced by the model used and the total converts to AI credits. Credit-billed features: Copilot Chat, Copilot CLI, Copilot cloud agent, Copilot Spaces, Spark, third-party coding agents. Inline code completions and next edit suggestions are NOT billed and stay unlimited (available even at $0 budget or when a spending limit is hit). Included credits are pooled at the billing-entity level (not per-user buckets), drawn down first, then metered overage billed at published per-credit rates. Adding licenses mid-cycle grows the pool immediately; removing them shrinks it only next cycle; unused credits do not carry over and reset to full at 00:00:00 UTC on the 1st of each calendar month. Cost controls: user-level budgets (hard stop on an individual's total consumption incl. pooled usage; $0 blocks credit features), cost-center budgets, org-level budgets, and enterprise spending limits (these limit metered charges); enable "Stop usage when budget limit is reached" to enforce. GitHub Apps using an installation token bill to the owning org under its policies; you cannot budget an individual app/installation.
- **Numbers**: 1 AI credit = $0.01 USD (so $10 budget = 1,000 credits). Included monthly allowance per user: Copilot Business 1,900 credits; Copilot Enterprise 3,900 credits. Example: enterprise with 100 Business users = shared pool of 190,000 credits. Copilot access / Standalone = no included allowance (metered from first use). Reset at 00:00:00 UTC on day 1 of each calendar month. Minimum client versions for correct pricing display: VS Code 1.120, Visual Studio 2022 17.14.33, Visual Studio 2026 18.6.0, SSMS 22.6, JetBrains plugin 1.9.1, Eclipse 0.18.0, Xcode 0.50.0, Copilot CLI 1.0.48.
- **Token-cost implication**: Treat Copilot spend as token-metered: lightweight-model chat costs a fraction of a credit while long frontier-model agent sessions across many files cost far more, so steer heavy agent work deliberately and lean on free inline completions/next-edit suggestions for routine coding. Configure pooled + user/cost-center/org budgets and enterprise spending limits before rollout; disable the "AI credits paid usage" policy (on by default for Business/Enterprise) if you want a hard stop at the included pool with no overage.
- **Caveats**: Vendor doc, no benchmarks; actual per-model token prices and model list are on a separate "Models and pricing" page, not here. Additional usage is enabled by default for Business/Enterprise (can silently incur overage) and may be capped. An enforced spending limit can block a user before their own user-level budget. Older client versions may show incorrect pricing/usage.
