# 242 — Budget Limits (Portkey / Prisma AIRS AI Gateway)
- **Source**: https://portkey.ai/docs/product/ai-gateway/virtual-keys/budget-limits (Portkey, 2026-11; page last modified 2026-09-22)
- **Claim**: Portkey's AI Gateway lets you set cost (USD) or token budget limits on providers/integrations; once reached the key auto-expires to prevent overspending.
- **Mechanism**: When creating a provider integration you set a cost-based limit (USD) and/or a token-based limit (input+output tokens). Limits apply only to requests made after the limit is set (never retroactively); spend counter starts from zero. Once set, a limit cannot be edited by any org member — to change it you duplicate the provider and recreate with a new limit. Optional alert thresholds send email notifications before the cap is hit while usage continues until the full limit. Periodic reset options: none, weekly (Sunday 12 AM UTC), or monthly (1st calendar day, 12 AM UTC). Spend/usage tracked in the Analytics tab filtered by provider and timeframe. Budgets can also be enforced at the workspace level across keys.
- **Numbers**: 1 AI credit — n/a here. Minimum cost limit $1; minimum token limit 100 tokens. Weekly reset Sunday 12 AM UTC; monthly reset 1st of month 12 AM UTC. A request log showing "0 cents" in the COST column means that model's pricing is not tracked and won't count toward the budget.
- **Token-cost implication**: Use provider-level budget caps (or workspace-level enforcement) as a hard spending guardrail; set alert thresholds below the cap for early warning. Note caps apply only going forward and only to models Portkey has pricing for, so unpriced models silently escape the budget.
- **Caveats**: Vendor doc (self-reported, no benchmarks). Feature is Enterprise-plan-only plus select Pro customers. Limits are immutable once set and only count models with Portkey pricing support. No independent measurement.
