# 093 — THINK-Bench: Evaluating Thinking Efficiency and Chain-of-Thought Quality of Large Reasoning Models
- **Source**: https://arxiv.org/abs/2505.22113 (arXiv / Jilin University, 2025-05)
- **Claim**: THINK-Bench is a benchmark that jointly evaluates reasoning efficiency and chain-of-thought quality of large reasoning models, revealing that most LRMs overthink on easy questions — generating excessive, redundant reasoning tokens with little accuracy benefit.
- **Mechanism**: 1,375 annotated samples across math/physics/chemistry, each at Simple/Difficult levels, with key reasoning steps annotated (Claude 3.7 Sonnet generates reference reasoning chains; critical steps extracted, multiple valid paths kept). Nine metrics computed by splitting model output into thinking content (partitioned into steps) vs output content, judged by Claude 3.7 Sonnet. Efficiency metrics: Tokens (total), First Correct Tokens (tokens until first correct answer), Efficiency = (1/N)·Σ(First Correct Tokens / Total Tokens) (0 if never correct), Reflection Tokens (from first correct answer to end), Reflection Quality = |valid reflections|/|all reflections| (valid = correctly identifies a prior error or confirms with new insight), Thought Num (count of discourse markers like "alternatively"/"wait"). CoT-quality metrics: Recall = |covered reference steps|/|reference steps|, Precision = |matched model steps|/|model steps|, plus Accuracy.
- **Numbers**: Dataset: 1,375 questions (929 multi-choice, 446 free-form; 293 math, 590 physics, 492 chemistry); 13,311 key-step annotations, avg 9.68 inference steps; avg question length 422.42, avg answer length 7.59, max question 1893, max answer 372. 11 models evaluated. Efficiency: Grok-3-mini-beta highest 61.69%, Deepseek-r1-distill-qwen-32b 52.62%, 14b 50.70%; Qwen3-235b-a22b 46.14%, Qwq-plus 44.58% (lowest). CoT quality: Qwen3-235b-a22b reflection quality 92.16%, precision 86.97%, recall 85.80%; Ernie-x1-turbo-32k reflection 90.97%, precision 88.67%, recall 82.03%. Thought Num: Qwq-plus highest 22.63, Qwen3 13.35; Claude-3-7-sonnet 0.28, Grok-3-mini-beta 0.38 (lowest). Tokens: Qwq-plus 5738.37 (reflection 3091.64), Qwen3-235b 4969.05 (reflection 2520.76); Claude-3-7-sonnet under 1000 (942.82, reflection 496.73). Accuracy: Qwen3-235b 94.91%, Claude-3-7-sonnet 94.25%; smallest distill (1.5b) 62.91%. By difficulty, efficiency on simple < difficult (overthinking on easy): e.g., Claude simple 0.52 vs difficult 0.47; tokens Qwen3 simple 2818.69 vs difficult 7128.80. Math uses most tokens / lowest efficiency vs chemistry/physics.
- **Token-cost implication**: Measure reasoning cost with process-aware metrics (First Correct Tokens, Efficiency ratio, Reflection Tokens/Quality, Thought Num), not just final-answer accuracy. Builders should target early-exit / dynamic reasoning-depth mechanisms because LRMs waste large token budgets reflecting after already reaching the correct answer, especially on simple questions; smaller/efficient models (Grok-3-mini, Claude 3.7 Sonnet) can reach correct answers with far fewer tokens than large verbose models.
- **Caveats**: Self-reported benchmark; covers only math/physics/chemistry. Relies on LLM-as-judge (Claude 3.7 Sonnet) for step evaluation — Claude 3.7 is both an evaluated model and the judge, risking bias. Annotation may miss valid but unannotated reasoning paths. Some models (DeepSeek distills, Ernie-X1-Turbo-32K) produced empty outputs that were skipped. No direct cost/price figures.
- **Topic**: observability
