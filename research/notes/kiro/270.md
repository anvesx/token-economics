# 270 — Claude Opus 4.6
- **Source**: https://www.anthropic.com/news/claude-opus-4-6 (Anthropic, 2026-10)
- **Claim**: Anthropic's upgraded flagship model (Claude Opus 4.6) improves agentic coding, long-context handling, and reasoning, and introduces new API cost controls (adaptive thinking, four effort levels, context compaction, 1M-token context in beta).
- **Mechanism**: The model is served via the Claude API as `claude-opus-4-6`. New cost/capability levers: (1) Adaptive thinking — the model decides when to use extended thinking rather than a binary on/off; (2) Effort parameter with four levels (low, medium, high=default, max), controlled via `/effort`, letting developers dial intelligence vs. speed/cost; (3) Context compaction (beta) — automatically summarizes and replaces older context when the conversation nears a configurable threshold so long-running agents don't hit the context limit; (4) 1M-token context window (beta, Claude Developer Platform only); (5) 128k output tokens per request; (6) US-only inference option. Claude Code adds agent teams (parallel subagents coordinating autonomously).
- **Numbers**: Standard pricing $5 / $25 per million input/output tokens (unchanged from predecessor). Prompts exceeding 200k tokens (1M context beta) priced at $10 / $37.50 per million input/output tokens. US-only inference at 1.1× token pricing. Max output 128k tokens. MRCR v2 8-needle 1M variant: Opus 4.6 scores 76% vs. Sonnet 4.5 at 18.5%. GDPval-AA: beats GPT-5.2 by ~144 Elo, beats Opus 4.5 by 190 Elo (≈70% win rate vs GPT-5.2). BigLaw Bench 90.2% (reported by Harvey; 40% perfect scores, 84% above 0.8). Box eval 68% vs 58% baseline (10% lift). Vending-Bench 2: earns $3,050.53 more than Opus 4.5. HLE with tools 53.0% (revised from 53.1%). SWE-bench Verified averaged over 25 trials; 81.42% with a prompt modification. MCP Atlas 62.7% at high effort. BrowseComp 86.8% with multi-agent harness. Default effort = high. Context compaction triggered at 50k tokens in some eval runs (up to 3M–10M total tokens).
- **Token-cost implication**: Use the effort parameter to control spend — dial down from high to medium when the model overthinks simple tasks. Enable context compaction for long agentic runs instead of manually trimming context or splitting requests. Be aware the 1M context beta carries ~2× input / 1.5× output premium above 200k tokens, so keep prompts under 200k when possible. 128k single-request output avoids multi-request chunking cost.
- **Caveats**: Vendor blog (self-promotional). Many figures are partner testimonials (Harvey, Box, Rakuten, etc.) and self-reported, not independent — except GDPval-AA, which the footnotes say was run independently by Artificial Analysis. Benchmark configs vary heavily (tools on/off, effort levels, harnesses, context-compaction thresholds), so headline scores are not apples-to-apples with other labs. Terminal-Bench scores mix reproduced and published numbers. Pricing/features for the 1M beta are platform-restricted. No independent cost-per-task figures given.
