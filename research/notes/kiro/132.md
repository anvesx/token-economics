# 132 — Fast Inference from Transformers via Speculative Decoding
- **Source**: https://arxiv.org/abs/2211.17192 (Google Research, 2022-11)
- **Claim**: Introduces speculative decoding, an algorithm that accelerates sampling from large autoregressive Transformers by 2X–3X without changing the output distribution, by using a small approximation model to draft tokens that the large target model verifies in parallel.
- **Mechanism**: A small efficient model Mq autoregressively generates γ candidate tokens; the large target model Mp evaluates all γ+1 positions in parallel in one pass. Accept each guess with probability min(1, p(x)/q(x)); on first rejection, resample that token from the adjusted distribution p'(x)=norm(max(0,p(x)−q(x))). This "speculative sampling" provably preserves Mp's exact distribution. Each Mp run yields 1 to γ+1 tokens. Expected tokens per run = (1−α^(γ+1))/(1−α) where α=E(min(p,q))=1−E(D_LK). Optimal γ chosen by maximizing walltime improvement given α and cost coefficient c (ratio of Mq to Mp runtime). Works with argmax, top-k, nucleus, temperature by casting all to standard sampling; applies to any off-the-shelf model with no retraining or architecture change. Trades extra arithmetic operations for reduced memory accesses/latency when memory-bandwidth-bound.
- **Numbers**: 2X–3X walltime speedup on T5-XXL (11B) vs T5X, identical outputs. Best approximation model T5-small (77M). Empirical α values: T5-XXL EnDe translation — T5-small 0.75 (T=0)/0.62 (T=1), T5-base 0.80/0.68, T5-large 0.82/0.71, bigram 0.20/0.19, unigram 0.08/0.07. CNN/DM summarization — T5-small 0.65/0.53. Measured speedups: EnDe 3.4X (temp=0, T5-small-f, γ=7) and 2.6X (temp=1); CNN/DM 3.1X (temp=0) and 2.3X (temp=1). c < 0.05, often ~0, in experiments. Trivial bigram with c=0 gives α≈0.2 → 1.25X speedup. Illustrative example: 38-token sentence generated in 9 serial Mp runs (97M target, 6M approx). Operations/Speed table (c=ĉ=0): α=0.9 γ=10 → 1.60X ops, 6.86X speed. Lenience l=1/0.5/0.3/0.1 → 2.5X/3.1X/3.6X/5X (T5-XXL, T5-small). Oracle for γ could add up to ~60% over fixed γ. Independent reimplementation (Chen 2023) showed 2X–2.5X on Chinchilla 70B. Approximation model ~2 orders of magnitude smaller than target performed best.
- **Token-cost implication**: In memory-bandwidth-bound serving with spare compute, speculative decoding gives a 2–3X latency win for free with identical outputs and no retraining — a near-default optimization. Pick an approximation model ~100x smaller; tune γ from α and c. Optional lenience (relax exact-distribution guarantee) buys up to 5X. Negligible-cost drafts (n-gram lookups, prefix-copy for summarization/chat) require no extra model.
- **Caveats**: Google-authored, self-reported (walltime only for T5-XXL; α measured for LaMDA 137B and GPT-like 97M but not full walltime). Not helpful when no spare compute (increases total arithmetic ops). Beam-search support only sketched. Tested only text modality. Theoretical predictions assume i.i.d. acceptance (approximation). Lenience can hurt sample diversity.
