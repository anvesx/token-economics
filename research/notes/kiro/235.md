# 235 — How do I track LLM cost and tokens in Langfuse?
- **Source**: https://langfuse.com/faq/all/costs-tokens-langfuse (Langfuse, no date)
- **Claim**: Langfuse can track cost and token usage for any LLM/endpoint via two methods — automatic cost inference for supported models, or explicit ingestion of provider-returned cost/token counts.
- **Mechanism**: (1) Automatic calculation — for supported models Langfuse infers cost; requires submitting usage and using the correct model names (OpenAI and Anthropic supported out of the box; exact names in the Models tab). (2) Explicit ingestion — pass back the cost and token counts you already track, including values some providers return in the response payload. Token counts are captured automatically across native integrations (OpenAI SDK, LangChain, LlamaIndex, and others). On Langfuse Cloud, built-in model prices update with every release; a self-hosted deployment picks up prices on upgrade.
- **Numbers**: none
- **Token-cost implication**: To get accurate per-call cost, either use a supported-model native integration with the exact catalog model name (so inference works) or ingest provider-reported cost/tokens directly (more authoritative). Self-hosters must upgrade to pick up new model prices, otherwise inferred cost drifts.
- **Caveats**: Vendor FAQ; brief, no measured data or savings. Out-of-the-box inference limited to OpenAI and Anthropic model names; correctness depends on supplying the right model string and submitting usage.
- **Topic**: observability
