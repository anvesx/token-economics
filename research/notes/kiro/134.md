# 134 — Menu Pricing of Large Language Models
- **Source**: https://arxiv.org/abs/2502.07736 (arXiv, 2025-02)
- **Claim**: Develops an economic theory of optimal LLM pricing/product design where a provider sells menus of token budgets to heterogeneous users; shows the high-dimensional screening problem collapses to one-dimensional screening, yielding committed-spend contracts that match observed industry pricing (Anthropic, OpenAI, GitHub, Poe).
- **Mechanism**: Users face a continuum of tasks with a gain function g(xi,z)=Ψ(xi)Φ(z) (inference tokens x, fine-tuning tokens z), multiplicatively separable, Ψ homogeneous of degree σ∈(0,1) with diminishing returns (scaling laws). Homogeneity makes the optimal token mix scale-invariant, so each user's whole type profile collapses to a scalar "aggregate type" θ(w)=(∫wi^(1/(1-σ))di)^(1-σ). Buyer indirect utility U=θ(w)·Ψ(X)Φ(Z), placing the problem in the Mussa-Rosen (1978) one-dimensional screening framework. Optimal menu excludes low types, distorts quality downward except at top, and is implementable as (a) maximum-spend (budget cap at marginal-cost prices — Poe), (b) minimum-spend (volume commitment unlocking discounts — GitHub overages), or (c) two-part tariffs. Extends to multiple models (CES aggregation; each type uses a single model, higher types get more capable models) and leader vs open-source fringe competition (three regions: fringe-only, deterrence, monopoly).
- **Numbers**: Observed price points: $20 (standard) and $200 (premium) at both Anthropic and OpenAI. Anthropic tiers (Jan 2026): Pro $20/mo (~45 msgs/5hrs), Max 5x $100/mo (~225 msgs/5hrs, 15–35 Opus hrs/wk), Max 20x $200/mo (~900 msgs/5hrs, 24–40 Opus hrs/wk); Opus consumes resources ~5x faster than Sonnet. OpenAI tiers: Free $0, Plus $20/mo (~80 GPT-4o msgs/3hrs, ~100 reasoning msgs/wk), Pro $200/mo (exclusive o1-pro). Poe (2025): Basic $5/300k pts ($16.67/M), Standard $20/1M ($20/M), Pro $50/2.5M, Advanced $100/5M, Premium $250/12.5M; per-message points — GPT-4o-mini 9, GPT-4o 224, Claude-3.5-Sonnet 276, Claude-3-Opus 1,697, Claude-Opus-4 4,105 (~450x ratio mini→Opus). GitHub Copilot (2026): Free $0/50 premium reqs, Pro $10/300, Pro+ $39/1500, Business $19/user/300, Enterprise $39/user/1000; model multipliers 0 (GPT-5 mini/4.1/4o), 0.25–0.33 (Haiku 4.5, o4-mini), 1 (Sonnet 4.x, GPT-5.x), 3 (Opus 4.5), 50 (GPT-4.5); overage $0.04/premium request. API pricing (Jan 2025, $/M input/output): GPT-4o-mini 0.15/0.60, GPT-4o 2.50/10.00, o1 15/60; Claude 3.5 Haiku 0.80/4.00, 3.5 Sonnet 3/15, 3 Opus 15/75; Gemini 1.5 Flash 0.075/0.30, 1.5 Pro 1.25/5.00. Output priced 3–5x input. GPT-4-class fell $30/$60→$2.50/$10 in 16 months (90% cut). Batch discounts ~50%, prompt-caching up to 90%. Gross margins 50–75%. DeepSeek (Jan 2025) reasoning $0.55/$2.19 vs OpenAI $15/$60.
- **Token-cost implication**: Linear pay-per-token API pricing (no volume discounts) is the constrained-efficient benchmark — providers prioritize adoption over rent extraction; nonlinear screening (subscriptions, credit budgets) is where margin is extracted. Builders should expect committed-spend/credit mechanics (budget caps vs overages) to behave like marginal-cost token pricing with a per-model multiplier, and expect continued API price compression driven by competition. Output tokens cost ~3–5x input because generation is sequential/autoregressive while input encoding is parallelizable.
- **Caveats**: Economic theory paper; pricing figures are descriptive observations as of stated dates, not the authors' measurements. Model assumes homogeneous production technology (same token mix per task) — relaxing it breaks the aggregation result. Abstracts from network effects, data externalities, privacy-constrained fine-tuning, and full oligopoly. Batch/caching discounts are noted as outside the model.
