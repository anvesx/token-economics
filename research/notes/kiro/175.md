# 175 — API pricing (Mistral AI)
- **Source**: https://docs.mistral.ai/inference/pricing (Mistral AI, n.d.)
- **Claim**: Mistral publishes per-token (and per-minute/per-page/per-char) API prices across model families, with Standard, Batch, and Priority tiers, and lists cached-input rates roughly an order of magnitude below standard input.
- **Mechanism**: Pricing is organized by family (generalist, OCR, audio, code, embedding, moderation/safety, time series, voice agents) and by tier toggle (Standard / Batch / Priority) and currency (USD/EUR). Text models bill input / cached-input / output per 1M tokens; cached input is ~10% of standard input price across the generalist line. OCR bills per 1000 pages, audio per minute or per 1M chars, voice agents per minute. Some models are self-hosted open-weights (cost = your own infra).
- **Numbers**: All /M tokens unless noted. Mistral Large 4: input $0.7, cached $0.07, output $2.1. Mistral Small 4: $0.15 / $0.015 / $0.6. Ministral 3 14B: $0.2 / $0.02 / $0.2; 3 8B: $0.15 / $0.015 / $0.15; 3 3B: $0.1 / $0.01 / $0.1. Z.ai GLM 5.3 Flash: $0.15 / $0.03 / $0.5; GLM 5.3: $1.4 / $0.14 / $4.4. DeepSeek V4.1 Flash 1017: $0.3 / $0.007 / $1.2. Codestral: $0.3 / $0.03 / $0.9. Codestral Embed: $0.15 input (no output); Mistral Embed: $0.1 / $0.01. OCR 4.1: $4 / $0.4 per 1000 pages; OCR 3: $2 / $0.2 per 1000 pages. Audio: Voxtral Mini Transcribe 3 $0.0035/min (cached $0.00035); Voxtral Small Transcribe 3 $0.004/min; Mini Transcribe Realtime 3 $0.008/min; Voxtral TTS 3 $13 per 1M chars (cached $1.3); Voxtral Small $0.004/min + $0.4/M output tokens. Voice agents: Mistral Small 4 $0.04/min, larger models $0.08/min. Mistral Moderation 2: Free. Shieldstral 1.0 and Timestral 1.0 (209M/123M/28M/5M): self-hosted open weights.
- **Token-cost implication**: Cached input costs ~10x less than fresh input (e.g. Large 4 $0.07 vs $0.7), so maximize prompt-cache reuse; pick the smallest adequate model (Ministral 3 3B at $0.1/$0.1 vs Large 4 at $0.7/$2.1 is ~7-20x cheaper) and use Batch/Priority tiers to shift cost/latency; DeepSeek V4.1 Flash has an unusually low cached-input rate ($0.007).
- **Caveats**: Vendor price list (list prices, Standard regional tier shown); Batch/Priority values require toggling the page and are not captured here. Prices change over time and this is an undated snapshot. No quality/benchmark data to justify model choice; self-hosted models' true cost depends on your own infrastructure.
