# 023 — Faster Cascades via Speculative Decoding
- **Source**: https://research.google/pubs/faster-cascades-via-speculative-decoding (Google Research, 2025-04)
- **Claim**: Speculative cascading can preserve the quality of a regular small-to-large model cascade while reducing inference cost by implementing the cascade’s deferral decision through speculative execution.
- **Mechanism**: Interleave a small and large model as in speculative decoding, but use an optimal deferral rule to decide which inputs need the larger model; approximate that rule with a plug-in estimator, then let the larger model primarily verify speculative work instead of always regenerating it.
- **Numbers**: Evaluated with T5 and Gemma models on benchmark language tasks; published at ICLR 2025. No exact cost, latency, token-price, or percentage result is stated in the supplied text.
- **Token-cost implication**: For a cascade, combine confidence-based deferral with speculative verification so accepted small-model work is not discarded and recomputed by the large model.
- **Caveats**: Google Research self-report; the supplied text is only the publication abstract, so it does not provide the deferral formula, benchmark names, baselines, absolute costs, latency, or per-model results.
- **Topic**: routing
