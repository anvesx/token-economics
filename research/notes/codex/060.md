# 060 — Claw-SWE-Bench: A Benchmark for Evaluating OpenClaw-style Agent Harnesses on Coding Tasks
- **Source**: https://arxiv.org/abs/2606.12344 (arXiv, 2026-06)
- **Claim**: General-purpose agent harnesses differ substantially in coding success, token use, runtime, and API cost even when the model, tasks, outer budget, and evaluator are fixed. The paper introduces a 350-instance benchmark plus an 80-instance Lite subset that approximates the full benchmark at about one quarter of its evaluation cost.
- **Mechanism**: A shared adapter runs each harness in the same SWE-bench Docker image at the specified base commit, blocks external network access except model inference, sends the same prompt, and exports the final Git diff rather than trusting agent-authored patch text. It standardizes timeout, worker count, patch cleanup, prediction format, and official test evaluation while leaving each harness’s system prompt, tools, parser, memory, and stopping policy as the experimental variable; Lite-80 selects 10 tasks per language with 2/3/3/2 difficulty-quartile quotas and filters candidates for score, ranking, and log-cost parity.
- **Numbers**: Full benchmark: 350 issues, 8 languages, 43 repositories; Lite: 80 issues, 10 per language, covering 38/43 repositories (about 88%). Lite mean Pass@1 was 0.6607 versus 0.6610 on full-350; mean absolute difference across 21 calibration pairs was 0.81 percentage points, held-out maximum difference was 1.70 points, and mean Lite/full cost ratio was 25.3%. The full adapter raised GLM 5.1 OpenClaw Pass@1 from 19.3% to 71.2% and reduced patch-apply failures from 69.1% to under 1.5%. Across 7 harnesses × 3 models × 350 tasks × 3 runs, the largest fixed-model harness gap was 24.3 points. With DeepSeek-V4.1-Flash, Hermes reached 81.7% at $36 over 350 tasks while GenericAgent reached 71.5% at $12; OpenClaw × 11 models ranged from 48.6% at $19.4 to 78.0% at $1,399.1. Main-model prices per 1M tokens (uncached input/cached input/output) were GLM-5.1 $1.40/$0.26/$4.40, Qwen 3.6-flash $0.25/$0.05/$1.50, and DeepSeek-V4.1-Flash $0.30/$0.006/$1.20; DeepSeek off-peak prices were $0.15/$0.003/$0.60. Each task had a 3,600-second timeout, 3-worker concurrency, and up to 300 turns where supported.
- **Token-cost implication**: Treat the harness as a routing and cost-control variable: benchmark model–harness pairs under identical task and cache accounting, use Lite-80-like representative subsets for iteration, then confirm finalists on the full suite. Export patches from repository state and remove future Git history so failed patch formatting or leaked fixes do not corrupt the cost-per-success estimate.
- **Caveats**: The paper’s authors built the benchmark and evaluated remote APIs through OpenRouter; main results are means of three runs, while some model-axis results use one run. Lite-80 was selected from the same 21 calibration columns it matches, though six held-out pairs were tested. Meta-Harness used all 350 tasks for both evolution and final evaluation, so its gains are not a fair held-out comparison. Prices are fixed snapshots, and total API cost excludes local orchestration, Docker evaluation, and 1,430 aggregate host-hours.
- **Topic**: agent-cost
