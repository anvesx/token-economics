# 250 — Building more with GPT-5.1-Codex-Max
- **Source**: https://openai.com/index/gpt-5-1-codex-max (OpenAI, 2025-11-19)
- **Claim**: OpenAI's GPT-5.1-Codex-Max is an agentic coding model trained to work across multiple context windows via compaction, and OpenAI states it is more token-efficient than GPT-5.1-Codex.
- **Mechanism**: The model is natively trained for compaction: when a Codex session nears the context-window limit it prunes its history while preserving the most important context, giving a fresh window, and repeats until the task completes (millions of tokens in one task; internal runs over 24 hours). A new 'xhigh' (Extra High) reasoning effort is added for non-latency-sensitive tasks; 'medium' is the recommended daily driver. All evals were run with compaction enabled at Extra High effort; Terminal-Bench 2.0 used Codex CLI in the Laude Institute Harbor harness.
- **Numbers**: On SWE-bench Verified, Codex-Max at medium reasoning effort beats GPT-5.1-Codex at the same effort while using 30% fewer thinking tokens. Appendix, GPT-5.1-Codex (high) vs Codex-Max (xhigh): SWE-bench Verified (n=500) 73.7% vs 77.9%; SWE-Lancer IC SWE 66.3% vs 79.9%; Terminal-Bench 2.0 52.8% vs 58.1%. Internally 95% of OpenAI engineers use Codex weekly and ship roughly 70% more pull requests. No per-token prices given.
- **Token-cost implication**: Use medium effort by default and reserve xhigh for tasks that tolerate latency; expect fewer thinking tokens at equal quality versus the prior Codex model. Long-horizon agent loops can rely on model-side compaction rather than manual context management, but remember xhigh spends more reasoning tokens.
- **Caveats**: Self-reported by OpenAI; the 30% figure applies to SWE-bench Verified at medium effort only. The savings claim is an expectation ("we expect... real-world savings"), with no dollar figures; the frontend cost example is qualitative. Benchmark table compares different effort levels (high vs xhigh). API access was "coming soon" at publication. Recommended only for agentic coding in Codex-like environments.
