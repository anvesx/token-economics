# 181 — Models & Pricing
- **Source**: https://api-docs.deepseek.com/quick_start/pricing/ (DeepSeek, date not stated)
- **Claim**: DeepSeek API price list for deepseek-flash and deepseek-v4-pro with separate cache-hit, cache-miss and output prices, and peak vs off-peak rates.
- **Mechanism**: Billing is tokens x price on total input and output. Input splits into cache hit and cache miss. Off-peak rates are half of peak. Peak hours: 01:00-04:00 and 06:00-10:00 UTC, Monday through Friday, excluding Chinese public holidays; all other times, including weekends and those holidays, are off-peak. Both models support thinking (default) and non-thinking modes, JSON output, tool calls, 1M context, max output 384K. Search and Fetch are separate APIs billed per successful request. Granted balance is deducted before topped-up balance.
- **Numbers**: USD per 1M tokens, deepseek-flash (DeepSeek-V4.1-Flash-1017) / deepseek-v4-pro (DeepSeek-V4-Pro-0813): input cache hit off-peak $0.003 / $0.022, peak $0.006 / $0.044; input cache miss off-peak $0.15 / $0.66, peak $0.3 / $1.32; output off-peak $0.6 / $1.98, peak $1.2 / $3.96. Concurrency limit 2500 / 500. Search and Fetch: $0.75 per 1,000 successful requests each. Derived (not stated): cache hit is 2% of cache miss on Flash and about 3.3% on Pro. Legacy names deepseek-v4-flash and deepseek-v4-flash-vision-exp are billed at Flash price.
- **Token-cost implication**: Cached input costs far less than uncached (see numbers), so prefix stability matters more than raw token trimming; shifting batch and non-urgent work to off-peak hours halves cost; thinking mode is on by default and output tokens carry the highest price.
- **Caveats**: Vendor price page; DeepSeek reserves the right to change prices. Vision supported on Flash only. Peak schedule is in UTC and depends on Chinese holidays.
