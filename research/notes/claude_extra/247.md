# 247 — AI Gateway Automatic Prompt Caching (Vercel)
- **Source**: https://vercel.com/docs/ai-gateway/models-and-providers/automatic-caching (Vercel, 2026-11; page last updated September 11, 2026)
- **Claim**: Setting caching: 'auto' makes Vercel AI Gateway add the provider-appropriate cache markers (for Anthropic, MiniMax, Alibaba) so agentic and multi-turn traffic reads cached prefixes; session affinity, cache_ttl and cache_anchor_items improve hit rates.
- **Mechanism**: For explicit-caching providers the gateway places cache_control breakpoints at two positions: on the last message (each request writes a cache entry the next request reads as a prefix) and on the message before the last user message, falling back to the system message (a changed tail still reads the stable prefix). Optional third marker via cache_anchor_items: N on the Responses API, declaring the first N input items byte-identical on future requests, useful when a client summarizes, prunes or compacts the middle of the prompt; invalid values are ignored. cache_ttl accepts 5m or 1h and applies to every automatic breakpoint; it needs top-level caching: 'auto' and is ignored if caching is set only via providerOptions.gateway.caching. The x-session-affinity header (opaque, stable per conversation or agent run, no personal data) is forwarded to providers and is also used by the gateway to keep a conversation on the provider holding its cache; no hit guarantee. OpenAI, Google and DeepSeek cache implicitly and need no change; default with caching unset is passthrough. Verify hits by checking cache-read token counts (a zero can mean miss, ineligible prompt or missing usage). has: ['implicit-caching'] restricts routing to implicit-caching models. Virtual models can pin caching: 'auto' or @default.
- **Numbers**: Anthropic cache write 1.25x base input (5 minutes) or 2x (1 hour); cache read 0.1x base input. Break-even is one read: saves 0.9x per token read vs a 0.25x write premium. A 1-hour entry costs an additional 0.75x base input to write; one read after the 5-minute entry would have expired saves 0.9x and repays that premium. Default Anthropic lifetime five minutes.
- **Token-cost implication**: For agents and multi-turn chats on Anthropic-family models route via caching: 'auto', send a stable session affinity value, and choose 1h TTL if pauses exceed five minutes. Declare cache_anchor_items when your client compacts history so the stable prefix still hits. For strictly one-shot traffic the write premium is a small net cost, so use manual markers or no caching. Monitor cache-read tokens to confirm.
- **Caveats**: Vendor documentation, no measured hit-rate or savings data. Supported auto-marker providers listed as Anthropic (direct, Vertex, Bedrock), MiniMax, Alibaba. cache_ttl and cache_anchor_items are advisory and only apply on the Responses API with caching: 'auto'. Provider thresholds and retention windows vary and are not given here.
