# 147 — Llama 4 Maverick 17B 128E Instruct
- **Source**: https://huggingface.co/meta-llama/Llama-4-Maverick-17B-128E-Instruct?local-app=docker-model-runner (Meta, 2025-05)
- **Claim**: Hugging Face model card for Meta's Llama 4 Maverick and Scout, open-weight natively multimodal mixture-of-experts models, with license, benchmark, quantization and training-compute details.
- **Mechanism**: Auto-regressive MoE with early fusion for multimodality. Both models activate 17B parameters per token; Scout has 16 experts (109B total), Maverick has 128 experts (400B total; page also shows 402B params in BF16 safetensors). Scout ships BF16 weights and fits on a single H100 with on-the-fly int4 quantization. Maverick ships BF16 and FP8 weights; FP8 fits on a single H100 DGX host. Loaded via transformers v4.51.0 (Llama4ForConditionalGeneration, flex_attention, bfloat16).
- **Numbers**: Context length: Scout 10M, Maverick 1M. Pretraining tokens: Scout ~40T, Maverick ~22T. Training: 7.38M H100-80GB GPU hours total (Scout 5.0M, Maverick 2.38M); 1,999 tons CO2eq location-based. Instruction-tuned benchmarks (0-shot, Maverick vs Scout): MMLU Pro 80.5 vs 74.3; GPQA Diamond 69.8 vs 57.2; LiveCodeBench (10/01/2024-02/01/2025) pass@1 43.4 vs 32.8; MMMU 73.4 vs 69.4; ChartQA 90.0 vs 88.8; DocVQA 94.4 vs 94.4. Llama 3.1 405B: MMLU Pro 73.4, GPQA Diamond 49.0, LiveCodeBench 27.7. Long-context MTOB table notes a 128K context window for the comparison model. License: 700 million monthly active user threshold requires a separate Meta license. Tested for image understanding up to 5 input images. Price per token: none.
- **Token-cost implication**: Self-hosting option: only 17B parameters are active per token, and FP8 (Maverick) or int4 (Scout) quantization lets them fit on one H100 or one H100 host, so per-token compute is far below the total parameter count suggests. - **Caveats**: Vendor model card, self-reported benchmarks; all evals run on bf16, not the quantized checkpoints. No latency, throughput or dollar figures. Gated model requiring license acceptance; commercial terms apply above 700M MAU.
