# 217 — Monitoring usage (Claude Code OpenTelemetry)
- **Source**: https://code.claude.com/docs/en/monitoring-usage (Anthropic, 2026-11)
- **Claim**: Reference for exporting Claude Code usage, cost and tool-activity telemetry through OpenTelemetry metrics, events and optional traces, with per-request cost and token attribution to model, agent, skill, plugin and MCP tool.
- **Mechanism**: Set CLAUDE_CODE_ENABLE_TELEMETRY=1, choose exporters (OTEL_METRICS_EXPORTER otlp|prometheus|console|none, OTEL_LOGS_EXPORTER), and an OTLP endpoint and headers; defaults are a 60,000 ms metric interval and 5,000 ms logs interval, delta temporality. Metrics include claude_code.session.count, claude_code.cost.usage (USD), claude_code.token.usage (type input, output, cacheRead, cacheCreation; "input" excludes cache reads and writes), lines_of_code, pull_request, commit, code_edit_tool.decision, active_time.total. Cost and token counters increment after each API request with attributes model, query_source (main, subagent, auxiliary), speed (fast), effort (low to max), agent.name, skill.name, plugin.name, mcp_server.name, mcp_tool.name (names redacted to "custom" or "third-party" unless OTEL_LOG_TOOL_DETAILS=1). The claude_code.api_request event carries cost_usd, cost_usd_micros, duration_ms, input/output/cache_read/cache_creation tokens, cache_creation_5m_tokens and cache_creation_1h_tokens (v2.1.300 or later), request_id, query_source (e.g. repl_main_thread, compact) and effort. Team attribution: OTEL_RESOURCE_ATTRIBUTES="department=...,team.id=...,cost_center=..." adds labels to every datapoint (no spaces allowed in values). Cardinality controls: OTEL_METRICS_INCLUDE_SESSION_ID, _VERSION, _ACCOUNT_UUID, _ENTRYPOINT, _RESOURCE_ATTRIBUTES, _REPOSITORY (v2.1.269 or later). Safety events log permission refusals, sandbox and hook blocks.
- **Numbers**: Defaults: metrics export 60000 ms, logs 5000 ms; headers helper script reruns every 29 minutes by default; sandbox_violation_count ranges "0" to "20". No prices or savings.
- **Token-cost implication**: Export cost.usage and token.usage grouped by model, effort, query_source (to separate subagent and compaction spend), skill and mcp_tool to find what drives spend; add cost_center resource attributes for chargeback; watch cacheRead versus cacheCreation to confirm caching works; keep high-cardinality attributes off metrics to limit backend storage cost.
- **Caveats**: Cost is an estimate computed client-side; many attributes depend on Claude Code version; reading is a reference, no measured results; default redaction hides third-party skill and MCP names. Lines 160-560 and 670-820 (traces, events, other settings) were skimmed for cost-relevant fields only.
- **Topic**: observability
