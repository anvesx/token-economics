# 112 — LLM Inference Benchmarking: How Much Does Your LLM Inference Cost?
- **Source**: https://developer.nvidia.com/blog/llm-inference-benchmarking-how-much-does-your-llm-inference-cost (NVIDIA Technical Blog, Vinh Nguyen and Sergio Perez, Jun 18, 2025; corpus tag 2025-04)
- **Claim**: A step-by-step method to turn GenAI-Perf benchmark data into a self-hosted LLM total cost of ownership (TCO): benchmark, pick the best deployment under a latency limit, size instances and servers for peak load, then convert yearly server cost into cost per 1,000 prompts and per 1M tokens.
- **Mechanism**: (1) Run NVIDIA GenAI-Perf (client-side; measures TTFT, inter-token latency, tokens/s, requests/s; works with any OpenAI-compatible API, NIM, vLLM, SGLang, Dynamo, Triton, TensorRT-LLM) at several concurrency levels to get a latency-throughput curve. Low concurrency gives low latency and low throughput; high concurrency batches better and raises throughput and latency. Compare precisions (FP4, FP8, BF16) on a Pareto front. (2) Drop points above the latency limit (for interactive chat, average TTFT at or below 250 ms) and pick the highest-throughput remaining point; normalize to requests/s per GPU if GPU counts differ. (3) Instances = planned peak requests/s divided by requests/s per instance. Servers = instances x GPUs per instance / GPUs per server. (4) Yearly server cost = initial server cost / depreciation years + yearly software + yearly hosting. Total = servers x yearly cost. (5) Cost per 1,000 prompts = yearly server cost / requests the server can serve in a year (assumes 100% uptime; adjust for real uptime). Cost per 1M tokens uses the input/output price ratio, since output tokens cost more time. The blog's formulas are images, not in the text.
- **Numbers**: Example inputs: server $320,000; 8 GPUs per server; 4-year depreciation; hosting $3,000 per server per year; software $4,500 per year. Reference commercial prices used for the input/output ratio: $1 per 1M input tokens, $3 per 1M output tokens. Latency example: TTFT at or below 250 ms for chat. The text gives no final computed cost per token.
- **Token-cost implication**: Self-hosting cost per token depends on the throughput you get at your latency limit, not peak throughput. Benchmark your real input/output lengths, choose the concurrency and precision that meet the limit, size for peak requests/s, and track utilization, since the formula assumes 100% uptime and idle capacity raises true cost per token. Compare the result to API prices before choosing to self-host.
- **Caveats**: Vendor guide (NVIDIA) written around its own tools and hardware; example costs are hypothetical; assumes constant full utilization; no measured model or GPU results in the text; figures are images.
