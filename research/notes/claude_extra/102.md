# 102 — Confident Adaptive Language Modeling
- **Source**: https://arxiv.org/abs/2207.07061 (Google Research / MIT CSAIL, NeurIPS 2022, 2022-07; v2 25 Oct 2022)
- **Claim**: CALM lets a Transformer LM decide per token how many decoder layers to run (early exit), and calibrates the exit threshold on held-out data so the full output provably stays within a user-set tolerance of the full model's output (or of its risk), with probability 1 - epsilon. It reports up to about 3x speedup on summarization, translation and QA.
- **Mechanism**: Exit heads share the output embedding with the top layer (no new parameters); the model is trained with a weighted per-layer loss (weight i / sum of layer indices, favouring higher layers). Per token, a confidence score is computed after each layer; exit if score >= threshold. Three confidence measures: softmax response (top-2 probability gap), hidden-state saturation (cosine similarity of consecutive layer states, parameter-free), and a small trained early-exit classifier (linear, |d|+1 parameters, trained with backbone frozen against an oracle of whether the layer's argmax equals the final layer's). Skipped layers: copy the exited layer's hidden state upward and compute K/V projections for the skipped layers from it (copying the K/V themselves instead dropped ROUGE-L to 23.02). A decaying threshold, lambda' = clip(0.9*lambda + 0.1*exp(-tau*t/N)), is more permissive later in the output because early errors propagate more. Calibration uses Learn then Test with fixed sequence testing: step down a grid of thresholds (e.g. 0.05 steps), compute a p-value (Hoeffding-Bentkus) for "consistency within delta" on a calibration set, stop at the first failure and return the last valid threshold (fallback 1 = full model). Two guarantees: textual consistency (output close to the full model's output, no labels needed) and risk consistency (quality loss vs references no more than delta).
- **Numbers**: Setup: 8-layer T5 1.1 decoder, tasks CNN/DM (ROUGE-L), WMT15 EN-FR (BLEURT as distance), SQuAD 1.1 (token F1); epsilon 0.05; 50 random trials, 80% calibration / 20% test; inference on one TPUv4 chip, batch size 1; speedup measured on TPUv3 over 200 examples. Oracle exit (earliest layer matching the final prediction): ROUGE-L 38.24 vs 38.32 full while averaging 1.53 layers per token (up to 5.2x). Test results (Table 2, speedup vs full model): CNN/DM risk-consistency delta 0.25 (softmax) x2.57; WMT risk delta 0.25 softmax x2.01 for delta 0.1 and x2.10 at delta 0.02 textual; SQuAD softmax up to x3.15 (layers 1.65). Softmax measure can lower layers but raise FLOPs (e.g. CNN/DM delta 0.1 softmax: 5.73 layers, FLOPs reduction x0.44 i.e. more FLOPs than baseline), while the classifier gives x1.03 to x1.15 FLOPs reduction there. Text states the headline as "up to about x3" speedup. Early-exit classifier F1 (layer 1, CNN/DM): 0.62 independent vs 0.59 geometric-like. A single static threshold with no decay lost more than 10 points of similarity when trying to speed up.
- **Token-cost implication**: Adaptive depth saves compute per token, not token count, and needs access to model internals plus training of exit heads, so only a self-hoster who trains or fine-tunes their own model can use it; API users cannot. The transferable lesson is calibrating a cheaper path against held-out data to bound quality loss, rather than picking a threshold by feel. Short outputs gain less because encoding time dominates.
- **Caveats**: Google Research, self-reported, small T5 encoder-decoders (8 layers; a 12-layer T5-base in the appendix), not modern decoder-only LLMs. Speedups are measured with batch size 1; batched serving would be harder because tokens in a batch exit at different layers (not tested). Guarantees are statistical, depend on exchangeable calibration data and a chosen metric (ROUGE, BLEURT, F1). Softmax measure can increase total FLOPs. The authors note their implementation adds conditionals that add overhead.
