# 275 — Batch API overview (Together AI)
- **Source**: https://docs.together.ai/docs/inference/batch/overview (Together AI, 2026-11)
- **Claim**: Together's batch API runs many independent requests asynchronously from one uploaded JSONL file at up to 50% off serverless rates, with its own rate-limit pool, in exchange for a job-shaped workflow with a 24-hour best-effort window.
- **Mechanism**: Upload a JSONL file (each line has a `custom_id` and a request body), create a batch for one model and endpoint (`/v1/chat/completions`, or audio transcription/translation), poll status until COMPLETED, then download the output and error files. Results come back in arbitrary order, so reconcile with `custom_id`. One uploaded file can back several batches within its retention window. Dedicated-model batch jobs run but get no discount.
- **Numbers**: Up to 50% off serverless rates for discounted models (the listed discounted-model table in the text names only openai/whisper-large-v3; other models "run at standard rates" per the page). Limits: 50,000 requests per batch, 100 MB per input file, 10 MB per line, 30B tokens enqueued per model, one model per batch, 24h window (not changeable). Batches under 1,000 requests typically finish in minutes. Files retained 7 days. Billed per successful response; failed requests not billed; cancelling does not refund responses already generated. Advised batch size 1,000 to 10,000 requests. Wait at least 72 hours of IN_PROGRESS before contacting support.
- **Token-cost implication**: Move offline work (classification, evals, synthetic data, bulk summarization) to batch. For labeling, set max_tokens to 4 and temperature to 0 and constrain the prompt to return only the label, since output tokens dominate cost on short-output jobs. Check the discounted-model list before assuming a 50% saving, and download results within 7 days.
- **Caveats**: Vendor documentation, no measurements. The "up to 50%" is a ceiling and the page excerpt lists only one discounted model, so the actual discount for a given LLM must be verified. The text does not state per-token prices.
- **Topic**: pricing
