# 209 — Fast mode for API Customers
- **Source**: https://openai.com/api-fast-mode (OpenAI, 2026-07; Priority processing renamed Fast mode on July 30, 2026)
- **Claim**: Fast mode (formerly Priority processing) is a premium pay-as-you-go service tier giving lower, more consistent latency than Standard at roughly double the per-token price, with a published price table, ramp rate limits and enterprise SLAs.
- **Mechanism**: Set service_tier "fast" (or "priority") per request, or default a project to Fast in Project settings. Billed per token at a premium over Standard. Cached input keeps the same 50%, 75% or 90% discount as Standard. Ramp rate limit: if Fast performance is degraded and traffic is processing at least 1M TPM and rising by more than 50% TPM in under 15 minutes, some traffic may be downgraded to Standard (response shows service_tier "Default"); limits are shared across projects and organizations. Rate limits are shared with other tiers; Scale Tier is separate and does not spill over. Compatible with data residency, ZDR and BAA. Usage dashboard: group by Service Tier or Line Item.
- **Numbers**: gpt-5.6-sol up to 2.5x faster. Prices per 1M tokens in Fast mode, short context input / cached / output (long context input / cached / output): GPT-6 Astra $20.00 / $2.00 / $100.00 ($40.00 / $4.00 / $150.00); GPT-6.1 Sol $4.00 / $0.20 / $20.00 ($8.00 / $0.40 / $30.00); GPT-6.1 Terra $2.00 / $0.10 / $10.00 ($4.00 / $0.20 / $15.00); GPT-6 Luna $0.20 / $0.02 / $1.00 ($0.40 / $0.04 / $1.50); GPT-5.6 Sol $8.00 / $0.80 / $40.00 ($16.00 / $1.60 / $60.00); GPT-5.6 Terra $4.00 / $0.40 / $24.00; GPT-5.6 Luna $0.40 / $0.04 / $2.40; GPT-5.5 $12.50 / $1.25 / $75.00; GPT-5.4 $5.00 / $0.50 / $30.00; GPT-4.1 $3.50 / $0.875 / $14.00; o3 $3.50 / $0.875 / $14.00. Uptime SLA 99.9% (Enterprise only); latency SLA e.g. GPT-5.6 Sol 99% above 80 tokens per second, GPT-5.6 Luna above 100, GPT-5.5 above 50 (p50 per 5 minutes). Long context for 5.5 and 5.4 is requests above 272K prompt tokens. GPT-6 Astra Fast prices are 2x the Astra Standard prices in the companion guide (206): $20 vs $10 input.
- **Token-cost implication**: Pay the roughly 2x premium only on latency-sensitive paths (chat, coding tools); keep batch and async jobs off Fast because they ramp traffic quickly and do not need it; ramp new models by feature flag over hours to avoid downgrade to Standard.
- **Caveats**: Vendor pricing page; latency SLAs apply to Enterprise customers only and are blank for the GPT-6 rows; "2.5x" is stated for gpt-5.6-sol only; not every future model is guaranteed support.
