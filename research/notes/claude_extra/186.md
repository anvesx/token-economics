# 186 — The new economics of AI cost management
- **Source**: https://www.databricks.com/blog/ai-cost-management (Databricks, 2026-10)
- **Claim**: Interview with a Databricks Unity Gateway lead arguing enterprises should move from maximizing token usage to measuring value per dollar, using attribution, routing, spend guardrails, tracing and a centralized gateway.
- **Mechanism**: Per-request tags (user, team, agent, endpoint, model, provider, or custom such as a pull request ID) feed cost attribution; all AI traffic flows through a central gateway (Unity Gateway) that can enforce budgets, alerts and capacity reduction; Smart Routing assesses task complexity in real time and sends requests to a frontier or lower-cost model; harness routing extends this because the same model under different harnesses (compaction rules, business logic) spends differently. Context bloat is avoided by letting agents pull context on demand via tools, MCP servers or skills instead of pushing it. Quality guard: define a proxy metric (e.g. merged pull requests not rolled back within two weeks) and run parallel budget experiments.
- **Numbers**: Roughly 5 to 10% of tasks genuinely need a frontier model; the other 90% are solvable by lesser models (speaker's estimate). Push context by default only if 90% or more certain it matters. Example guardrail: if a power user spends at most about $300 per day, set a hard cap around $500; cut default frontier access after a team burns 70% of budget. Example attribution: one pull request cost $300. No savings percentages measured.
- **Token-cost implication**: Tag every request at the gateway, cap spend with alerts before hard stops, route most tasks to cheaper models while reserving frontier for the few that need it, and prefer on-demand context retrieval. Test cost cuts against an outcome metric, not just spend.
- **Caveats**: Vendor interview promoting its own product, figures are the interviewee's rules of thumb not measurements. "Emerging research" on harness cost differences is cited but not named.
- **Topic**: agent-cost
