# 287 — Inference Providers index (Hugging Face)
- **Source**: https://huggingface.co/docs/inference-providers/index (Hugging Face, date not given)
- **Claim**: Hugging Face's Inference Providers is a unified, OpenAI-compatible proxy over about 18 third-party inference providers, using one HF token, pay-as-you-go, with no extra markup on provider rates. Its default routing picks the fastest provider, and a model-id suffix switches to the cheapest.
- **Mechanism**: Point an OpenAI-compatible client at `https://router.huggingface.co/v1` (or use `huggingface_hub` InferenceClient / huggingface.js) with an HF token. Append a policy suffix to the model id: `:fastest` (default, equivalent to provider "auto", highest throughput in tokens/s), `:cheapest` (lowest price per output token), `:preferred` (your order in account settings), or a provider name such as `openai/gpt-oss-120b:groq`. Selection is server-side. `hf models ls --warm` lists models served by at least one provider.
- **Numbers**: none (no per-token prices on this page; it links to a separate Pricing and Billing page). Claims stated: "No extra markup on provider rates"; monthly included credits for PRO and Team & Enterprise orgs. Partners listed include Baseten, Cerebras, Cohere, DeepInfra, Fal AI, Featherless AI, Fireworks, Groq, HF Inference, Novita, Nscale, OVHcloud, Public AI, Replicate, Scaleway, Together, WaveSpeedAI, Z.ai.
- **Token-cost implication**: The default routes by speed, not price, so set `:cheapest` explicitly for cost-sensitive traffic, noting it ranks by output-token price only and ignores input and cached-input rates. One token and one API give a cheap way to compare providers for the same open model.
- **Caveats**: Vendor docs, no measurements, no price data or failover details in the text. "Cheapest" is by output price per the text, which may not be cheapest for input-heavy or cache-heavy workloads. Excludes the linked pricing page.
- **Topic**: routing
