# 130 — NVIDIA Platform Delivers Lowest Token Cost Enabled by Extreme Co-Design
- **Source**: https://developer.nvidia.com/blog/nvidia-extreme-co-design-delivers-new-mlperf-inference-records (NVIDIA Technical Blog; Ashraf Eassa, Zhihan Jiang; 2026-04-01)
- **Claim**: On MLPerf Inference v6.0, NVIDIA Blackwell Ultra systems posted the highest throughput on every model and scenario tested. Software updates alone gave up to 2.7x more tokens from the same GB300 NVL72 hardware in six months, cutting cost per token by more than 60% (NVIDIA's statement).
- **Mechanism**: TensorRT-LLM kernel fusion and faster kernels; optimized Attention Data Parallel (better balancing of context requests across ranks). For the new DeepSeek-R1 Interactive scenario, Dynamo features: disaggregated prefill/decode serving, Wide Expert Parallel (shards MoE experts across NVL72 GPUs to cut expert weight load time), Multi-Token Prediction (up to 3 extra tokens predicted and verified in parallel), and KV-aware routing.
- **Numbers**: Per-GPU, GB300 NVL72 v5.1 to v6.0: DeepSeek-R1 Server 2,907 to 8,064 tokens/sec/gpu (2.77x); DeepSeek-R1 Offline 5,842 to 9,821 (1.68x); Llama 3.1 405B Server 170 to 259 (1.52x); Llama 3.1 405B Offline 224 to 271 (1.21x). Text of the post also says up to 2.7x on DeepSeek-R1 Server and 1.5x on Llama 3.1 405B Server. Four GB300 NVL72 systems (288 Blackwell Ultra GPUs) with Quantum-X800 InfiniBand: DeepSeek-R1 Offline 2,494,310 tokens/sec, Server 1,555,110 tokens/sec. Other v6.0 results: GPT-OSS-120B Offline 1,046,150, Server 1,096,770, Interactive 677,199 tokens/sec; DeepSeek-R1 Interactive 250,634 tokens/sec; Qwen3-VL Offline 79 samples/sec, Server 68 queries/sec; Wan 2.2 offline 0.059 samples/sec, single-stream 21 secs; DLRMv3 Offline 104,637 samples/sec, Server 99,997 queries/sec. DeepSeek-R1 Interactive: 5x faster minimum token rate and 1.3x shorter time to first token than the Server scenario. 14 partners submitted; 291 cumulative NVIDIA MLPerf wins since 2018 (claimed 9x all others combined). No dollar prices.
- **Token-cost implication**: Cost per token falls with delivered throughput on fixed hardware, so serving-stack upgrades (kernels, disaggregated prefill/decode, MTP, KV-aware routing, expert parallelism) lower unit cost without new GPUs. High interactivity (fast token rate) costs much throughput: DeepSeek-R1 Interactive 250,634 vs Server 1,555,110 tokens/sec at the 4-system scale, though the two figures come from different configurations. Price tiers for fast output are therefore plausible.
- **Caveats**: Vendor blog; "more than 60%" cost reduction is derived by NVIDIA from throughput gain at the same infrastructure and power, not from a published price. Per-GPU numbers are derived by dividing total throughput by reported chips and are not an MLPerf primary metric. Table 1 text is partly garbled (the Server/Interactive column mapping for some models is unclear). Benchmarks are offline/server/interactive MLPerf scenarios, not production traffic. The 2.7x figure was achieved by partner Nebius.
