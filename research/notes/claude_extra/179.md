# 179 — Standard Vault Pricing
- **Source**: https://docs.cohere.com/docs/model-vault/standard/pricing (Cohere, date not stated)
- **Claim**: Cohere Model Vault, a dedicated managed inference platform, is priced per GPU-hour times replicas rather than per token; the page also lists legacy per-token prices and Rerank search-unit definition.
- **Mechanism**: Model Vault runs Cohere or open-weight models on isolated (no multi-tenancy) GPUs; you pay on-demand hourly per GPU and number of replicas, with Fixed or Flex plans, reserved capacity and monthly or annual commits through sales. An Encrypted (Confidential Compute) variant is priced higher for H100 and B200. Rerank: one search unit is one query with up to 100 documents; documents over 500 tokens (including the query) are split into chunks that each count as a document.
- **Numbers**: On-demand $/GPU-hour (promotional price through March 31 '27 in parentheses): L4 24GB $3.00 ($1.00); A100 40GB $3.25 ($2.25); A100 80GB $3.50 ($2.25); MI300X 192GB $6.00 ($4.00); H100 80GB $6.25 ($4.25); H200 141GB $7.25 ($5.50); H100 80GB Encrypted $9.00 ($4.25); B200 192GB $9.75 ($8.00); B200 Encrypted $12.00 ($8.00); GB200 192GB $12.50 ($10.00). Legacy per 1M tokens (input/output): Command $1.00/$2.00; Command-light $0.30/$0.60; Command R 03-2024 $0.50/$1.50; Command R+ 04-2024 $3.00/$15.00; Command R+ 08-2024 $2.50/$10.00; Aya Expanse 8B and 32B $0.50/$1.50. Billing issued monthly or at $250 outstanding. Tokens: simple text approaches 1 token per word, complex text 3-4 tokens per word.
- **Token-cost implication**: Dedicated-GPU pricing makes cost a function of utilization, not tokens: compare GPU-hour cost divided by sustained tokens per hour against per-token API prices before choosing a dedicated deployment. Rerank 5 banner says "sharper search, fewer tokens" (marketing line, no figure).
- **Caveats**: Vendor price list; says pricing does not indicate GPU availability; no throughput figures, so cost per token cannot be derived from this page. Which table rows are the Encrypted variant is inferred from the checkmark column layout.
