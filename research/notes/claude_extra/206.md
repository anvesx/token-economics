# 206 — A model guide for the GPT-6 family
- **Source**: https://openai.com/index/practical-guide-building-gpt-6 (OpenAI, Oct 2, 2026)
- **Claim**: OpenAI guide to choosing among GPT-6 Astra, 6.1 Sol and 6 Luna, reasoning effort and speed, with advice on caching, compaction and production measurement to manage time and cost.
- **Mechanism**: Treat model choice, reasoning level and speed as an intelligence/price tradeoff. Reasoning levels: Low for routine extraction and small edits, Medium for judgment, High for difficult debugging, Extra high/Max only if High falls short and the gain justifies cost; effort can be changed mid-conversation without breaking cache. Fast mode (faster, more consistent, higher per-token cost) and Ultrafast (Astra only; speeds token generation independently of reasoning effort). Keep stable instructions and reference material before changing task details and keep tool definitions consistent for caching; use compaction for long conversations; include cache writes and long-context rates when estimating workflow cost. Test with cost per successful task.
- **Numbers**: Prices per 1M tokens, input / output / cached input: GPT-6 Astra $10.00 / $50.00 / $1.00; GPT-6.1 Sol $2.00 / $10.00 / $0.10 ("near-Astra intelligence for a fifth of the price"); GPT-6 Luna $0.10 / $0.50 / $0.01. Cached input up to 95% cheaper than uncached depending on model. Invideo reports roughly 3x success rate on color-grading tasks (customer anecdote).
- **Token-cost implication**: Use Luna for high-volume structured tasks (invoice extraction, classification), Sol for complex coding, Astra only where max intelligence is needed; default to lower reasoning effort and escalate on measured need; measure cost per successful task, not per token; build prefixes for caching and budget for cache writes.
- **Caveats**: Vendor marketing guide; the "fifth of the price" claim is the list-price ratio, not a quality benchmark; the customer stories are unquantified except Invideo; no independent measurement.
- **Topic**: reasoning-budget
