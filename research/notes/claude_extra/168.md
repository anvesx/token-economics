# 168 — Pricing and Billing
- **Source**: https://huggingface.co/docs/inference-providers/pricing (Hugging Face, date not stated)
- **Claim**: Hugging Face Inference Providers gives pay-as-you-go access to 200+ models with provider rates passed through with no markup, plus monthly credits and organization-level billing and usage reporting.
- **Mechanism**: Two modes: routed by Hugging Face (billed on the HF account, credits apply) or a custom provider key (billed by the provider, HF credits do not apply). Team/Enterprise orgs bill usage to the org by sending header X-HF-Bill-To: <org> (or a resource-group ID for Enterprise with Resource Groups), or bill_to / billTo in the SDK clients. Admins can set a spending limit and disable providers. Enterprise API endpoint /api/organizations/<org>/billing/usage/inference returns a daily time series by member, model and provider with requests, cost in cents, and input, output and cached input token counts (token counts only for chat completions). hf-inference charges compute time x hardware price.
- **Numbers**: Free users: no monthly credits. PRO: $2.00 per month. Team/Enterprise: $2.00 per seat per month, shared among members. Provider rates passed through with no additional fees. hf-inference example: FLUX.1-dev request taking 10 seconds on a GPU costing $0.00012 per second is billed $0.0012. Usage API: costs rounded to nearest cent per row; requests appear up to 2 hours after being made; default 7 days per page, max 31; window within last 12 months. As of July 2025, hf-inference focuses mostly on CPU inference.
- **Token-cost implication**: Use a billing header or bill_to to attribute spend per org or resource group, and the Enterprise usage API (including cached input token counts) for per-member, per-model cost reporting. A custom provider key forfeits HF credits but bills directly with the provider.
- **Caveats**: Vendor documentation; no per-model token prices listed on this page. Usage API requires Enterprise plan or above, rounding can make rows differ from the invoice, and token counts are only for chat completions.
