# 213 — Overview of request-based billing (legacy)
- **Source**: https://docs.github.com/en/copilot/reference/copilot-billing/request-based-billing-legacy/github-copilot-premium-requests (GitHub, date not stated)
- **Claim**: Describes GitHub Copilot's legacy premium-request billing (for Pro and Pro+ subscribers on an existing annual plan who stayed on it after June 1, 2026): a monthly per-user allowance of premium requests, model multipliers, per-session cloud agent billing, and budget controls.
- **Mechanism**: Each plan includes a fixed monthly premium-request allowance that resets on the 1st at 00:00:00 UTC. Premium models consume it; some use multipliers (advanced reasoning models may count 5x or 20x). Overage, if enabled, is billed at the standard rate. Each Copilot cloud agent session (started by prompting a task or assigning an issue) consumes one premium request and also draws GitHub Actions compute from included monthly compute. Usage is split into SKUs (Copilot premium requests; Spark; Copilot cloud agent, dedicated SKUs from November 1, 2025). Budgets alert at 75%, 90% and 100%; a $0 budget with "Stop usage when budget limit is reached" blocks paid overage while keeping the subscription (deleting a budget removes the limit).
- **Numbers**: Multipliers 5x or 20x for advanced reasoning models; 1 premium request per cloud agent session; budget alerts at 75/90/100%; allowance reset 1st of month 00:00:00 UTC. Allowance counts per plan not stated.
- **Token-cost implication**: Under request-based billing the unit is the interaction, not tokens, so one long agent session costs the same as a short one while a reasoning-model call can cost 5-20 requests; route routine work to non-multiplied models, set a $0 stop budget to cap spend, and use per-SKU budgets to attribute cloud agent cost.
- **Caveats**: Legacy scheme, applies only to a narrow subscriber group after June 1, 2026; model-to-multiplier table is in another page and is not included here.
