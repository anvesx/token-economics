# 285 — Claude Fable 5.1 overview
- **Source**: https://platform.claude.com/docs/en/models/fable-5-1/overview (Anthropic, date not given; page states release September 1, 2026)
- **Claim**: Claude Fable 5.1 is Anthropic's top-tier model for demanding reasoning and long-horizon agentic work. It keeps Fable 5's input and output prices but cuts cache reads to a quarter of the previous cost, and Anthropic recommends starting with Opus 5.5 for most workloads.
- **Mechanism**: Adaptive thinking is always on and effort steers depth (default effort high). Per-message effort changes (beta) are meant to alter effort mid-conversation without invalidating the prompt cache. Breaking changes from Fable 5: forced tool use errors, only Fable 5.1 and Mythos 5.1 can read its thinking blocks, editing earlier turns invalidates thinking blocks, some advisor-tool pairings unsupported.
- **Numbers**: Fable 5.1: $10 input / $50 output per MTok, 1M context, 128K max output, 5m cache write $12.50, 1h cache write $20, cache read $0.25 per MTok, Batch API 50% off input and output. Comparison table (input / output per MTok): Opus 5.5 $4 / $20 (default effort medium), Sonnet 5.5 $2 / $10 (default effort high), Haiku 5.5 from $0.10 / $0.50 (default effort medium); all 1M context, 128K output. Latency: Fable slower, Opus moderate, Sonnet fast, Haiku fastest. Retirement not sooner than September 1, 2027.
- **Token-cost implication**: Default to Opus 5.5 (2.5x cheaper than Fable on both input and output) and escalate to Fable 5.1 only when evals on Opus 5.5 at higher effort still fail. For cache-heavy agents the $0.25 read price is 2.5% of the $10 input price, so long stable prefixes become very cheap; use per-message effort changes to avoid cache invalidation when you vary effort. Always-on thinking means output-token cost includes reasoning, so tune effort.
- **Caveats**: Vendor docs; no benchmark scores in this text, so capability claims ("stronger long-running agentic coding...") are unquantified. "A quarter of the cost" refers to the prior Fable 5 cache read price, which is not stated here.
