# 244 — What is an AI gateway? (Vercel)
- **Source**: https://vercel.com/i/what-is-an-ai-gateway (Vercel, 2026-07-24)
- **Claim**: An AI gateway is a single proxy endpoint in front of all model providers that handles routing, failover, key management, token-based rate limiting, caching and per-request cost reporting; the article argues multi-provider apps grow one eventually and promotes Vercel's AI Gateway.
- **Mechanism**: Application authenticates once to the gateway, which authenticates to each provider (OIDC tokens on Vercel, or bring-your-own-key at provider price with no markup). Default provider choice weighs recent uptime and latency; an explicit provider order overrides it; a fallback model list is stepped through on failure and per-provider timeouts move to the next provider on slow responses. Every request is logged; the reporting API returns cost, market cost, input, output, cached input, cache creation and reasoning tokens and request count by day and by user. Zero Data Retention routing restricts to ZDR providers. Contrast drawn: router picks a model then hands off; traditional API gateway rate-limits requests with exact-URL caching; AI gateway limits by tokens and caches by prompt similarity (semantic).
- **Numbers**: Gateway latency under 20 ms before reaching a provider (Vercel). Ferro Labs (Go gateway, vendor-published, mock upstream fixed at 60 ms): ~25 microseconds overhead per request; at 1,000 concurrent users +8.1 ms p50 and +51.9 ms p99. Cloudflare docs: caching can cut latency up to 90% on a hit. LiteLLM benchmark: P95 630 ms to 150 ms and P99 1,200 ms to 240 ms when worker count matches CPUs; without tuning, throughput vs direct vLLM can degrade 1.7 to 4x (one engineer's report). Vercel production index through April 2026: teams at over 1 million requests/month route across 11 or more models; tool-call share of tokens rose from 31.6% to 58.9% (Oct 2025 to Apr 2026). a16z 2025 survey: 37% of 100 enterprise CIOs run 5+ models, up from 29%. Menlo: 66% moved to a newer model from the same provider, 11% left for another vendor. Vercel customers: P99 streaming latency 10% to 14% better, API error rates down 43.8% vs unmanaged direct calls; Searchable 100+ billion tokens, 5x development velocity; Zo Computer 20x reliability. Self-hosted LiteLLM-style proxy ~$500 to $1,700 per month infrastructure, database and observability.
- **Token-cost implication**: Put attribution (per user, per feature, with cached/reasoning token breakdown) and failover in a gateway layer rather than app code, so cost is visible per request instead of at invoice time. Use token-based limits rather than request limits, and consider semantic caching on repeated queries. Budget for the cost of running a self-hosted proxy.
- **Caveats**: Vendor marketing from Vercel, promoting its own product; customer results are self-reported case studies; benchmark figures come from other vendors' own tests against mock upstreams, not full-request measurements. No claim about token price savings from routing itself.
- **Topic**: routing
