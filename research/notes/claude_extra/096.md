# 096 — Just Enough Thinking: Efficient Reasoning with Adaptive Length Penalties Reinforcement Learning
- **Source**: https://arxiv.org/abs/2506.05256 (Stanford University / SynthLabs, arXiv, 2025-06)
- **Claim**: Adding a length penalty whose size scales with how often the model already solves a prompt (online solve rate) teaches a reasoning model to spend few tokens on easy problems and keep a large budget for hard ones. On DeepScaleR-1.5B this halves average tokens with little accuracy loss.
- **Mechanism**: Adaptive Length Penalty (ALP), an extra RL reward term. For each prompt, sample K rollouts and compute p_solved = fraction correct. Reward r = 1[answer correct] - beta * N * max(p_solved, 1/K), where N normalizes length (e.g. max trace length) and beta is a global weight; the 1/K floor keeps a small penalty even on unsolved prompts. Works with any group-based RL (GRPO, RLOO, Reinforce++) with no extra rollouts, since the group already provides the solve rate. Trained with GRPO in VeRL for 100 steps, batch 512, learning rate 1e-6, KL coefficient 0.001, 16K context in the main run, beta = 1e-7.
- **Numbers**: Average token use cut by about 50% (average length ratio vs base model 49%). Table 1 (Pass@1 at 4096 max tokens, 64 samples): DeepScaleR-1.5B original: MATH-500 0.81, AIME 24&25 0.22, OlympiadBench 0.47, mean lengths 2326 / 3906 / 3309 tokens. ALP-8K (beta=1e-7): 0.80 / 0.24 / 0.51, lengths 646 / 2254 / 2107. R1-Distill-Qwen-1.5B original: 0.72 / 0.12 / 0.36, lengths 2804 / 4007 / 3606; ALP-8K: 0.81 / 0.252 / 0.51, lengths 862 / 3331 / 2107; ALP-4K: 0.79 / 0.25 / 0.51, lengths 679 / 2740 / 1631. ALP uses 21% of its tokens on the easiest 50% of problems (fixed-length L1-Exact: 50%). Adaptation ratio (tokens on hardest 30% over easiest 30%): ALP 5.35x, R1-Alpha 4.57x, ThinkPrune 2.81x, DeepScaleR 2.41x, L1-Max 1.36x, L1-Exact 1.01x. Efficiency score: ALP 0.68, R1-Alpha 0.64, ThinkPrune 0.61. On MATH-500, ALP uses about 500 tokens on the easiest problems and nearly 3000 on the hardest (6x). At a 1024-token budget ALP gets 40% higher Pass@1 than the base on easier tasks. Mixed-difficulty test (60% AIME): ALP accuracy 0.89 to 0.52, average tokens about 500 to 2200. Frequency of "wait" about halved; repetitions 269.3 to 125.9 per response. Training cost: 100 steps with 16K context on 4 nodes of 8 H100 took 64 hours; 8K context took 34 hours.
- **Token-cost implication**: If you train your own reasoning model with RL, make the length penalty difficulty-aware instead of uniform so token savings come from easy prompts and not from hard ones. For off-the-shelf models, expect a fixed budget cap to cut accuracy on hard prompts; route by difficulty or use budgets that scale with it.
- **Caveats**: Authors' own results, math only (no code or general tasks), 1.5B models only. Baselines are public checkpoints with different data and hyperparameters, not matched retraining. Text says K=16 rollouts in one place and the hyperparameter table says rollout number 32. Text reports "40% higher Pass@1" at 1024 tokens without a table.
