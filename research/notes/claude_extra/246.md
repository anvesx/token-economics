# 246 — AI Gateway vs. OpenAI API (Vercel)
- **Source**: https://vercel.com/i/ai-gateway-vs-openai-api-direct (Vercel, 2026-07-27)
- **Claim**: Vercel argues that choosing a gateway over direct provider calls is first a reliability decision (failover rescued 3.5% of requests across its fleet), that the gateway bills at provider list price with zero markup, and that teams with load-bearing prompt caching should measure or go direct.
- **Mechanism**: Gateway reissues a request to a healthy alternative provider on error, rate limit or timeout; per-key budgets return HTTP 402 when exceeded (stopping runaway agent loops); caching: 'auto' applies the right cache strategy per provider (Anthropic and MiniMax need explicit cache markers); reporting API queryable by user, tag, provider or credential type. OpenAI Python SDK migrates by base-URL swap; AI SDK uses a gateway model string such as openai/gpt-5.5 (AI SDK 7 defaults to the gateway). Direct path keeps provider-specific options (parallelToolCalls, store, user, fine-tuning) and manual cache_control control. Example failure of abstraction layers: an AutoGPT bug embedded a fresh random token in the cached system prompt, invalidating the ephemeral Anthropic cache on every request.
- **Numbers**: 3.5% of fleet requests succeed only after failover; those rescued calls carry 4.9% of spend. Token price: provider list price, zero markup (also with BYOK); team-wide Zero Data Retention or provider allowlist $0.10 per 1,000 requests; Custom Reporting queries $5.00 per 1,000. Gateway overhead sub-20 ms (Vercel-published, no controlled head-to-head); Zo Computer saw 25.7% better average latency on its most-used model after switching; one independent benchmark found native Anthropic SDK 15 to 20% faster on small prompts, about even at large context. Anthropic cache reads billed at one-tenth of base input rate; a 90% cached-token discount "changes your unit economics". OpenAI Tier 1 starts at a $100 monthly cap; example 30,000 TPM means one request over 30,000 tokens fails (128,000-token context unreachable). OpenAI Dec 26, 2024 outage about four and a half hours; 99.93% reported uptime. Teams at 1M to 10M requests/month use 18 distinct models on average, over 10M use 35. Okara: four billion tokens a day, 120,000 companies, eight SDKs consolidated.
- **Token-cost implication**: Budget guards (per-key budgets) and failover belong in infrastructure. If cached-token discounts drive your margin, measure cache hit rate through any gateway before committing and verify the abstraction does not mutate cached prefixes. BYOK fallback to system credentials bills against Vercel credits, so budget for it.
- **Caveats**: Vendor marketing from Vercel for its own product; failover rates and spend share are fleet figures self-reported without methodology; no controlled head-to-head latency test; BYOK requests are excluded from published latency and throughput metrics. Rate-limit tier numbers are model- and tier-specific examples.
- **Topic**: routing
