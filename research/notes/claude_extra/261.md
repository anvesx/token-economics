# 261 — GitHub Copilot CLI is now generally available
- **Source**: https://github.blog/changelog/2026-02-25-github-copilot-cli-is-now-generally-available (GitHub, 2026-02-25)
- **Claim**: GitHub announced general availability of Copilot CLI, a terminal coding agent with plan and autopilot modes, sub-agents, multi-vendor model choice, auto-compaction and cross-session memory.
- **Mechanism**: Plan mode (Shift+Tab) builds a plan before coding; autopilot runs end-to-end without approvals; built-in agents (Explore, Task, Code Review, Plan) run in parallel; "&" prefix delegates to the cloud coding agent. Users switch models mid-session with /model, configure reasoning effort for extended-thinking models and toggle reasoning visibility with Ctrl+T. Auto-compaction compresses history in the background when the conversation approaches 95% of the context window. Repository and cross-session memory persist learned conventions. Hooks (preToolUse can deny or modify tool calls, postToolUse for post-processing), plugins, skills and custom agents extend behavior.
- **Numbers**: Auto-compaction triggers at 95% of the context window. GPT-5 mini and GPT-4.1 are included with a Copilot subscription at no additional premium request cost. Models listed: Claude Opus 4.6, Claude Sonnet 4.6, GPT-5.3-Codex, Gemini 3 Pro, Claude Haiku 4.5 for quick tasks. Public preview began September 2025. No token prices or savings figures.
- **Token-cost implication**: Use the zero-premium-request included models for routine work, switch to faster models (Haiku) for quick tasks and tune reasoning effort per task. Plan mode and auto-compaction are cost-relevant: plan first to avoid wasted agent iterations, and note long sessions are sustained by compaction at 95%.
- **Caveats**: Product announcement by the vendor; no measurements. Premium request pricing beyond the included models is not stated here. Autopilot removes approval gates, so cost and scope are bounded only by the user's own controls.
