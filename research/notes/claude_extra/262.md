# 262 — GitHub Copilot is moving to usage-based billing
- **Source**: https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing (GitHub, 2026-04-27)
- **Claim**: GitHub announced that all Copilot plans move on June 1, 2026 from premium request units to GitHub AI Credits consumed by token usage, because agentic sessions made flat per-request pricing unsustainable.
- **Mechanism**: Credits are consumed by token usage (input, output and cached tokens) at each model's published API rates. Each plan includes monthly credits equal to its price, with optional purchase of more; Business and Enterprise credits are pooled across the organization; admins can set budgets at enterprise, cost center and user level and choose to allow overage at published rates or cap spend. Fallback to a lower-cost model after exhausting allotment is removed. Code completions and Next Edit suggestions do not consume credits. Copilot code review also consumes GitHub Actions minutes at standard Actions rates. Annual Pro/Pro+ subscribers stay on premium requests with increased model multipliers (table not present in the text) until expiry.
- **Numbers**: Plan prices unchanged: Pro $10/month (includes $10 credits), Pro+ $39/month ($39 credits), Business $19/user/month ($19 credits), Enterprise $39/user/month ($39 credits). Promotional included usage for June, July and August: Business $30/month and Enterprise $70/month in credits. Preview bill experience in early May 2026.
- **Token-cost implication**: Under token-metered billing a multi-hour autonomous session costs far more than a quick chat, so builders should monitor tokens per task, prefer cheaper models for routine work, use cached-token pricing, and set budgets. No automatic downgrade to a cheaper model when credits run out.
- **Caveats**: Vendor announcement, no usage distribution or cost-per-session data. It says a quick chat and a multi-hour session "can cost the user the same amount" under the old model but gives no figures. The per-model multiplier table and the per-model API rates are not in the extracted text.
