# 237 — Prompt caching (Helicone gateway)
- **Source**: https://docs.helicone.ai/gateway/concepts/prompt-caching (Helicone, 2026-03)
- **Claim**: Helicone's OpenAI-compatible AI Gateway exposes provider prompt caching (OpenAI-style automatic, Anthropic cache_control, Gemini context caching) and documents each provider's multipliers, TTLs and minimums.
- **Mechanism**: OpenAI and compatible providers (OpenAI, Grok, Groq, Deepseek, Moonshot AI, Azure OpenAI) cache automatically for prompts over 1024 tokens; prompt_cache_key can be set to control cache keying. For Anthropic, up to 4 cache_control breakpoints per request with type "ephemeral" and ttl "5m" or "1h", set through the OpenAI SDK using @helicone/helpers types. prompt_cache_key, safety_identifier and user all map to Anthropic's user_id, which is its cache key. Gemini supports implicit and explicit caching with a 5-minute TTL plus an hourly storage fee.
- **Numbers**: Claims cached prompts cost up to 90% less. Anthropic multipliers: cache read 0.1x (example Sonnet at $3/MTok base: $0.30/MTok), 5-minute write 1.25x ($3.75/MTok), 1-hour write 2.0x ($6.00/MTok); minimum 1024 tokens for most models; Vertex AI and Bedrock only support 5-minute caching. Gemini: cache read 0.25x (75% off input), write 1.0x plus storage; storage $4.50/MTok/hour for 2.5 Pro, $1.00/MTok/hour for 2.5 Flash and Flash-Lite; minimum 1024 tokens (Flash), 2048 (Pro). Gemini 2.5 Pro up to 200K tokens: input $1.25/MTok, cache read $0.31/MTok, 5-min write $1.625/MTok ($1.25 + $4.50 x 5/60 = $0.375 storage); over 200K: input $2.50, read $0.625, 5-min write $2.875/MTok. OpenAI: standard rates for writes, discounted reads, exact pricing varies by model (no figures).
- **Token-cost implication**: Put long stable prefixes (system prompt, documents, examples) first and above provider minimums; use prompt_cache_key per document or workflow for hit control. On Anthropic choose 5m vs 1h TTL by reuse interval (1h write costs 2.0x vs 1.25x), and on Gemini account for storage fees when deciding whether caching pays.
- **Caveats**: Vendor gateway docs summarizing provider pricing; figures are as stated on the page and may drift from provider pages. Anthropic caching via the gateway covers messages only; tool caching is "coming soon". Gemini example says "TTL: 5 minutes only", which is as written here.
