# 205 — Model guidance (GPT-6 / GPT-5.6)
- **Source**: https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6 (OpenAI, date not stated)
- **Claim**: OpenAI's migration and prompting guide for the GPT-6 family (Astra, 6.1 Sol, 6.1 Terra, 6 Luna) and GPT-5.6, covering model tiers, reasoning-effort settings, caching changes, leaner prompts, pro mode and Programmatic Tool Calling.
- **Mechanism**: Tiers trade cost for capability (Astra highest; Sol near-Astra at lower cost; Terra fast and efficient; Luna fastest and cheapest). Reasoning effort levels: none, low, medium (default), high, xhigh, max (Astra and 6.1 Sol do not support none). A configuration_update input item changes reasoning effort mid-conversation without rewriting the prefix, preserving cache (keep request-level reasoning.effort unchanged). GPT-5.6 explicit prompt caching lets you mark reusable prefixes; cache writes are billed at 1.25x the uncached input rate, reads stay discounted; track cached_tokens and cache_write_tokens; prompt_cache_retention is replaced by prompt_cache_options.ttl (e.g. "30m"; mode "explicit" or breakpoints avoid unnecessary writes). Persisted reasoning (reasoning.context all_turns default for GPT-5.6, current_turn earlier) reuses reasoning items across turns via previous_response_id or encrypted items. Pro mode (reasoning.mode "pro") applies more model work and returns one answer; tokens billed at the model's standard rates. Programmatic Tool Calling lets the model write JavaScript to call tools and reduce intermediate output in a hosted runtime, best for bounded filtering, joining, ranking or aggregation, not when each result changes the next decision. Async tool calling and mid-turn steering are also listed.
- **Numbers**: Leaner prompts in a sample of internal coding-agent evals: scores up roughly 10-15%, total tokens down 41-66%, cost down 33-67% (directional). Cache writes 1.25x uncached input rate. Images over 65,535 pixels per side are scaled down; limit 30,000 patches. Astra: estimated API cost per task lower than earlier models despite higher per-token price (no figures given). No per-token prices in this text.
- **Token-cost implication**: Cut repeated instructions and unused tools before choosing a bigger model; start at medium effort and test one level lower when migrating; change effort with configuration_update to keep the cache; track cache write tokens because writes cost more than uncached input; use pro mode and max effort only where evals show gains; use Programmatic Tool Calling to keep large intermediate results out of context.
- **Caveats**: Vendor guidance; the lean-prompt and cost figures are internal and directional; Astra's lower per-task cost is asserted without numbers; Fast and Ultrafast modes mentioned without pricing.
