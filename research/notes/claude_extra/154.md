# 154 — Using GitHub Copilot CLI
- **Source**: https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/overview?plain=1 (Microsoft GitHub, date not stated)
- **Claim**: Usage guide for GitHub Copilot CLI covering sessions, permissions, custom agents, skills, hooks, MCP servers, and context-window management.
- **Mechanism**: Context control uses /usage (GitHub AI Credits used in session, duration, lines edited, token usage per model), /context (visual token usage), /compact (manual history compression). Auto-compaction starts in the background at about 80% of the token limit; if static context (system messages and tool definitions) already uses roughly 75% or more, it waits until about 90%; at about 95% the CLI waits for compaction to finish. Built-in subagents (Explore, Task, General purpose, Code review, Research, Rubber duck) run in separate contexts to keep the main conversation small; Task returns brief summaries on success and full output on failure. Other features: @file context inclusion, ! to run shell commands without a model call, /every and /after scheduled prompts, custom instructions files, hooks, assisted permissions (an LLM approves requests it judges safe), sandboxing.
- **Numbers**: Compaction thresholds: about 80% (default), about 90% (when static context is about 75% or more), about 95% (blocking). No prices or dollar figures.
- **Token-cost implication**: Offload exploration and noisy command output to subagents so the main context stays small; keep static context (tool definitions, system messages) lean because it shifts the compaction trigger and leaves less reclaimable space; use /usage to track per-model token use per session. Assisted permissions add an extra LLM call per eligible request.
- **Caveats**: Product documentation, not a measurement; no savings figures. Does not describe how AI Credits map to tokens or price.
- **Topic**: agent-cost
